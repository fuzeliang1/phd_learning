## ralmpc_prune.py（带 tube 的鲁棒版本）

按论文公式 (22)–(29) 和 Algorithm 1 独立实现的 RALMPC，没有沿用 MATLAB 代码（原因见本节末尾）。系统、约束、代价、x0=(4,0) 和常值扰动 d=(0,0.01) 取自 `main.m`。预测时域 N=8，每轮 60 步，8 轮迭代。每一步都检查四件事：

1. MPC 问题是否可行；
2. 真实闭环是否满足约束；
3. 真实下一状态是否落在预测 tube 内，即 H(x_{t+1} − x_{1|t}) ≤ s_{1|t}。这一项用来检验实现本身，任何违反都说明代码有错；
4. 定理 1 的代价下降条件 (45)：V_{t+1} − V_t ≤ −ℓ(x_t,u_t) + ℓ_{max,s}。

### 结论

- **提升空间裁剪在鲁棒自适应版本中同样无损**：三组设定下与全集一致，全程零违反，点数只有全集的约 1/4–1/6，同一轮的单步求解快 3–12 倍。
- **全集不仅慢，数值上也会失效**：约 1200–2000 个点时，所有内点法都无法稳定求解。可行性 LP 和 HiGHS 的 QP 求解器都确认问题本身可行，所以这是数值问题，不是理论问题。这比"只是变慢"更有力地说明裁剪是必要的。
- **x 投影凸包的问题在鲁棒版本里换了形式**：没有观察到证书违反（名义版里有），但样本集几乎停止增长，学习随之停滞。自适应设定下，它的最终代价比提升空间裁剪高约 1.4–2.1%；不自适应时差别可以忽略（145.12 vs 145.11）。
- **提升空间裁剪后的点数仍在缓慢增长**：不自适应时 8 轮从 161 涨到 556。所以方向二的"有预算压缩"（C2）仍然必要。

### 与论文、原 MATLAB 代码的实现差异

为了让理论在数值上可检验，做了以下改动。前五项是理论上合法的设计选择，第六项是数值处理。

1. **多面体 P 的形状**：沿用原代码的构造方式（在参数集 H 表示的轴向点上取 0.75-收缩集）。但 ρ、L_B 和在线 tube 都按论文用参数集的真实顶点 (±1,±1) 计算。若改用真实顶点构造 P，x0=(4,0) 处的鲁棒问题不可行。
2. **假设 4 的终端点**：tube 尺度从 x1 较大处冲到 s_steady 以上后，只能从上方渐近 s_steady，有限步内到不了。因此改为存一条从 (0, s̄) 衰减到 (0, s_steady) 的链，s̄=0.9/max c_j，每个点的代价按 (27) 式计算。x=0 时 s̄≥s_steady 的每个水平都是鲁棒不变的，后继关系和代价下降都严格成立。
3. **初始解**：求解时把 d̄ 放大 1%，使存下的 tube 有余量。这只会更保守，理论上合法；否则在线问题恰好落在可行域边界上，内点法失准。
4. **tube 增长约束的精确化简**：max_{i,l} H_i D(x) e_l 的 112 个分段只保留系数凸包的顶点（4 个），在 2000 个随机点上与原式差为 0。
5. **完全相同的样本点只保留代价最小的一个**：对三种策略同样处理，这一步是无损的。
6. **数值处理**：目标函数加 1e-7‖λ‖² 的正则（对最优值的影响 ≤1e-7）；求解器链为 Clarabel → HiGHS → PIQP → SCS → OSQP。

## certified_parallel_mpc.py

标量例子取自 Parallel MPC 论文 Example 1.1：x⁺=2x+u，|u|≤1，g=x²+u²（|x|≤2）。单元 A、B 是论文中两个已认证的终端设计。另加两个"学习得到"的终端价值：C 在 x≈0.45 处有一个伪极小值，D 是 J* 乘上 15% 的平滑误差。J* 由细网格值迭代得到。

| 策略 | 可行初始状态（共 19 个） | 平均次优 | 最坏 J/J* |
|---|---|---|---|
| 原论文 {A,B} | 17 | 0.03% | 1.002 |
| 不加证书，直接取最小 {A,B,C,D} | 19 | 312% | 24.9 |
| 加证书 {A,B,C,D} | 19 | 0.49% | 1.05 |

证书规则：学习单元在其预测终端态 x_N 上要通过 T J(x_N) − J(x_N) ≤ (1−α)·g(x_t,u_t)（α=0.5），移位候选同样要检验。一旦闭环值函数不满足 V_t ≤ V_{t−1} − α g_{t−1}，就锁定只用离线认证单元。复查更正（2026-10-23）：先前写的"9 个初始状态出现断裂，说明断裂检测必需"不成立。脚本现在用 `BREAK_TOL = 1e-6` 判定断裂，主表的断裂计数全为 0。脚本记录到的下降条件违反共 24 次（19 个初始状态中的 13 个），全部发生在 |x|<1e-4 处、全部在认证单元 A 上，违反量 1e-9 至 4e-8，当时 V_t 本身只有 1e-8 量级。这是原点附近的数值舍入（单元 A 用 3e-3 容差近似 x=0，控制量取网格），不是学习单元造成的真实断裂。关掉锁定后，19 个初始状态的代价逐点不变。所以这个例子只说明终端检验（包括对移位候选的检验）能挡住 C 的伪极小值；断裂监测的必要性目前只有理论论证，还需要专门构造例子。

不加证书时的失效机理：x_0 ≥ 0.2 的轨迹全部停在 x≈0.225。MPC 每一步都计划"这一步原地不动，下一步进 0.45 的坑"（预测值 0.1776），执行第一步后又重复同样的计划，每步付出约 0.10 的阶段代价。

局限：标量系统、暴力网格搜索、模型精确且确定。

## break_search.py（断裂是否真的发生、是否要紧）

在标量例子上加一个学习单元 E（往前看 2 步），它的终端价值取 5 类、共 66 种误差：

| 误差族 | 形式 | 个数 | 代表的实际情况 |
|---|---|---|---|
| 伪极小值 | J\*·(1 − a·exp(−((x−c)/w)²)) | 36 | 数据覆盖不到处的外推坑（类似单元 C） |
| 正弦相对误差 | J\*·(1 + e·sin(kx+p)) | 18 | 处处有相对误差但没有坑（类似单元 D） |
| 目标区域置零 | max(0, J\* − b) | 6 | RL 任务在目标附近终止，价值在目标邻域内为 0 |
| 局部乐观带 | 在 r1 ≤ \|x\| ≤ r2 内减去常数 d | 4 | 局部整体偏乐观 |
| 整体缩放 | s·J\* | 2 | 处处按比例偏乐观 |

初始状态取 [−0.8, 0.8] 上 9 个点，每条轨迹 30 步。真实断裂的判定：违反量 > 1e-6 且 \|x\| > 1e-3（排除原点附近的舍入）。

**不检验 vs 检验**（认证单元 {A,B}，α = 0.5，表中为各族成员最坏 J/J\* 的最大值）：

| 误差族 | 不检验 | 不检验时最坏 > 1.5 的成员 | 检验 |
|---|---|---|---|
| 伪极小值 | 8.947 | 12/36 | 1.066 |
| 正弦相对误差 | 1.021 | 0/18 | 1.021 |
| 目标区域置零 | 15.164 | 5/6 | 1.059 |
| 局部乐观带 | 7.406 | 4/4 | 1.046 |
| 整体缩放 | 1.014 | 0/2 | 1.014 |

**真实断裂：**

| α | 认证单元 | 出现断裂的误差 | 有断裂的轨迹 | 最大违反量 | 锁定与不锁定的代价差 | 代价 > v₀/α | 代价 > 定理 2 的界 | 检验后最坏 J/J\* |
|---|---|---|---|---|---|---|---|---|
| 0.5 | A / B / AB | 无 | 0 | — | — | 0 | 0 | 1.066–1.067 |
| 0.9 | A | 3 个置零 + 3 个乐观带 | 16 | 0.162 | ≤ 3e-11 | 0 | 0 | 1.009 |
| 0.9 | B 或 AB | 同上 | 16 | 0.132 | 0 | 0 | 0 | 1.008 |

结论：

- **终端检验是主要的保护。** 不检验时 66 种误差里有 21 种最坏代价超过 1.5 倍（最高 15.2 倍）；检验后全部不超过 1.067 倍。
- **α = 0.5 时，三种认证单元组合下都没有真实断裂。** 原因是"自修复"：移位计划也是同一学习单元下一时刻自身问题的可行解，所以该单元重新求解的值自动满足下降条件；只有新解和移位候选都检验失败、其他候选又不够低时才会断裂。
- **α = 0.9 时出现了真实断裂，而且只来自加性乐观误差。** 以置零误差 b = 0.3、x₀ = 0.8 为例：E 的预测值整体偏低一个常数，逐步看却是自洽的，能通过检验，v₀ = 2.874（J\* = 3.165）。轨迹靠近置零区域后 E 的检验失败，改用认证单元 B，而 B 的诚实值高于 v_t − α·g_t。这说明单步检验不能保证每一步都下降，断裂监测在证书层面是必要的。乘性误差（正弦、缩放）一次断裂都没有，这与"相对 Bellman 残差有界则不会断裂"的猜想一致（见选题文档 3.3 节命题 5）。
- **但这些断裂都没有造成后果。** 锁定与否代价相同；实际代价从未超过 v₀/α；定理 2 的后验界全部成立，而且更紧（上例中实际 3.165、定理 2 给出 3.170、v₀/α 为 3.193）。所以在这个例子里，断裂监测只是让证书在形式上保持成立，没有观察到它对性能的作用。是否影响性能，要在有模型误差、局部求解器或认证单元更保守的设定中检验。
- 局限：标量系统、暴力网格搜索、模型精确。

### 对方向一的含义

1. **并行取最小不保证优于最好的单个单元。** 例 4.1 中 x₀ = (−5, 2.7)：单元 3 单独使用的闭环代价是 59.717，并行 MPC 是 60.163（正文配置）或 59.814（代码配置）。中心单元按预测值选：J̃₁ = 60.2 < J̃₃ = 60.9，于是选了单元 1；但最低的上界不等于最好的闭环。论文 Remark 3.3 只在 J_j = J_µ̃ᵢ 等条件下保证优于单个策略，这里是一个满足论文全部假设的具体反例。方向一同样按预测值取最小，论文里应当报告"优于每个单元"这一点不能保证，只能保证上界。
2. **论文三个例子几乎没有可改进的空间。** 例 4.2 中并行 MPC 与 J\* 的相对间隙为 5e-6 至 5e-4，单独使用 u≡0 单元也只差 2e-5 至 5e-4；例 4.3 的间隙 ≤ 2e-4；例 4.1 为 0–0.9%（x₀ = (−5, 2.7) 时 0.3%–0.9%，另一个初始状态为 0）。学习终端价值在这些例子上最多改进千分之几，所以方向一阶段 1 不能沿用它们展示收益，要换成短时域下明显次优的设定（时域更短、认证单元更保守、或非线性系统），并像这里一样报告与 J\* 下界的间隙。
3. **可以直接复用的部件。** 不变集计算、最小迹公共 Lyapunov、带模态枚举的分段仿射前瞻问题、MIQP 下界，都已在这个脚本里实现并与论文核对过，阶段 1 可以直接在上面加学习单元和证书检验。

局限：只复现了论文报告的量；计时只用了一种求解器；例 4.2 的 LMI 增益沿用了论文打印值。

### 候选二：单摆起摆（Gym Pendulum-v1 动力学）

设定：m = l = 1，g = 10，dt = 0.05 s，半隐式欧拉，θ = 0 为竖直向上。为了让 NMPC 光滑，做了两处改动：速度上限 |ω| ≤ 8 写成约束（Gym 是截断）；角度代价用 2(1 − cos θ)（竖直附近等于 θ²，Gym 是取模后的 θ²）。阶段代价 2(1 − cos θ) + 0.1ω² + 0.001u²。

### 结论

1. **认证 MPC 只要可行、求解器又找到了好的解，代价就接近最优。** 论文两个例子缩短到 ℓ = 1 时，覆盖处的平均间隙 ≤ 0.5%；唯一超过 5% 的是"ℓ = 1、只用 LQR 单元"（7% 的状态，最大 5.3%）。单摆在好初值下间隙 ≤ 0.5%（例外是 u_max = 5、N = 80 的 2 个状态，差 5–7%，来自局部解）。所以选题文档阶段 0 结论里"先确认代价余量 > 5%"这个标准在这几类系统上都满足不了。学习终端价值能带来的收益是**覆盖率**：让短时域在认证短时域不可行的状态上也能用。
2. **覆盖率余量确实大。** 例 4.1 的 ℓ = 1 只覆盖 46%（只用 LQR）或 62%（4 个单元）；单摆 u_max = 2 时 N = 10 只覆盖 7%，要 N = 40–60（2–3 s）才到 96–100%。力矩充足（u_max = 5）时 N = 20 就到 95%，余量小得多。
3. **但在单摆上，"短时域 + 学习价值"相对"长时域认证 NMPC"几乎没有计算优势。** 热启动的 IPOPT 单次求解，N = 10 是 2.5 ms，N = 60 是 3.1 ms。只要长时域问题有好初值，选题文档 3.7 节的止损条件"同等计算量的长时域 MPC 追平本方法"在单摆上直接触发。
4. **长时域认证 NMPC 的真正弱点是初值。** 不用任何学习信息、从朴素初值出发时，N = 40–80 只能覆盖 70–81% 的状态；覆盖的状态上平均比参考差 47%–78%，最差的状态代价是参考的 4.4–5.9 倍。原因是长时域起摆问题非凸，IPOPT 会收敛到多摆几圈或方向不对的局部解。短时域（N ≤ 20）不受初值影响。

**对方向一的含义（判断，尚未验证）：**

- 最强的基线不是"认证短时域 MPC"，而是"**认证长时域 NMPC + 学习得到的初值**"（AC4MPC 用 actor 轨迹作初值，就是这个做法）。这个基线本身就有标准 MPC 的证书，学习只影响初值、不影响保证。方向一要赢它，至少要在下面一项上有明确优势：
  - 长时域问题本身很贵：高维、多障碍物、多智能体，单次求解远超实时预算。单摆不属于这种情况。
  - 学习价值带有模型算不出的信息：例如 WAM 对他车意图、语义目标或进度的估计。这时物理模型的时域再长也得不到这部分信息。
  - 拿不到可靠的初值。
- 学习单元有用的地方，恰好是认证短时域不可行的地方（单摆 N = 10 时占 93%）。在那里一旦断裂，没有认证后备可以锁定；如果加上命题 3 的放行条件（下一状态必须在认证区域内），学习单元就被限制回认证区域，收益随之消失。方法里需要明确：这部分状态只有"不断裂时的定理 1"，或者配一个只在断裂时才求解的长时域认证后备。
- 阶段 1 建议：单摆起摆（u_max = 2）适合做机制验证。覆盖率余量大，值迭代表可以直接当作"近乎完美的学习单元"，在它上面加误差就能复现 `break_search.py` 那类实验。但论文主实验要换成长时域 NMPC 本身昂贵或不可靠的系统，并把"长时域认证 NMPC + 学习初值"列为必须比较的基线。

局限：单摆只有 2 维状态；认证椭球是采样认证，不是证明；IPOPT 是局部求解器，覆盖率是下界；J_ref 是 J\* 的上界，间隙因此偏小；计时只在一台 4 核机器上测了一种求解器。
