## 第 21 课：强化学习的问题怎么写

### 这一课要解决的问题

第 8 课说过，RL 要解决的就是最优控制问题。这一课把 RL 的问题写成标准形式（MDP），定义 V 和 Q 两种价值函数，并给出后面所有算法的"地图"。

### 21.1 马尔可夫决策过程（MDP）

一个 RL 问题由五样东西组成：

| 符号 | 名字 | 走廊例子里是什么 | 控制里的对应 |
|---|---|---|---|
| S | 状态集合 | {0, 1, 2, 3, 4} | 状态 x |
| A | 动作集合 | {左, 右} | 控制量 u |
| P(s′ \| s, a) | 转移概率：在 s 做 a，下一步到 s′ 的概率 | 确定性走廊：往右一定到 s + 1 | 模型 x⁺ = f(x, u) |
| r(s, a) | 奖励 | 每步 −1 | −g(x, u) |
| γ | 折扣因子 | 0.9 | MPC 理论里通常不打折，γ = 1 |

"马尔可夫"的意思是：下一步只取决于现在的状态和动作，和更早的历史无关。这其实就是第 1.1 节对"状态"的要求：知道现在的状态和接下来的控制，就能算出未来。

和第 2 课的最优控制问题相比，有两点不同：

1. 转移可以是随机的，用概率 P 描述，比如路面打滑；
2. RL 默认**不知道** P 和 r 的公式，只能通过和环境交互得到样本：在状态 s 做了 a，看到奖励 r 和下一状态 s′。

### 21.2 回报

从第 t 步开始的**回报**（return）：

> G_t = r_t + γ·r_{t+1} + γ²·r_{t+2} + …

数例：在走廊上从 0 出发一直往右，4 步到终点：G = −1 − 0.9 − 0.81 − 0.729 = **−3.439**。到终点以后不再有奖励，所以只有 4 项。

### 21.3 两种价值函数：V 和 Q

- **状态价值** V^π(s)：从 s 出发、一直按策略 π 行动，回报的期望。
- **动作价值** Q^π(s, a)：从 s 出发，**先做动作 a**，之后再按 π 行动，回报的期望。
- **最优价值** V\*(s)、Q\*(s, a)：在所有策略里取最好的。

它们的关系：

- V\*(s) = max_a Q\*(s, a)：从 s 出发的最好结果，等于"先选最好的第一步，之后一直最好"；
- 最优策略：π\*(s) = argmax_a Q\*(s, a)。

**为什么 Q 很重要**：只要知道 Q\*，**不需要模型**就能选动作，直接挑 Q 最大的那个。只知道 V\* 的话，选动作之前要先用模型试走一步，算出每个动作的 r + γ·V\*(下一状态) 再比较，这就是第 3 课 Bellman 方程里的那一步"试走"。没有模型的 RL 算法，所以大多学 Q。

**走廊的最优价值**（γ = 0.9，从终点往回算）：

- V\*(4) = 0（终点）；
- V\*(3) = −1 + 0.9 × 0 = −1；
- V\*(2) = −1 + 0.9 × (−1) = −1.9；
- V\*(1) = −1 + 0.9 × (−1.9) = −2.71；
- V\*(0) = −1 + 0.9 × (−2.71) = −3.439。

**动作价值**：往右是最优动作，所以 Q\*(s, 右) = V\*(s)。往左要多绕路：

- Q\*(3, 左) = −1 + 0.9 × V\*(2) = −1 − 1.71 = −2.71；
- Q\*(2, 左) = −1 + 0.9 × V\*(1) = −1 − 2.439 = −3.439；
- Q\*(1, 左) = −1 + 0.9 × V\*(0) = −1 − 3.0951 = −4.0951；
- Q\*(0, 左) = −1 + 0.9 × V\*(0) = −4.0951（撞墙留在 0）。

| 状态 s | 0 | 1 | 2 | 3 |
|---|---|---|---|---|
| Q\*(s, 右) = V\*(s) | −3.439 | −2.71 | −1.9 | −1.0 |
| Q\*(s, 左) | −4.0951 | −4.0951 | −3.439 | −2.71 |
| 优势 A\*(s, 左) = Q\*(s, 左) − V\*(s) | −0.656 | −1.385 | −1.539 | −1.71 |

最后一行是**优势函数**（advantage）：A(s, a) = Q(s, a) − V(s)，意思是"这个动作比按策略走好多少"（负数表示差多少）。最优动作的优势是 0。它在第 25–27 课会反复出现。

### 21.4 Bellman 方程的四种写法

第 3 课的 Bellman 方程，在 RL 里有四种写法。转移随机时要对下一状态取期望（Σ_{s′} P(s′ | s, a)·…）：

| 写法 | 方程 | 谁在用 |
|---|---|---|
| V^π | V^π(s) = Σ_a π(a \| s)·[r(s, a) + γ·Σ_{s′} P(s′ \| s, a)·V^π(s′)] | 评估一个策略（A2C、PPO 的 critic） |
| Q^π | Q^π(s, a) = r(s, a) + γ·Σ_{s′} P(s′ \| s, a)·Σ_{a′} π(a′ \| s′)·Q^π(s′, a′) | SARSA、DDPG、TD3、SAC 的 critic |
| V\* | V\*(s) = max_a [r(s, a) + γ·Σ_{s′} P(s′ \| s, a)·V\*(s′)] | 值迭代（第 3 课） |
| Q\* | Q\*(s, a) = r(s, a) + γ·Σ_{s′} P(s′ \| s, a)·max_{a′} Q\*(s′, a′) | Q-learning、DQN |

**一个随机的例子：打滑的走廊。** 往右只有 0.8 的概率成功，0.2 的概率打滑、留在原地。从 3 出发，一直往右：

> V\*(3) = −1 + 0.9 × [0.8 × V\*(4) + 0.2 × V\*(3)] = −1 + 0.18·V\*(3)

V\*(3) 出现在等号两边。移项：V\*(3) × (1 − 0.18) = −1，所以 V\*(3) = −1/0.82 = **−1.2195**。

同样一路往回算（每个状态都满足 V\*(s) × 0.82 = −1 + 0.72 × V\*(s + 1)）：

- V\*(2) = [−1 + 0.72 × (−1.2195)]/0.82 = −1.878/0.82 = −2.2903；
- V\*(1) = [−1 + 0.72 × (−2.2903)]/0.82 = −3.2305；
- V\*(0) = [−1 + 0.72 × (−3.2305)]/0.82 = **−4.0561**。

打滑让每个状态都"更贵"了（−4.0561 比 −3.439 差）。

### 21.5 算法地图：三个问题

后面所有算法，都可以用三个问题来分类：

1. **学什么？**
   - 只学价值，动作从价值里挑（value-based）：Q-learning、DQN；
   - 只学策略（policy-based）：REINFORCE；
   - 两个都学（actor-critic）：A2C、PPO、DDPG、TD3、SAC。
2. **数据从哪来？**
   - on-policy（同策略）：只能用**当前策略**刚采的数据，策略一更新，旧数据就作废：REINFORCE、A2C、PPO；
   - off-policy（异策略）：可以用旧策略的、别人的、随机试出来的数据：Q-learning、DQN、DDPG、TD3、SAC。
3. **用不用模型？**
   - 无模型（model-free）：上面这些都是；
   - 有模型（model-based）：Dyna、AlphaZero、MuZero、Dreamer、TD-MPC。MPC 就是"模型已知时的规划"。

| 算法 | 年份 | 学什么 | 数据 | 动作 | 本部分 |
|---|---|---|---|---|---|
| Q-learning | 1989 | Q（表格） | off-policy | 离散 | 第 22 课 |
| REINFORCE | 1992 | 策略 | on-policy | 都可以 | 第 25 课 |
| SARSA | 1994 | Q（表格） | on-policy | 离散 | 第 22 课 |
| DQN | 2013/2015 | Q（神经网络） | off-policy | 离散 | 第 23 课 |
| A2C / A3C | 2016 | 策略 + V | on-policy | 都可以 | 第 26 课 |
| TRPO / PPO | 2015 / 2017 | 策略 + V | on-policy | 都可以 | 第 27 课 |
| DDPG / TD3 | 2016 / 2018 | 确定性策略 + Q | off-policy | 连续 | 第 28 课 |
| SAC | 2018 | 随机策略 + 两个 Q | off-policy | 连续 | 第 28 课 |
| AlphaZero / MuZero | 2018 / 2020 | 策略 + V + 树搜索（MuZero 还学模型） | 自我对弈 | 离散 | 第 29 课 |
| Dreamer / TD-MPC | 2020 / 2022 | 模型 + 策略 + 价值 | off-policy | 连续 | 第 29 课 |

（年份已核对，见附录 C。取正式发表的年份，只有 arXiv 版的取 arXiv 年份；DQN 的 arXiv 版和 Nature 版都重要，写成 2013/2015。Q-learning 的 1989 是 Watkins 的博士论文，收敛性证明发表于 1992 年。）

### 21.6 动态规划和 RL 的根本区别

第 3 课的值迭代 J ← TJ，每一步都要用模型对所有 u 算 g + J(f(x, u))。RL 的核心改动只有一句话：

> **用样本平均代替用模型算期望。**

在 s 做 a、实际看到 r 和 s′，就把 r + γ·V(s′) 当作"期望值的一个带噪声的样本"。第 22 课的所有算法都建立在这个想法上。

## 第 22 课：不用模型估计价值：蒙特卡洛、TD、Q-learning、SARSA

### 这一课要解决的问题

不知道模型，只有一条条走过的轨迹，怎样估计价值？怎样找到最优策略？

### 22.1 蒙特卡洛（MC）：走完一整局，取实际回报的平均

最直接的办法：从 s 出发走很多局，每局记下实际的回报 G，取平均。

- **确定性走廊、一直往右**：每一局从 0 出发的回报都是 −3.439，走一局就够了。
- **打滑走廊、一直往右，从 3 出发**：第一次就成功的概率 0.8，回报 −1；第二次才成功的概率 0.2 × 0.8 = 0.16，回报 −1 − 0.9 = −1.9；第三次才成功的概率 0.032，回报 −2.71；……
  - 回报的平均是 **−1.2195**，正好等于 V\*(3)，没有偏差；
  - 回报的标准差是 **0.4796**。
- **打滑走廊从 0 出发**（仿真 20 万局）：平均 −4.0564（真值 −4.0561），标准差 **0.6517**，90% 的回报落在 [−5.217, −3.439] 之间。

MC 的特点：

- **无偏**：平均值就是真值；
- **方差大**：一局和一局差很多，要平均很多局才准；
- **必须等一局结束**才能算回报。车辆这类连续运行的任务，"一局"可能很长。

### 22.2 TD(0)：走一步就更新，用自己的估计补上剩下的

TD 的想法（Sutton 1988）：不等一局结束，每走一步，就用"这一步实际得到的奖励 + 下一状态的估计"当目标：

> V(s) ← V(s) + α·[r + γ·V(s′) − V(s)]

方括号里就是第 8.3 节的 TD 误差 δ（这里用奖励写，符号和第 8.3 节的代价写法相反）。α 是学习率。用自己的估计去更新自己的估计，叫**自举**（bootstrapping）。

**手算**：确定性走廊，策略"一直往右"，α = 0.5，V 全部从 0 开始，每局按 s = 0、1、2、3 的顺序更新。

第 1 局：

- V(0) ← 0 + 0.5 × (−1 + 0.9 × V(1) − V(0)) = 0.5 × (−1 + 0 − 0) = −0.5（此时 V(1) 还是 0）；
- V(1)、V(2) 同理，都是 −0.5（更新它们时，下一格还是 0）；
- V(3) ← 0.5 × (−1 + 0.9 × 0) = −0.5（V(4) = 0 是终点）。

第 2 局（现在 V = (−0.5, −0.5, −0.5, −0.5)）：

- V(0) ← −0.5 + 0.5 × (−1 + 0.9 × (−0.5) + 0.5) = −0.5 + 0.5 × (−0.95) = −0.975；
- V(1)、V(2) 同理，都是 −0.975；
- V(3) ← −0.5 + 0.5 × (−1 + 0 + 0.5) = −0.75。

第 3 局（现在 V = (−0.975, −0.975, −0.975, −0.75)）：

- V(0) ← −0.975 + 0.5 × (−1 + 0.9 × (−0.975) + 0.975) = −0.975 + 0.5 × (−0.9025) = −1.4262；
- V(1) 同理 −1.4262；
- V(2) ← −0.975 + 0.5 × (−1 + 0.9 × (−0.75) + 0.975) = −0.975 + 0.5 × (−0.7) = −1.325；
- V(3) ← −0.75 + 0.5 × (−1 + 0 + 0.75) = −0.875。

| 第几局之后 | V(0) | V(1) | V(2) | V(3) |
|---|---|---|---|---|
| 1 | −0.5 | −0.5 | −0.5 | −0.5 |
| 2 | −0.975 | −0.975 | −0.975 | −0.75 |
| 3 | −1.4262 | −1.4262 | −1.325 | −0.875 |
| 5 | −2.2417 | −2.105 | −1.7 | −0.9688 |
| 8 | −3.0216 | −2.5574 | −1.8645 | −0.9961 |
| 真值 | −3.439 | −2.71 | −1.9 | −1.0 |

从表里能看出两点：

1. 离终点最近的 V(3) 最先变准，正确的信息是**从终点一格一格往回传**的；
2. 前几局的估计有偏（目标里用了还不准的 V(s′)），这是 TD 的**偏差**；但每次更新只涉及一步的随机性，**方差小**，而且走一步就能更新，不用等一局结束。

### 22.3 MC 和 TD 之间：n 步回报和 λ

| | 目标 | 偏差 | 方差 |
|---|---|---|---|
| TD(0) | r_t + γ·V(s_{t+1}) | V 不准时有 | 小 |
| n 步回报 | r_t + γ·r_{t+1} + … + γ^{n−1}·r_{t+n−1} + γⁿ·V(s_{t+n}) | 中 | 中 |
| MC | r_t + γ·r_{t+1} + …（一直加到局末） | 无 | 大 |

TD(λ)（Sutton 1988）把所有 n 步回报按权重 (1 − λ)·λ^{n−1} 加权平均：λ = 0 就是 TD(0)，λ = 1 就是 MC。这个想法在第 27 课变成 PPO 用的 GAE。

### 22.4 Q-learning：直接学最优的 Q

Watkins（1989）的 Q-learning：

> Q(s, a) ← Q(s, a) + α·[r + γ·max_{a′} Q(s′, a′) − Q(s, a)]

它就是 21.4 节第四行（Q\* 的 Bellman 方程）的样本版：把"对 s′ 取期望"换成"实际到达的那个 s′"。

最重要的性质是 **off-policy**：实际行动时可以随便探索，比如 **ε-贪心**（以 ε = 0.1 的概率随机选一个动作，否则选当前 Q 最大的动作）；但目标里用的是 max，学到的是**最优**策略的价值，和实际怎么走的无关。

走廊上的结果（ε = 0.1，α = 0.1，Q 全部从 0 开始，2000 局）：

| | s = 0 | 1 | 2 | 3 |
|---|---|---|---|---|
| Q(s, 右) | −3.439 | −2.71 | −1.9 | −1.0 |
| Q(s, 左) | −4.095 | −4.095 | −3.439 | −2.71 |

和 21.3 节的 Q\* 完全一致。

一个细节：Q 从 0 开始，而真值全是负数，所以初值是"乐观"的。没试过的动作看起来比试过的好（0 比负数大），智能体会主动去试。这叫**乐观初始化**，是一种简单的探索手段。

### 22.5 SARSA：学"自己实际在做的"策略

SARSA（Rummery 和 Niranjan 1994）把目标里的 max 换成下一步**实际选的**动作 a′：

> Q(s, a) ← Q(s, a) + α·[r + γ·Q(s′, a′) − Q(s, a)]

名字来自更新用到的五个量 (s, a, r, s′, a′)。它是 on-policy 的：学的是"带着探索噪声的那个策略本身"的价值，而不是最优策略的价值。

Sutton–Barto 书里的"悬崖行走"例子（例 6.6）说明了两者的区别：网格上起点和终点之间，贴着悬崖边走最短；每步奖励 −1，掉下悬崖奖励 −100 并回到起点；训练时用 ε-贪心，偶尔会随机迈一步。

- Q-learning 学到"贴着悬崖边走"（最优路线），但训练时因为随机迈的那一步经常掉下去，训练中的平均回报反而更低；
- SARSA 把"自己会随机乱迈一步"也算进了价值，学到离悬崖远一点的安全路线。

（这是书里的结论，这里没有重算。）对控制的启示：如果执行时一定带着噪声，学"带噪声的策略"的价值更安全。

### 22.6 表格方法的极限

到这里，价值都存成一张表，每个 (s, a) 一个数。问题：

1. **状态连续**：单摆的 (θ, ω) 有无穷多个值；
2. **维数灾难**：每维分 100 格，单摆 2 维是 1 万格，6 维的车辆模型是 10¹² 格；
3. **不会推广**：在一个格子学到的东西，对旁边的格子毫无帮助，哪怕两个状态几乎一样。

所以要用一个带参数的函数（比如神经网络）来近似价值，这就是第 23 课。

## 第 23 课：从表格到神经网络：DQN、经验回放、目标网络

### 这一课要解决的问题

用函数近似 Q 以后，Q-learning 会变得不稳定，甚至发散。DQN 用"目标网络"和"经验回放"两招把它稳住。这一课用例子一讲清楚：为什么会发散、两招各自在解决什么、它们什么时候管用。

### 23.1 用函数近似 Q

把表格换成带参数 w 的函数 Q_w(s, a)。训练就是回归：让 Q_w(s, a) 接近目标（也叫标签）

> y = r + γ·max_{a′} Q(s′, a′)

**用例子一的代价版本**：x⁺ = 2x + u，g = x² + u²。这里是代价，要最小化，所以 max 换成 min；不打折，γ = 1。

真实的 Q\*：先付这一步的代价，再加上从下一状态出发的最优价值：

> Q\*(x, u) = x² + u² + 4.236·(2x + u)²

展开：4.236 × (4x² + 4xu + u²) = 16.944x² + 16.944xu + 4.236u²，再加上 x² + u²：

> Q\*(x, u) = 17.944x² + 16.944xu + 5.236u²

所以用三个特征 (x², xu, u²) 就能精确表示 Q\*：Q_w(x, u) = w₀x² + w₁xu + w₂u²。

**由 Q_w 选动作**：对 u 求导令其为 0：2w₂u + w₁x = 0，得 u = −w₁/(2w₂)·x。代回去，最小值是 (w₀ − w₁²/(4w₂))·x²。

代入 Q\* 的系数检查：u = −16.944/10.472·x = −1.618x；最小值 (17.944 − 16.944²/20.944)·x² = (17.944 − 13.708)·x² = 4.236x²。和第 4 课的 LQR 完全一致。

**数据**：在 [−1, 1] × [−1, 1] 里随机取 500 个 (x, u)，每个记下代价 g 和下一状态 x⁺ = 2x + u。动作是随机取的，不是某个好策略选的，所以这是典型的 off-policy 数据。

### 23.2 做法一：拟合 Q 迭代（把标签冻住，每轮都拟合到底）

**拟合 Q 迭代**（fitted Q iteration；Ernst 等 2005，Riedmiller 的 NFQ 2005）：

1. 用当前的 Q_old 给每个样本算标签：y_i = g_i + min_u Q_old(x⁺_i, u)；
2. 用最小二乘把 Q_new 拟合到这些标签上，**拟合到底**；
3. Q_old ← Q_new，回到第 1 步。

结果（从 w = 0 开始；"隐含的 p"指 min_u Q_w 的系数 w₀ − w₁²/(4w₂)，也就是对 J\* = 4.236x² 的估计）：

| 第几轮 | w = (w₀, w₁, w₂) | 隐含的 p | 贪心增益 w₁/(2w₂) |
|---|---|---|---|
| 1 | (1, 0, 1) | 1 | 0 |
| 2 | (5, 4, 2) | 3 | 1 |
| 3 | (13, 12, 4) | 4 | 1.5 |
| 4 | (17, 16, 5) | 4.2 | 1.6 |
| 5 | (17.8, 16.8, 5.2) | 4.2308 | 1.6154 |
| 6 | (17.923, 16.923, 5.231) | 4.2353 | 1.6176 |
| 7 | (17.941, 16.941, 5.235) | 4.2360 | 1.6180 |
| 8 | (17.944, 16.944, 5.236) | 4.2361 | 1.6180 |

隐含的 p 依次是 1、3、4、4.2、4.2308……，和第 3.4 节值迭代的数列一模一样。原因：二次函数经过 Bellman 算子还是二次函数（第 3.3 节：p·x² 变成 [1 + 4p/(1 + p)]·x²），所以每一轮的最小二乘都能精确拟合，拟合 Q 迭代就**等于**值迭代。

**每一轮误差缩小多少**：0.146 倍。来源：T(p) = 1 + 4p/(1 + p) 的导数在 p\* 处是 4/(1 + p\*)² = 4/27.42 = 0.146。另一种理解：0.146 = 0.382²，而 0.382 是最优闭环 x⁺ = 0.382x 的收缩系数。p 的误差是在下一状态上被"看到"的，下一状态缩小了 0.382 倍，误差就按它的平方缩小。

**数据有噪声时**：给代价加上标准差 0.1 的噪声，换 400 组不同的数据各做一遍（每组 500 个样本、40 轮）：

- p 的平均 4.2332，标准差 0.0407（约 1%），最低 4.118，最高 4.343；
- 52.5% 的结果比真值 4.2361 低（乐观），47.5% 比真值高（悲观）。

即使函数族完全对，有限的、带噪声的数据也会让 critic 带着 ±1% 量级、方向随机的误差。这个结果第 24 课还要用。

### 23.3 做法二：在线半梯度 Q-learning（每来一个样本走一小步）

神经网络通常不"拟合到底"，而是每来一个（或一小批）样本，就沿梯度走一小步：

> δ = g + min_u Q_w(x⁺, u) − Q_w(x, u)，w ← w + η·δ·(x², xu, u²)

η 是步长（学习率）。关键在于：标签 g + min_u Q_w(x⁺, u) 用的是**当前**的 w，w 一变，标签也跟着变。这叫**半梯度**：求梯度时假装标签是常数，其实它依赖 w。

结果（同样的 500 个样本，每步随机抽一个；"发散"指参数的绝对值超过 10⁶）：

| 步长 η | 结果 |
|---|---|
| 0.003 | 第 10337 步发散 |
| 0.001 | 第 30944 步发散；换 5 组数据，分别在第 25515–29296 步发散 |
| 0.0003 | 第 101206 步发散 |
| 0.0001 | 每 4 万步记一次 p：3.74 → 27.8 → 170 → 1063 → 6411，越来越大 |

步长越小，发散得越慢，但**都发散**。

**更说明问题的实验**：直接从 Q\* 旁边出发（每个参数加一个约 0.001 的随机扰动），η = 0.001：

| 第几步 | 1 | 1000 | 3000 | 5000 | 8000 | 10000 | 20000 |
|---|---|---|---|---|---|---|---|
| 和 w\* 的距离 | 0.002 | 0.0092 | 0.145 | 2.47 | 42.3 | 151 | 27500 |
| 隐含的 p | 4.239 | 4.249 | 4.440 | 7.29 | 38.4 | 110 | 17682 |

在 w\* 本身，每个样本的 TD 误差都是 0（500 个样本里最大的也只有 1e−14），所以 w\* 是这个算法的不动点。但这个不动点**不稳定**：稍微偏一点，就被越推越远，每 1000 步放大约 4 倍。

**为什么："你追标签，标签跑得比你还快"。** 只看 w₀ 一个分量：w₀ 增加 Δ，预测 Q_w(x, u) 增加 Δ·x²；而标签里的 min_u Q_w(x⁺, u) 大约增加 Δ·(x⁺)²。下一状态 x⁺ = 2x + u 平均比 x 大得多（数据里 |x| ≤ 1，|x⁺| 可以到 3）。按数据平均，标签的增加量是预测增加量的 4.6 倍：E[x²·(x⁺)²] = 0.911，E[x⁴] = 0.2。于是每次"把预测往标签拉"，标签反而被抬得更高。

严格一点的说法：把期望的更新在 w\* 附近线性化，得到矩阵 b·aᵀ − M，其中 M = E[φφᵀ]（φ = (x², xu, u²)），b = E[φ·(x⁺)²]，a = (1, −1.618, 2.618) 是 min_u Q_w 对 w 的导数。这个矩阵最大的特征值是 **+1.444**，是正的。正特征值意味着误差大约按 e^{1.444·η·步数} 增长：η = 0.001 时每 1000 步放大 e^{1.444} = 4.24 倍，和上表实测的约 4 倍一致（第 3000 步到第 5000 步放大了 17 倍，每 1000 步约 4.1 倍）。步长只改变发散的快慢，改变不了发散这件事。

**这就是"致命三元组"**（deadly triad，Sutton–Barto 书第 11.3 节）。下面三样同时出现时，价值学习可能发散：

1. **函数近似**：所有 (x, u) 共用一组参数 w。在一个样本上更新，会改变所有地方的 Q，包括标签里用到的下一状态 x⁺；
2. **自举**：标签里用了 Q_w 自己；
3. **off-policy**：数据的分布（随机的 u）和目标里的策略（贪心的 u）不一样，下一状态落在数据范围之外。

书里的说法是：三样里去掉任何一样，就可以避免这种不稳定。表格（不共享参数）的 Q-learning 收敛；不自举（用 MC 回报当标签）就是普通的回归；评估一个固定策略、并且数据来自这个策略本身（on-policy）时，线性特征的 TD 被证明收敛（Tsitsiklis 和 Van Roy 1997）。例子一和 Baird 1995 年的经典反例是同一类：真值可以用这组特征精确表示，算法照样发散。

**拟合 Q 迭代为什么不发散？** 因为它每一轮都把回归解到底，等于在函数族里精确地做了一次 Bellman 算子，误差按 0.146 缩小。半梯度每次只沿当前样本的特征方向挪一小步，挪的方向和"误差应该缩小的方向"不一致，又被不断变化的标签牵着走。

### 23.4 目标网络：让标签慢下来

DQN（Mnih 等，Nature 2015）的第一招：复制一份参数 w⁻，叫**目标网络**。标签用 w⁻ 算：

> y = r + γ·max_{a′} Q_{w⁻}(s′, a′)

w⁻ 每隔 C 步才同步一次（w⁻ ← w），DQN 里 C = 10000（凭记忆）。

两次同步之间，标签是固定的，问题变成普通的回归。如果每段时间里回归都能解得差不多，整个过程就接近 23.2 节的拟合 Q 迭代；C 趋于无穷时，就是拟合 Q 迭代本身。

**在例子一上测**：每种设置换 5 组数据，各跑 15 万步。这 500 个固定的样本本身就相当于一个回放缓冲区（23.5 节）。

| 步长 η | 同步间隔 C | 理论：每个同步周期误差放大的倍数 | 实测（5 组数据） |
|---|---|---|---|
| 0.05 | 50 | 3.03 | 全部发散（第 1069–1217 步） |
| 0.05 | 200 | 1.67 | 全部发散（第 3450–5020 步） |
| 0.05 | 500 | 0.818 | 全部收敛到 4.2361 |
| 0.05 | 2000 | 0.143 | 全部收敛到 4.2361 |
| 0.01 | 50 | 1.65 | 全部发散（第 3158–3630 步） |
| 0.01 | 200 | 2.82 | 全部发散（第 4882–5325 步） |
| 0.01 | 500 | 3.19 | 全部发散（第 9208–9803 步） |
| 0.01 | 2000 | 1.054 | 3 组发散；2 组跑完 15 万步还没收敛（p = 5.59、4.20） |

"理论"一列是把期望的更新线性化以后，一个同步周期内误差被放大的倍数（矩阵的谱半径）。小于 1 就收敛，大于 1 就发散。实测和理论完全吻合。

规律：**每个同步周期里，回归要解得够好**。一个周期内回归剩下的误差大约是 e^{−η·λ_min·C}，λ_min = 0.0889 是矩阵 M 最小的特征值：

- η = 0.05、C = 500：剩 10.8%，收敛；
- η = 0.01、C = 500：剩 64%，发散；
- η = 0.05、C = 50：剩 80%，发散。

两个反直觉的现象：

- 同步太勤（C = 50、200）照样发散，等于没用目标网络；
- η = 0.01 时，C 从 50 加到 500，放大倍数反而从 1.65 增大到 3.19。回归解了一半就同步，最糟糕。要么同步得很勤（接近不用目标网络），要么长到能把回归解完。

**软更新**（DDPG、TD3、SAC 用的）：不隔 C 步硬同步，而是每一步都让 w⁻ 往 w 挪一点点：

> w⁻ ← (1 − τ)·w⁻ + τ·w

- τ = 0.005：w⁻ 和 w 的差距每 138 步减半（0.995^138 ≈ 0.5）；
- τ = 0.001：每 693 步减半。

在例子一上（每一步的误差放大倍数，小于 1 才收敛）：

| 步长 η | τ | 理论：每步放大倍数 | 实测（5 组数据） |
|---|---|---|---|
| 0.05 | 0.01 | 1.014 | 全部发散 |
| 0.05 | 0.005 | 1.007 | 全部发散 |
| 0.05 | 0.001 | 0.9999 | 3 组收敛到 4.2361，2 组发散 |
| 0.01 | 0.01、0.005、0.001 | 1.007、1.005、1.001 | 全部发散 |

τ = 0.001、η = 0.05 时理论值刚好小于 1，处在稳定的边缘，实测也是一半一半。

**这一节的结论**：目标网络是一个"让标签变慢"的实用手段，它管用的条件是"标签慢、回归快"，不是收敛的保证。例子一是一个困难的例子：下一状态最大是数据范围的 3 倍，标签被放大得厉害。在这里，只有间隔足够长的硬同步可靠。实际的深度 RL 里，目标网络大大减少了发散，但"训练曲线突然崩掉"仍然常见。

### 23.5 经验回放：把数据存起来、打乱了再用

DQN 的第二招来自 Lin（1992）：把每一步的 (s, a, r, s′) 存进一个**回放缓冲区**（DQN 存最近 100 万条），每次训练时从里面**随机**抽一小批（DQN 是 32 条，凭记忆）。

它解决三个问题。

**1. 打破相关性。** 一条轨迹上相邻的样本几乎一样，比如单摆这一刻和下一刻的状态差不多。SGD（随机梯度下降）默认样本大致相互独立，如果喂进去一长串相似的样本，网络就只记得最近看到的。

例：用特征 (1, x, x²) 拟合 y = x²（函数族完全对），2000 个样本，每个样本走一步 SGD（步长 0.3），只过一遍：

| 样本顺序 | 拟合完以后在 [−1, 1] 上的最大误差（20 组平均） |
|---|---|
| 按 x 从小到大排好（像一条从左慢慢扫到右的轨迹） | 0.503 |
| 打乱 | 0.0000 |

按顺序喂的那一组，拟合结果在 x = −1、0、1 处是 0.729、0.496、0.999（真值 1、0、1）：只有最后看到的右端是准的，前面的部分被"忘掉"了。打乱以后完全准确。

**2. 重复利用。** 每条数据可以被抽中很多次。DQN 每 4 步更新一次、每次抽 32 条、缓冲区 100 万条，一条数据在缓冲区里平均被用 (100 万 ÷ 4) × 32 ÷ 100 万 = **8 次**。这对数据昂贵的场景（真车、真机器人）很重要。

**3. 平滑数据分布。** 当前的 Q 决定怎么走，怎么走决定采到什么数据，数据又决定 Q，这是一个反馈环，可能来回振荡。缓冲区里混着很多个旧策略的数据，振荡被抹平了。

**代价**：缓冲区里是旧策略的数据，所以只有 off-policy 算法（Q-learning 一家：DQN、DDPG、TD3、SAC）能直接用。REINFORCE、A2C、PPO 这些 on-policy 算法不能用经验回放（第 25、27 课解释原因）。

**改进：优先回放**（Schaul 等 2016）：TD 误差大的样本说明"还没学会"，就多抽它们；为了不引入偏差，再用重要性权重修正。

### 23.6 DQN 整体

DQN（Mnih 等；2013 年 arXiv 版，2015 年 Nature 版）第一次让一个算法、一套超参数，直接从屏幕像素学会玩几十个 Atari 游戏。

| 组成 | 内容（凭记忆，Nature 版） |
|---|---|
| 输入 | 最近 4 帧 84×84 的灰度图 |
| 网络 | 3 层卷积 + 全连接层，输出每个动作的 Q（最多 18 个动作） |
| 经验回放 | 缓冲区 100 万条，每次抽 32 条，每 4 步更新一次 |
| 目标网络 | 每 10000 次更新同步一次 |
| 探索 | ε-贪心，ε 在前 100 万帧里从 1.0 线性降到 0.1 |
| 其他 | γ = 0.99；奖励截断到 [−1, 1]；RMSProp 优化器，学习率 0.00025 |
| 结果 | 49 个游戏，过半达到人类测试员 75% 以上的分数 |

训练循环：

1. 用 ε-贪心选动作，执行一步，把 (s, a, r, s′) 存进缓冲区；
2. 每 4 步，从缓冲区随机抽 32 条；
3. 用目标网络算标签 y = r + γ·max_{a′} Q_{w⁻}(s′, a′)（如果 s′ 是终点，y = r）；
4. 对 (Q_w(s, a) − y)² 做一步梯度下降；
5. 每 10000 次更新，令 w⁻ ← w。

### 23.7 DQN 之后的改进（2016–2018）

| 改进 | 年份 | 解决的问题 | 做法 |
|---|---|---|---|
| Double DQN | 2016 | 高估（第 24 课） | 用在线网络挑动作、目标网络估值 |
| 优先回放 | 2016 | 样本利用率 | 按 TD 误差的大小抽样 |
| Dueling DQN | 2016 | 很多状态下选哪个动作都差不多 | 网络分成 V(s) 和 A(s, a) 两支，Q = V + A |
| 多步回报 | — | 自举的偏差、信息往回传得慢 | 用 n 步回报当标签（第 22.3 节） |
| 分布式 RL（C51） | 2017 | 只学期望，丢了回报分布的信息 | 学回报的整个分布 |
| Noisy Nets | 2018 | ε-贪心的探索太笨 | 在网络权重上加可学习的噪声 |
| Rainbow | 2018 | — | 把上面 6 个合在一起，效果远好于任何一个单独的改进 |

（年份已核对，见附录 C 的 C17–C22。）

**DQN 一家的根本限制**：动作必须是离散的、个数不多，因为每一步都要对所有动作算 max。车辆的转角、油门是连续的，这引出第 25–28 课的策略方法。

## 第 24 课：高估、Double Q 和"取两个 critic 的较小值"

### 这一课要解决的问题

Q-learning 的目标里有一个 max，而 max 会系统性地高估。这一课讲高估从哪来、Double Q 怎样消除它、TD3 和 SAC 为什么干脆取两个 critic 的较小值，以及这为什么就是第 8.5 节说的"悲观"。

### 24.1 max 会高估：一个最小的例子

两个动作，真实价值都是 0。我们的估计带有噪声：每个估计 = 0 + 一个在 [−1, 1] 里均匀分布的误差。每个估计**单独看**都没有偏差，平均是 0。

但取 max 以后，max(估计 1, 估计 2) 的平均是 **+1/3 ≈ +0.333**（仿真 100 万次：+0.3330）。

原因：max 总是挑中"碰巧估高了"的那个。动作越多，越容易挑到估得特别高的：

| 动作个数 k | 2 | 5 | 10 | 100 |
|---|---|---|---|---|
| E[max] | 0.333 | 0.667 | 0.818 | 0.980 |

公式是 (k − 1)/(k + 1)。推导：k 个 [0, 1] 上均匀分布的数，最大值的平均是 k/(k + 1)（标准结果）；[−1, 1] 上的均匀分布等于"[0, 1] 上的均匀分布乘 2 再减 1"，所以平均是 2k/(k + 1) − 1 = (k − 1)/(k + 1)。

这在决策理论里叫**优化者的诅咒**（optimizer's curse，Smith 和 Winkler 2006）：从一堆有误差的估计里挑出最好的那个，事后看它往往没有估计的那么好。"挑选"这个动作本身制造了偏差。

**换成代价的语言**：MPC 在所有计划里找代价最低的。如果终端价值有误差，它会挑中"终端价值碰巧估低了"的计划。第 8.4 节 0.45 处的陷阱，就是这个效应的极端情况。

### 24.2 自举把高估一层层传下去

Q-learning 的标签 r + γ·max_{a′} Q(s′, a′) 里有一个 max，高估进入了标签；下一状态的 Q 又被用来更新上一个状态……高估沿着轨迹往回传，一层叠一层。理想化地算（每层都是独立的新噪声），每层加 0.333，γ = 0.99 时最多能叠到 0.333/(1 − 0.99) ≈ 33。这是理想化的上限估计，实际网络的误差会相关。Thrun 和 Schwartz（1993）最早分析了函数近似带来的高估。

**Sutton–Barto 书的例 6.7，自己重算了一遍：**

- 状态 A 有两个动作。往右：直接结束，奖励 0。往左：到状态 B，奖励 0。
- 状态 B 有 10 个动作，每个都直接结束，奖励服从均值 −0.1、标准差 1 的正态分布（书里说"很多个动作"，这里取 10 个）。
- 所以往左的真实价值是 −0.1，比往右的 0 差，应该往右。
- 用 ε = 0.1 的 ε-贪心，最优情况下在 A 处往左的比例只来自随机探索：0.1 × 0.5 = 0.05。

2000 次独立重复，α = 0.1，每局在 A 处选"往左"的比例：

| 第几局 | 1 | 5 | 10 | 20 | 50 | 100 | 300 |
|---|---|---|---|---|---|---|---|
| Q-learning | 0.494 | 0.683 | 0.874 | 0.941 | 0.813 | 0.472 | 0.126 |
| Double Q-learning（24.3 节） | 0.490 | 0.481 | 0.458 | 0.319 | 0.153 | 0.092 | 0.059 |
| 最优 | 0.05 | 0.05 | 0.05 | 0.05 | 0.05 | 0.05 | 0.05 |

Q-learning 在第 16 局达到峰值 0.947：几乎每局都往左走，明明往左更差。原因：B 有 10 个动作，max 对 10 个带噪声的估计取最大，早期明显为正，于是 Q(A, 左) 被推到 0 以上，看起来比往右好。要几百局以后，噪声被平均掉，才慢慢纠正。Double Q-learning 的峰值只有 0.522（第 2 局），之后很快下降。

### 24.3 Double Q-learning：挑和估分开

van Hasselt（2010）的想法：高估来自"用同一组估计既挑动作、又给这个动作估值"。那就用两组独立的估计 Q_A、Q_B：

> 更新 Q_A 时，目标 = r + γ·Q_B(s′, argmax_{a′} Q_A(s′, a′))

用 A 挑，用 B 估。B 的误差和"A 挑中了谁"无关，所以没有偏差。每次更新时随机选一组更新，两组轮流。

在 24.1 节的例子里：用 A 挑出看起来最好的动作，再看 B 对它的估计，平均 **+0.0002**，基本就是 0。

**Double DQN**（van Hasselt、Guez、Silver 2016）：DQN 本来就有两个网络，直接复用，在线网络挑、目标网络估：

> y = r + γ·Q_{w⁻}(s′, argmax_{a′} Q_w(s′, a′))

只改了一行代码，在 Atari 上明显减少了高估、提高了分数。

### 24.4 TD3：干脆取两个 critic 的较小值

连续动作的 actor-critic（第 28 课）也有高估。Fujimoto 等（2018，TD3 论文）发现：

- DDPG 的 critic 明显高估；
- 把 Double DQN 的办法搬过来效果有限：actor-critic 里策略变化很慢，在线网络和目标网络几乎一样，"挑"和"估"并不独立。

TD3 的做法：训练两个 critic Q₁、Q₂（随机初始化不同），两个都回归到同一个目标：

> y = r + γ·min(Q₁⁻(s′, a′), Q₂⁻(s′, a′))，a′ 由目标 actor 给出

这叫 **clipped double Q**（截断的双 Q）。

用 24.1 节的例子比较三种做法（a\* 是 A 认为最好的动作）：

| 动作个数 k | 2 | 5 | 10 | 100 |
|---|---|---|---|---|
| 单个估计取 max：E[A(a\*)] | +0.334 | +0.667 | +0.818 | +0.980 |
| Double Q：E[B(a\*)] | −0.001 | 0.000 | −0.001 | 0.000 |
| TD3：E[min(A(a\*), B(a\*))] | −0.167 | −0.048 | −0.016 | 0.000 |

（每格 40 万次仿真。k = 2 时 TD3 一格的精确值是 −1/6。）

TD3 是**故意低估**的。为什么宁可低估，也不要高估？因为两者不对称：

- **高估会自我强化**：actor 专门往 Q 高的地方走，被高估的动作正好被选中，它的高估又通过标签传给上一个状态；
- **低估不会自我强化**：被低估的动作 actor 不选，它就不会出现在标签里，误差不会被传下去。

TD3 的作者的说法是：被低估的动作不会通过策略更新被显式地传播。SAC 也用同样的"两个 critic 取较小值"（第 28 课）。

### 24.5 这为什么就是第 8.5 节的"悲观"

第 8.5 节说：RL 常见的应对是训练几个 critic，取最悲观的那个（对奖励取最小，对代价取最大）。现在可以把这句话讲完整。

**1. 换成代价的语言。** 奖励 = −代价，"对奖励取 min"就是"对代价取 max"：

> J_悲观(x) = max(J₁(x), J₂(x))

意思是：两个 critic 都说"这里便宜"，才相信这里便宜。

**2. 它对付陷阱的方式。** 第 8.4 节的学习单元 C 在 x = 0.45 处给出 J = 0.026，真实值 0.858，MPC 被吸过去。假设还有一个用不同数据或不同初始化训练的 critic D，它在 0.45 处没有这个错误（比如给出 0.7，这个数只是假设），那么 max(0.026, 0.7) = 0.7，坑被填上了。这正是 TD3 里发生的事：actor 想利用某个 critic 的错误，必须两个 critic 在同一个地方犯同样的错。

**3. 用 23.2 节的 400 个带噪声的 critic 做实验。** 每个 critic 的 p 都有约 1% 的随机误差。在例子一里，J = p·x² 是否诚实（TJ ≤ J）只取决于 p：

| p | 3.5 | 4.0 | 4.2 | 4.236 | 4.333 | 5 | 6 |
|---|---|---|---|---|---|---|---|
| TJ − J 的系数 T(p) − p | +0.611 | +0.200 | +0.031 | 0 | −0.083 | −0.667 | −1.571 |

p ≥ 4.236（悲观，对代价估高）就诚实；p < 4.236（乐观）就不诚实。把 400 个 critic 两两配成 200 对：

| 做法 | p 的平均 | 诚实（p ≥ p\*）的比例 |
|---|---|---|
| 单个 critic | 4.2332 | 47.5% |
| 两个取较悲观的（代价取 max） | 4.2553 | 70.5% |
| 两个取较乐观的（代价取 min） | 4.2111 | 24.5% |

取较悲观的那个，诚实的比例从 47.5% 升到 70.5%。

**4. 悲观的两个局限。**

- **共同的盲区挡不住**：如果两个 critic 用同样的数据训练（比如都只见过 |x| ≤ 0.3），它们在 0.45 处可能**都**外推得很低，取 max 还是低。取 max 只能消除"两个 critic 意见不同"的那部分误差。
- **好的估计也被压低**：k = 2 时，哪怕两个估计本身都没有偏差，取 min 也会系统性地偏低 0.167。在代价的语言里，就是 critic 系统性偏高，MPC 偏保守。

还要说明一点：在例子一的二次函数里，"悲观"恰好等价于"诚实"；一般情况下悲观并不保证诚实（例如 J 在当前状态附近不偏高、只在某些下一状态上偏高时，TJ 反而可能超过 J），所以仍然需要检验。

**5. 方向一走的是另一条路。**

| | 悲观（TD3/SAC 取较小值） | 检验（方向一） |
|---|---|---|
| 需要模型吗 | 不需要 | 需要（用模型算 TJ） |
| 额外的计算 | 多训练一个 critic | 每个学习单元在计划终点多解一个一步优化 |
| 对好的估计 | 也压低，浪费信息 | 照单全收 |
| 两个 critic 共同的盲区 | 挡不住 | 能挡住：检验用的是模型，和 critic 的训练数据无关 |
| 理论保证 | 没有 | 定理 1、定理 2 |

两者也可以结合：先取 max(J₁, J₂) 当一个学习单元，再做检验（第 30.2 节）。

### 24.6 更多的悲观：集成和离线 RL

（年份和发表处已核对，见附录 C 的 C26–C31。每条"做法"的一句话描述和各自的摘要一致，属于摘要级；REDQ 的"10 个、挑 2 个"这类具体设置凭记忆。）

- **REDQ**（Chen 等 2021）：训练 10 个 critic，每次随机挑 2 个取较小值。可以把每步数据的更新次数提得很高而不发散，样本效率高。
- **TQC**（Kuznetsov 等 2020）：每个 critic 学回报的分布，把所有 critic 的分位数放在一起，扔掉最高的几个再平均，比"取 min"更细地控制悲观的程度。
- **离线 RL**：只有一批固定的旧数据，不能再和环境交互。critic 在数据之外的动作上外推出的高值，没有新数据来纠正，所以离线 RL 最需要悲观：BCQ（2019）限制动作接近数据；CQL（Kumar 等 2020）在训练时专门压低数据外动作的 Q；TD3+BC（2021）在 TD3 上加一项"动作别离数据太远"；IQL（2022）完全不在数据外的动作上取 max。
- **和方向一的关系**：MPC 在计划终点 x_N 查询 critic，x_N 可能落在 critic 的训练数据之外。这和离线 RL 面对的**分布偏移**（使用时的输入落在训练数据的分布之外）是同一个问题。离线 RL 用悲观解决，方向一用模型检验解决。

## 第 25 课：直接学策略：策略梯度、REINFORCE 和基线

### 这一课要解决的问题

DQN 一家只能处理离散动作，而且策略由 argmax 决定，会突然跳变。能不能直接学策略本身？

### 25.1 为什么要直接学策略

价值方法的三个毛病：

1. **连续动作**：每一步都要对动作求 max。转角是连续的，求 max 本身就是一个优化问题。
2. **策略会跳变**：两个动作的 Q 是 1.00 和 1.01，选后者；更新一点点变成 1.00 和 0.99，就整个换成前者。参数的微小变化引起行为的突变，训练不稳定。
3. **有时最好的策略是随机的**：比如石头剪刀布；或者状态看不全的时候。

策略方法直接写一个带参数 θ 的策略 π_θ(a | s)：

- 两个动作：π(右) = σ(θ) = 1/(1 + e^{−θ})，π(左) = 1 − σ(θ)。θ = 0 时各占 0.5；θ 越大，越倾向往右；
- 连续动作：高斯分布 N(μ_θ(s), σ_θ(s)²)，网络输出均值和标准差。

参数变一点，概率就变一点，行为是平滑变化的。

### 25.2 策略梯度：怎样不用模型求导

目标：让期望回报 J(θ) = E[R] 最大。用双臂老虎机来推（只有一个状态，拉 1 号臂得 R₁，拉 0 号臂得 R₀，π(1 号臂) = σ(θ)）：

> J(θ) = σ(θ)·R₁ + (1 − σ(θ))·R₀

如果知道 R₁ 和 R₀，可以直接求导：∇J = σ′(θ)·(R₁ − R₀) = σ(1 − σ)·(R₁ − R₀)。但 RL 不知道 R₁、R₀，只能拉臂看结果。

**对数导数技巧**：因为 ∇log π = ∇π/π，所以 ∇π(a) = π(a)·∇log π(a)。于是

> ∇J = Σ_a ∇π(a)·R(a) = Σ_a π(a)·∇log π(a)·R(a) = E_{a∼π}[∇log π(a)·R(a)]

最后一个等号把"对所有动作求和"变成了"按策略抽样再平均"，不需要知道 R(a) 的公式：每拉一次臂，∇log π(a)·R(a) 就是梯度的一个样本。

对 σ 来说：∇log σ(θ) = 1 − σ，∇log(1 − σ(θ)) = −σ。

**数例**：θ = 0（π = 0.5），R₁ = 1，R₀ = 0。

- 拉到 1 号臂：样本 = (1 − 0.5) × 1 = **+0.5**；
- 拉到 0 号臂：样本 = (−0.5) × 0 = **0**；
- 平均 = 0.5 × 0.5 + 0.5 × 0 = 0.25，正好等于 σ(1 − σ)·(R₁ − R₀) = 0.25 × 1；方差 0.0625。

直观意思：**做了一个动作、回报高，就提高这个动作的概率，提高多少和回报成正比。**

推广到多步（策略梯度定理，Sutton 等 2000；REINFORCE，Williams 1992）：

> ∇J = E[ Σ_t ∇log π_θ(a_t | s_t)·G_t ]

G_t 是从第 t 步往后的回报。

### 25.3 方差问题和基线

**同样的差距，换个基准就完全不同。** 把奖励改成 R₁ = 101、R₀ = 100（差距还是 1）：

- 拉到 1 号臂：样本 = 0.5 × 101 = **+50.5**；
- 拉到 0 号臂：样本 = −0.5 × 100 = **−50**；
- 平均还是 0.25，但方差变成 **2525.06**，是原来的约 4 万倍。

每次估计要么是 +50.5、要么是 −50，正确的方向（平均 +0.25）被淹没在噪声里。

**基线**：把 R 换成 R − b，b 是任何不依赖动作的数。它不改变梯度的期望：

> E[∇log π(a)·b] = b·Σ_a π(a)·∇log π(a) = b·Σ_a ∇π(a) = b·∇(Σ_a π(a)) = b·∇1 = 0

所以减去 b 只改变方差，不引入偏差。取 b = 100.5：拉到 1 号臂，样本 0.5 × 0.5 = +0.25；拉到 0 号臂，样本 (−0.5) × (−0.5) = +0.25。方差变成 **0**。

**学习实验**（R₁ = 101、R₀ = 100，学习率 0.01，每步拉一次臂，共 200 步，2000 次重复）：

| | 最后 P(1 号臂) 的平均 | 最后 P(1 号臂) < 0.5 的比例（学反了） |
|---|---|---|
| 不用基线 | 0.511 | 49.0% |
| 基线 b = 100.5 | 0.620 | 0% |

不用基线时，将近一半的实验学反了方向。

**最好的基线**大约是"从这个状态出发的平均回报"，也就是 V(s)。这时 R − b 变成 Q(s, a) − V(s) = A(s, a)，也就是第 21.3 节的**优势函数**："好于平均就加概率，差于平均就减概率"。

### 25.4 REINFORCE 算法和它的问题

REINFORCE（Williams 1992）：

1. 用当前策略 π_θ 跑完一局，记下每一步的 (s_t, a_t, r_t)；
2. 算每一步的回报 G_t；
3. θ ← θ + 学习率 × Σ_t ∇log π_θ(a_t | s_t)·(G_t − b(s_t))；
4. 扔掉这局数据，回到第 1 步。

问题：

1. **方差大**：G_t 是 MC 回报（第 22.1 节），本来方差就大；
2. **必须跑完一局**才能更新；
3. **on-policy**：梯度公式里的期望是对**当前**策略取的。策略一更新，旧数据就不再是"当前策略的样本"，只能扔掉，数据利用率很低。

前两个问题由 critic 解决（第 26 课），第三个问题由重要性采样部分解决（第 27 课）。

## 第 26 课：Actor-critic：critic 怎样帮 actor

### 这一课要解决的问题

REINFORCE 的方差太大，而且要等一局结束。用一个学出来的价值函数（critic）来估计优势，能把方差降下来，还能走几步就更新。

### 26.1 actor 和 critic 的分工

- **actor**：策略 π_θ，负责选动作；
- **critic**：价值函数 V_φ（用第 22 课的 TD 方法学），负责给 actor 的动作打分，也就是估计优势。

最早的 actor-critic 是 Barto、Sutton 和 Anderson 1983 年做的倒立摆控制。

优势的几种估法：

| 估法 | 公式 | 偏差 | 方差 |
|---|---|---|---|
| MC 回报（REINFORCE） | G_t | 无 | 最大 |
| MC 回报减基线 | G_t − V(s_t) | 无 | 中 |
| TD 误差 | δ_t = r_t + γ·V(s_{t+1}) − V(s_t) | V 不准时有 | 最小 |
| GAE（第 27.5 节） | δ_t + (γλ)·δ_{t+1} + (γλ)²·δ_{t+2} + … | 介于两者之间 | 介于两者之间 |

为什么 TD 误差可以当优势：如果 V 就是 V^π，那么

> E[δ_t | s_t, a_t] = r_t + γ·E[V^π(s_{t+1})] − V^π(s_t) = Q^π(s_t, a_t) − V^π(s_t) = A(s_t, a_t)

**数例：四种估法的方差。** 走廊，随机策略 π(右) = 0.7（θ = ln(0.7/0.3)），γ = 0.9，从 0 出发。先解一个线性方程组，求出这个策略的真实价值（每个状态满足 V(s) = −1 + 0.9 × [0.7·V(s + 1) + 0.3·V(左边一格)]）：

> V^π = (−5.373, −4.639, −3.473, −1.938, 0)

critic 就用这个真实的 V^π。跑 10 万局，每局算一个梯度估计 Σ_t ∇log π(a_t | s_t)·Ψ_t（往右时 ∇log π = 0.3，往左时 −0.7）：

| Ψ_t 用什么 | 梯度估计的平均 | 标准差 |
|---|---|---|
| G_t | +3.137 | 8.61 |
| G_t − V(s_t) | +3.149 | 3.72 |
| GAE，λ = 0.95 | +3.148 | 3.36 |
| δ_t（相当于 λ = 0） | +3.146 | 2.82 |

四种的平均一样（都无偏，差别在仿真误差 ±0.03 以内），标准差从 8.61 降到 2.82，降了三分之二。标准差降到三分之一，要达到同样的精度，需要的样本数就降到约九分之一。这就是 critic 对 actor 的帮助。梯度为正，说明增大 θ（更多地往右走）能提高回报。

注意：这里的 critic 是精确的。critic 不准时 δ_t 会有偏差，这正是第 27.5 节 GAE 要权衡的地方。

### 26.2 训练：两个损失函数

每采一批数据：

- **critic 的损失**：(V_φ(s_t) − y_t)²，y_t = r_t + γ·V_φ(s_{t+1})（或者 n 步回报、λ 回报）。这是回归，和第 23 课一样。
- **actor 的损失**：−Σ_t log π_θ(a_t | s_t)·Â_t。Â_t 是 critic 算出来的优势，求导时当作常数。让这个损失变小，就是沿着第 25 课的策略梯度往上走。
- **熵奖励**：再加一项 −β·H(π(· | s_t))，鼓励策略保持一定的随机性，防止过早地变成确定性策略、不再探索。H 是熵，第 28.5 节解释。

### 26.3 A3C 和 A2C：用并行代替经验回放

A3C（Mnih 等，ICML 2016；下面的线程数、步数凭记忆）：16 个 CPU 线程，各自在一个环境副本里跑，每跑 5 步算一次 n 步优势、更新共享的参数，彼此异步进行。A2C 是它的同步版本：所有环境一起跑 n 步，拼成一批，一起更新。效果差不多，实现更简单。

为什么要并行：on-policy 不能用经验回放来打破相关性（第 23.5 节），那就同时跑很多个环境，同一时刻的样本来自不同的环境，彼此不相关。

### 26.4 一个重要的区别：critic 只要"够当基线"就行

在 actor-critic 里，critic 的唯一任务是给优势提供一条参考线，降低方差。它不准，只会让方差大一些（或带来一点偏差），不会直接让动作变差。

方向一里的终端价值不一样：它直接决定 MPC 选哪个计划，准不准直接影响行为和保证。

所以：**A2C、PPO 训练出来的 critic，本来就不是为了"处处准确"而训练的**。直接拿来当终端价值之前，必须检验（第 30 课）。

## 第 27 课：TRPO 与 PPO：步子迈多大；PPO 的价值函数与 GAE

### 这一课要解决的问题

策略梯度给出了方向，但没说步子该迈多大。迈大了，策略被毁；迈小了，学得太慢，而且数据只能用一次。TRPO 和 PPO 解决步长问题；PPO 再配上 critic 和 GAE，成为今天最常用的算法。

### 27.1 步子太大会怎样

on-policy 方法有一个特别的危险：数据来自当前策略。如果某一步更新把策略改坏了，下一批数据就是坏策略采的，可能再也学不回来。

而且**参数空间的一步**和**策略空间的一步**不是一回事：

| 参数的变化 | 策略的变化 | 两个策略的差异（KL 散度） |
|---|---|---|
| θ 从 0 到 1 | σ 从 0.5 到 0.731，变了 0.231 | 0.1201 |
| θ 从 4 到 5 | σ 从 0.982 到 0.993，变了 0.011 | 0.0066 |

同样是 θ 加 1，两种情况下策略的差异相差 18 倍。按参数定步长，在不同的地方效果完全不同。

**KL 散度**：衡量两个概率分布差多少的量。两个"二选一"的分布（选第一项的概率分别是 p 和 q）之间：

> KL(p‖q) = p·ln(p/q) + (1 − p)·ln((1 − p)/(1 − q))

例：KL(0.5‖0.6) = 0.5 × ln(0.5/0.6) + 0.5 × ln(0.5/0.4) = 0.5 × (−0.1823) + 0.5 × 0.2231 = **0.0204**。两个分布完全相同时 KL = 0，差得越多越大。

### 27.2 重要性采样：用旧策略的数据评价新策略

想用旧策略 π_old 采的数据，估计新策略 π_new 的期望回报。办法是给每个样本乘一个权重 r = π_new(a)/π_old(a)，叫**重要性权重**或**概率比**：

> E_{π_new}[R] = E_{π_old}[(π_new(a)/π_old(a))·R]

数例：旧策略拉 1 号臂的概率是 0.5，新策略是 0.6。1 号臂样本的权重是 0.6/0.5 = 1.2，0 号臂样本的权重是 0.4/0.5 = 0.8。按旧策略平均：0.5 × 1.2 × R₁ + 0.5 × 0.8 × R₀ = 0.6R₁ + 0.4R₀，正好是新策略的期望回报。

于是可以定义一个**替代目标**：

> L(θ) = E_{π_old}[ r_t(θ)·Â_t ]，r_t(θ) = π_θ(a_t | s_t)/π_old(a_t | s_t)

它在 θ = θ_old 处的梯度就是策略梯度。但它只在新旧策略接近时可信：策略变了，访问到的状态也会跟着变，而这个公式没有考虑这一点。

### 27.3 TRPO：给步子划一个圈

TRPO（Schulman 等 2015）：

> 最大化 L(θ)，约束：平均的 KL(π_old ‖ π_θ) ≤ δ（δ 取 0.01）

在 KL 的意义下规定"每步最多变多少"，不管在参数空间的哪里，步子的实际效果都一样。理论来源是 Kakade 和 Langford 2002 年的结果：在这样的约束下，每一步的改进有下界，策略单调变好（在理论的假设下）。

数例：从 π = 0.5 出发，KL ≤ 0.01 只允许改到 **0.570**。

缺点：要解带约束的优化（自然梯度、共轭梯度、线搜索），实现复杂，和一些网络结构（actor 和 critic 共享参数、dropout）配合不好。

### 27.4 PPO：用裁剪代替约束

PPO（Schulman 等 2017）不加约束，而是直接改目标函数：

> L^CLIP(θ) = E[ min( r_t·Â_t, clip(r_t, 1 − ε, 1 + ε)·Â_t ) ]，ε = 0.2

clip(r, 0.8, 1.2) 把概率比限制在 [0.8, 1.2] 里。四种情况逐个看：

| 优势 Â | 概率比 r | 不裁剪 r·Â | 裁剪后 | 取 min | 含义 |
|---|---|---|---|---|---|
| +1 | 1.5 | +1.5 | +1.2 | **+1.2** | 好动作的概率已经涨了 50%，收益最多按涨 20% 算，不再继续推 |
| +1 | 0.7 | +0.7 | +0.8 | **+0.7** | 好动作的概率反而降了，按不裁剪的算，梯度照常把它推回去 |
| −1 | 0.5 | −0.5 | −0.8 | **−0.8** | 坏动作的概率已经降了一半，惩罚封顶，不再继续压 |
| −1 | 1.4 | −1.4 | −1.2 | **−1.4** | 坏动作的概率反而涨了，按更坏的那个算，全额惩罚 |

规律：**往好的方向走，收益封顶；往坏的方向走，损失全算。** 取 min 让目标成为真实改进的一个**悲观下界**。这和第 24 课"取两个 critic 的较小值"是同一种思想：宁可低估收益，也不要被高估骗。

封顶以后，概率比超出 [0.8, 1.2] 的样本梯度为 0，策略自然不会离旧策略太远。这样就可以在同一批数据上训练好几轮（epoch），数据利用率比 REINFORCE 高。

**数例：为什么一定要裁剪。** 双臂老虎机，1 号臂奖励的均值 1.0，0 号臂 0.5，都带标准差 1 的噪声，所以 1 号臂更好。每批拉 16 次，优势 = 奖励 − 这批的平均奖励；在同一批数据上做 10 轮梯度上升（学习率 2）；共 30 批；2000 次重复。

| | 第 1 批之后 P(1 号臂) 的 5% / 50% / 95% 分位数 | 30 批之后 P(1 号臂) 的平均 | 卡在差的臂上（P < 0.1）的比例 |
|---|---|---|---|
| 不裁剪 | 0.173 / 0.859 / 0.955 | 0.917 | 7.0% |
| 裁剪（ε = 0.2） | 0.397 / 0.590 / 0.690 | 0.977 | 0% |

不裁剪时，一批 16 个带噪声的样本，就能把策略从 0.5 推到 0.96 或者 0.17。推错了方向的，之后几乎只拉差的那个臂，好臂的样本越来越少，再也学不回来（7% 卡死）。裁剪以后，每批最多改 20% 左右，偶尔推错了方向，下一批也能改回来。

### 27.5 PPO 的价值函数和 GAE

你问的"PPO 著名的价值函数"，指的就是 PPO 里的 critic V_φ(s)，以及配套的 GAE。

**它是什么**：V_φ(s) 估计"从状态 s 出发、按**当前**策略走下去，折扣回报的期望"，也就是 V^π，不是 V\*。

**它的唯一用途**：给优势提供基线。PPO 选动作完全靠 actor，critic 不参与选动作。这一点和 DQN 的 Q 完全不同。

**怎样用它算优势：GAE**（广义优势估计，Schulman 等 2016）：

> Â_t = δ_t + (γλ)·δ_{t+1} + (γλ)²·δ_{t+2} + …，δ_t = r_t + γ·V(s_{t+1}) − V(s_t)

实际计算时从后往前递推：Â_t = δ_t + γλ·Â_{t+1}，最后一步 Â = δ。

**手算**：一局 3 步，每步奖励 −1，γ = 0.9。critic 给出的 V = (−2.5, −1.8, −0.9)，不太准（真实值是 −2.71、−1.9、−1.0）；终点的 V = 0。

第一步，算三个 TD 误差：

- δ₀ = −1 + 0.9 × (−1.8) − (−2.5) = −1 − 1.62 + 2.5 = **−0.12**；
- δ₁ = −1 + 0.9 × (−0.9) − (−1.8) = −1 − 0.81 + 1.8 = **−0.01**；
- δ₂ = −1 + 0.9 × 0 − (−0.9) = **−0.1**。

第二步，按不同的 λ 从后往前递推：

- λ = 0：Â = δ = (−0.12, −0.01, −0.1)；
- λ = 0.5（γλ = 0.45）：Â₂ = −0.1；Â₁ = −0.01 + 0.45 × (−0.1) = −0.055；Â₀ = −0.12 + 0.45 × (−0.055) = **−0.1448**；
- λ = 0.95（γλ = 0.855）：Â₂ = −0.1；Â₁ = −0.01 + 0.855 × (−0.1) = −0.0955；Â₀ = −0.12 + 0.855 × (−0.0955) = **−0.2017**；
- λ = 1（γλ = 0.9）：Â₂ = −0.1；Â₁ = −0.01 + 0.9 × (−0.1) = −0.1；Â₀ = −0.12 + 0.9 × (−0.1) = **−0.21**。

λ = 1 时，Â₀ = −0.21 = G₀ − V(s₀) = (−1 − 0.9 − 0.81) − (−2.5)，就是 MC 回报减基线，完全不依赖 critic 准不准。λ = 0 时完全依赖 critic。

critic 的训练目标 V_target = Â + V：

| λ | V_target(s₀, s₁, s₂) | 是什么 |
|---|---|---|
| 0 | (−2.62, −1.81, −1.0) | TD 目标 r + γ·V(s′) |
| 0.5 | (−2.645, −1.855, −1.0) | — |
| 0.95 | (−2.702, −1.896, −1.0) | PPO 的默认 |
| 1 | (−2.71, −1.9, −1.0) | MC 回报，等于真实值 |

**λ 怎么选：偏差和方差的权衡。** 打滑走廊（往右成功率 0.8），一直往右，critic 比真实值乐观 20%（V̂ = 0.8 × V^π）。用 λ 回报 V̂(s₀) + Â₀ 估计 V(0)，真值 −4.0561，10 万局：

| λ | 估计的平均 | 偏差 | 标准差 |
|---|---|---|---|
| 0 | −3.445 | +0.611 | 0.238 |
| 0.5 | −3.600 | +0.456 | 0.279 |
| 0.9 | −3.923 | +0.134 | 0.510 |
| 0.95 | −3.987 | +0.070 | 0.574 |
| 1 | −4.058 | −0.002 | 0.651 |

λ 小：方差小，但 critic 的错误直接带进来。λ = 0 的偏差 +0.611，正好是 critic 在下一状态上的误差乘以 γ：0.9 × 0.2 × 3.396 = 0.611（3.396 是下一状态真实价值绝对值的平均）。λ 大：不依赖 critic，没有偏差，但方差大。λ = 0.95 是常用的折中：偏差只剩 0.07，标准差比 λ = 1 小 12%。

**critic 的损失和 PPO 的总损失**：

> L = −L^CLIP + c₁·(V_φ(s_t) − V_target_t)² − c₂·H(π_θ(· | s_t))

c₁ 取 0.5 或 1；c₂ 是熵奖励的系数，Atari 取 0.01，连续控制常取 0（凭记忆）。

**几个实现细节**（凭记忆，来自 PPO 的开源实现和后来的大规模实验）：

- **优势归一化**：每个小批里，把 Â 减去均值、除以标准差，让学习率不受奖励尺度的影响。
- **价值裁剪**：critic 的更新也像策略一样裁剪：V_clipped = V_old + clip(V − V_old, −ε, ε)，损失取两种平方误差的较大者。后来的大规模实验（Engstrom 等 2020，Andrychowicz 等 2021）发现它基本没有帮助，有时有害。
- **actor 和 critic 共享网络还是分开**：共享省计算，但两个损失会互相干扰；连续控制里通常分开。
- 观测归一化、奖励缩放、正交初始化等。"PPO 的 37 个实现细节"这篇博客（Huang 等 2022）专门整理了这些。

### 27.6 PPO 的完整训练循环

1. 用当前策略在 N 个并行环境里各跑 T 步（连续控制常用 1 个环境 × 2048 步，Atari 用 8 × 128；凭记忆）；
2. 用当前的 critic 算每一步的 δ_t 和 GAE 优势 Â_t，以及 V_target = Â + V；
3. 记下 π_old(a_t | s_t)；
4. 在这批数据上训练 K 轮（连续控制 10 轮，Atari 3–4 轮）：每轮打乱、分成小批（连续控制每批 64 条），用 Adam（学习率 3e−4）对总损失 L 做梯度下降；
5. 扔掉这批数据，回到第 1 步。

PPO 论文在连续控制任务上的默认值（凭记忆）：γ = 0.99，λ = 0.95，ε = 0.2，学习率 3e−4，T = 2048，10 轮，小批 64。

**为什么 PPO 成了默认选择**：

- 只用一阶梯度，几十行代码就能实现；
- 对超参数不太敏感；
- 离散、连续动作都能用，容易大规模并行；
- 用在了 OpenAI Five（Dota 2）、大量的仿真机器人训练（用成千上万个并行环境训练足式机器人走路），以及大语言模型的 RLHF。

**PPO 的缺点**：on-policy，每批数据训练几轮就扔，样本效率低，通常要几百万到几十亿步。仿真里便宜，真车、真机器人上就太贵了。这是第 28 课 off-policy 方法的动机。

### 27.7 PPO 在大语言模型里：RLHF

InstructGPT（Ouyang 等 2022）用 PPO 训练语言模型，这叫 RLHF（基于人类反馈的强化学习）。对应关系：

| RL 的概念 | 在语言模型里 |
|---|---|
| 状态 | 题目 + 已经生成的文字 |
| 动作 | 下一个词（token） |
| 一局 | 生成一个完整的回答 |
| 奖励 | 回答结束时，奖励模型（用人类的偏好比较数据训练出来）给的分数；每个词再减一项 β·log(π_θ/π_ref)，不让模型离原来的模型太远 |
| critic | 价值模型 V(已经写出的部分)："写到这里，最后大概能得多少分" |

训练时显存里要放四个模型：策略、参考策略、奖励模型、价值模型。价值模型通常和策略一样大，开销很大。

### 27.8 GRPO：去掉 critic

GRPO（Shao 等 2024，DeepSeekMath；后来用在 DeepSeek-R1）的做法：同一个题目让模型回答一组（DeepSeekMath 里是 64 个，凭记忆），每个回答的优势 = (它的奖励 − 这组的平均奖励) ÷ 这组的标准差。其他部分（裁剪、KL 项）沿用 PPO。

数例：

- 4 个回答，奖励 (1, 0, 0, 1)：平均 0.5，标准差 0.5，优势 (+1, −1, −1, +1)；
- 4 个回答，奖励 (1, 0, 0, 0)：平均 0.25，标准差 0.433，优势 (+1.732, −0.577, −0.577, −0.577)。只有一个答对时，答对的那个得到很大的正优势。

（这里的标准差按总体标准差算；不同实现可能用样本标准差，数值略有不同。）

这就是第 25.3 节的基线：**用同一个状态下多次采样的平均当基线，代替 critic。**

**为什么语言模型可以去掉 critic，而控制里不行**：语言模型可以无数次回到"同一个题目"，从完全相同的状态重新采样 64 次；真实的车不可能回到完全相同的状态，试 64 种开法再比较。所以对真实的物理系统，要么用 critic，要么用模型（仿真器）来"回到同一个状态"。后者正是 MPC 在做的事：用模型从当前状态出发，试很多种计划。

同一条思路上还有 RLOO（Ahmadian 等 2024，用"除了自己以外其他回答的平均"当基线）；DPO（Rafailov 等 2023）更进一步，在偏好数据上完全不用 RL。

## 第 28 课：连续动作的 off-policy 方法：DDPG、TD3、SAC

### 这一课要解决的问题

到第 27 课为止有两条路，各缺一块：

| | 能处理连续动作吗 | 能用旧数据（off-policy、经验回放）吗 |
|---|---|---|
| DQN 一家（第 23、24 课） | 不能：每一步都要对所有动作取 max | 能 |
| PPO 一家（第 25–27 课） | 能 | 不能：一批数据训练几轮就扔，要几百万步 |

车辆、机器人的控制量是连续的，真车、真机器人上的数据又很贵，两样都要。这一课的三个算法就是把两块拼起来：

- **DDPG**（2016）：像 DQN 一样学一个 Q，再学一个确定性的 actor 专门去"求 Q 的最大值"；
- **TD3**（2018）：给 DDPG 打三个补丁，对付高估和不稳定；
- **SAC**（2018）：换成随机策略，并在目标里加上"保持随机"的奖励（熵），探索更好、训练更稳。

今天连续控制里最常用的 off-policy 算法就是 TD3 和 SAC。方向一阶段 1 计划里的"换成 SAC critic"（`CLAUDE.md` 下一步 5a），用的就是这一课的东西。

### 28.1 想法：用一个网络代替"求 max"

DQN 选动作：a = argmax_a Q(s, a)。Atari 最多 18 个动作，挨个算一遍就行。动作连续时（比如前轮转角可以是 [−0.014, 0.014] rad 里的任意数），每一步求 max 本身就是一个优化问题；训练时，每个样本的标签 r + γ·max_{a′} Q(s′, a′) 里还要再求一次。一批 256 个样本，就是 256 个优化问题。

DDPG 的想法：再训练一个网络 μ_θ(s)，专门负责输出"让 Q 最大的那个动作"。

- 选动作：a = μ_θ(s)，一次前向计算，不用解优化问题；
- 标签：把 max_{a′} Q(s′, a′) 换成 Q(s′, μ_θ(s′))，即 y = r + γ·Q(s′, μ_θ(s′))。

actor 成了一个"学出来的求 max 器"。μ 是**确定性**的：同一个状态总给同一个动作（第 25 课的策略是随机的，给的是一个概率分布）。

换成代价的语言：actor 负责"求 Q 的最小值"。和 MPC 对照：MPC 每一步现场解一个优化问题；DDPG 的 actor 相当于把"这个优化问题的解"背了下来，以后查表一样直接给出。这句话第 28.10 节和第 29、30 课还会用到。

### 28.2 确定性策略梯度：链式法则

actor 怎么训练？目标是让 actor 给出的动作在 critic 眼里尽量好：

> 最大化 J(θ) = E_s[ Q(s, μ_θ(s)) ]（代价语言：最小化）

E_s 表示对状态取平均，状态从回放缓冲区里抽。求导就是链式法则，这叫**确定性策略梯度定理**（deterministic policy gradient，DPG；Silver 等 2014）：

> ∇_θ J = E_s[ ∂Q/∂a(s, a)|_{a = μ_θ(s)} · ∂μ_θ(s)/∂θ ]

两项各管一件事：

- ∂Q/∂a：critic 告诉 actor"动作往哪边挪一点，Q 会变好"；
- ∂μ/∂θ：actor 自己算"参数怎么改，动作才会往那边挪"。

和第 25 课比：那里不知道回报 R 对动作 a 的导数，只能用对数导数技巧，靠"多试几次、看结果"估计梯度，方差很大；这里有一个可以求导的 critic，可以直接对动作求导。代价是：梯度的好坏完全取决于 critic 的斜率准不准（下面的第二张表）。

**数例：例子一（代价语言）。** critic 先用真实的 Q\*（第 23.1 节）：

> Q\*(x, u) = 17.944x² + 16.944xu + 5.236u²

actor 是线性的：u = μ_k(x) = −k·x，参数只有一个 k。按链式法则：

- ∂Q/∂u = 16.944x + 2 × 5.236u = 16.944x + 10.472u；
- ∂μ/∂k = −x；
- 代入 u = −kx：dQ/dk = (16.944x − 10.472kx) × (−x) = −x²·(16.944 − 10.472k)。

状态在 [−1, 1] 上均匀分布，E[x²] = 1/3，所以平均梯度是 −(16.944 − 10.472k)/3。代价要最小，沿负梯度走，步长 η = 0.1：

> k ← k − 0.1 × [−(16.944 − 10.472k)/3] = k + 0.1 × (16.944 − 10.472k)/3

从 k = 0 开始。第 1 步：k = 0 + 0.1 × 16.944/3 = 0.5648。第 2 步：k = 0.5648 + 0.1 × (16.944 − 10.472 × 0.5648)/3 = 0.5648 + 0.1 × 11.0295/3 = 0.9325。以此类推：

| 第几步 | 1 | 2 | 3 | 5 | 10 | 15 | 20 |
|---|---|---|---|---|---|---|---|
| k | 0.5648 | 0.9325 | 1.1718 | 1.4289 | 1.5959 | 1.6155 | 1.6177 |
| 闭环总代价系数 | 发散 | 发散 | 7.557 | 4.514 | 4.239 | 4.2361 | 4.2361 |

**闭环总代价系数怎么来的**（第 2.5 节推导过，这里再写一遍）：u = −kx 时 x⁺ = (2 − k)·x，每步代价 x² + k²x² = (1 + k²)·x²，下一步状态乘 (2 − k)、代价乘 (2 − k)²，所以总代价 = (1 + k²)·x²·[1 + (2 − k)² + (2 − k)⁴ + …] = (1 + k²)/(1 − (2 − k)²)·x²，要求 |2 − k| < 1，否则发散。验算：k = 1.5 时 3.25/0.75 = 4.333，正是单元 B（"每步减半"）；k = 1.618 时 3.618/0.854 = 4.236，正是 J\*。

从表里看三件事：

1. 收敛到 k = 16.944/10.472 = **1.618**，就是 LQR 增益。梯度为 0 的地方就是 ∂Q/∂u = 0，也就是第 23.1 节"对 u 求导令其为 0"。actor 学到的就是 critic 的 argmin。
2. 每步误差缩小到原来的 1 − 0.1 × 10.472/3 = **0.651** 倍（误差 k − 1.618 的系数）。
3. 前两步 k < 1，闭环系数 2 − k > 1，系统还在发散。**训练过程中的 actor 不一定能用**，要等它收敛。

换成更像实际训练的做法：从 500 个状态里每次随机抽 32 个算平均梯度（像从回放缓冲区抽小批），走 200 步，也收敛到 1.618（已验证）。

**critic 不准时，actor 忠实地执行错误。** 把 critic 换成第 23.2 节拟合 Q 迭代前几轮的结果（还没收敛的 critic），actor 照样收敛到这个 critic 的 argmin，k = w₁/(2w₂)：

| critic（拟合 Q 迭代第几轮） | w = (w₀, w₁, w₂) | actor 学到的 k | critic 声称的代价系数 | 实际闭环代价系数 |
|---|---|---|---|---|
| 第 2 轮 | (5, 4, 2) | 1.0 | 3.0 | ∞（x⁺ = x，永远不收敛） |
| 第 3 轮 | (13, 12, 4) | 1.5 | 4.0 | 4.333 |
| 第 4 轮 | (17, 16, 5) | 1.6 | 4.2 | 4.238 |
| 第 5 轮 | (17.8, 16.8, 5.2) | 1.6154 | 4.2308 | 4.2361 |
| 真值 | (17.944, 16.944, 5.236) | 1.618 | 4.2361 | 4.2361 |

"critic 声称的代价系数"就是 min_u Q_w 的系数 w₀ − w₁²/(4w₂)（第 23.2 节的"隐含的 p"）。

第 2、3 轮的 critic 都**低估了代价**（声称 3.0、4.0，实际 ∞、4.333），actor 被它们说服了：第 2 轮的 critic 让 actor 学出了一个根本稳不住系统的控制律，而 critic 还声称总代价只有 3x²。这和第 8.4 节 MPC 被学习价值骗进 0.45 的坑是同一件事：

> **一个优化器面对一个学出来的函数，会把这个函数的错误当真。**

actor 是用梯度做优化，MPC 是用模型加求解器做优化，被骗的方式一样。后面 TD3 的三个改动、SAC 的熵、方向一的检验，都是在对付这件事。

**为什么 DPG 天然是 off-policy 的。** 看两个网络各自用到数据里的什么：

- actor 的梯度公式里只有状态 s，**不用数据里记录的动作**：动作是 actor 现场给出的 μ_θ(s)；
- critic 学 Q^μ 用的是第 21.4 节表格第二行（Q^π 的 Bellman 方程），下一步动作由 μ(s′) 给出。数据里的 (s, a, r, s′) 只用来告诉它"在 s 做 a，得到 r、到 s′"，和这个 a 是谁选的无关，和 Q-learning 一样。

所以回放缓冲区里旧策略的数据可以直接用，**不需要第 27.2 节的重要性权重**。严格地说，梯度公式里状态的分布应该是"当前策略访问到的状态"，用缓冲区里的旧状态是一种近似；实际中效果很好（Degris 等 2012、Silver 等 2014 讨论过这一点，凭记忆）。

### 28.3 DDPG：DQN 的两招 + 确定性策略梯度

DDPG（Deep Deterministic Policy Gradient；Lillicrap 等，2015 年 arXiv，2016 年 ICLR）= 确定性策略梯度 + 第 23 课 DQN 的经验回放和目标网络。actor 和 critic 各有一个目标网络。

**训练循环**：

1. 选动作 a = μ_θ(s) + 探索噪声，执行一步，把 (s, a, r, s′) 存进回放缓冲区；
2. 从缓冲区随机抽一小批；
3. **critic**：标签 y = r + γ·Q_{w⁻}(s′, μ_{θ⁻}(s′))，用目标 critic 和目标 actor 算；对 (Q_w(s, a) − y)² 做一步梯度下降；
4. **actor**：对 −Q_w(s, μ_θ(s)) 做一步梯度下降。这就是 28.2 节的链式法则，用深度学习框架的自动求导，一行代码就完成；
5. **软更新**两个目标网络：w⁻ ← (1 − τ)·w⁻ + τ·w，θ⁻ ← (1 − τ)·θ⁻ + τ·θ（第 23.4 节）。

| 组成 | DDPG 论文里的设置（凭记忆） |
|---|---|
| 网络 | 两层隐藏层，400 和 300 个神经元 |
| 学习率 | actor 1e−4，critic 1e−3（critic 另加 0.01 的权重衰减） |
| 软更新 τ | 0.001（每 693 步差距减半，第 23.4 节） |
| 小批 | 64 |
| 缓冲区 | 100 万条 |
| γ | 0.99 |
| 探索噪声 | OU 过程，θ = 0.15，σ = 0.2 |

**探索噪声为什么要专门讲。** 确定性策略自己不探索：同一个状态永远给同一个动作，没试过的动作永远不会试。所以执行时要加噪声。DDPG 用的是 **OU 噪声**（Ornstein–Uhlenbeck 过程），按"每一步保留上一步噪声的 85%，再加一点新的随机数"生成：

> ε_{t+1} = (1 − 0.15)·ε_t + 0.2·N(0, 1)

（这里把时间步长取为 1；各家实现里时间步长的取法不同，下面的数只用来说明"前后相关的噪声"这个概念。）

- 长期标准差：设平稳时方差是 s²，则 s² = 0.85²·s² + 0.2²，s = 0.2/√(1 − 0.85²) = 0.2/0.527 = **0.380**；
- 相邻两步的相关系数 0.85，隔 10 步还有 0.85¹⁰ = 0.197；
- 连续 10 步噪声的平均值，标准差 **0.301**；同样大小的独立噪声（白噪声），10 步平均只有 0.380/√10 = **0.120**。

（10 步平均的标准差的算法：平均值的方差 = (s²/100)·Σ_i Σ_j 0.85^{|i−j|}，i、j 从 0 到 9。）

意思是：OU 噪声会**连着几步往同一个方向推**。对有惯性的系统（力 → 速度 → 位置），这样的推法能把系统推得更远：一个二重积分器（v⁺ = v + ε，x⁺ = x + v）被噪声推 20 步，OU 噪声下位置的标准差是 56.2，同样大小的白噪声下是 20.3，相差 2.8 倍（已验证，20 万次仿真，噪声从平稳分布开始）。

对车辆的直观意义：每一步随机抖一下方向盘，正负抵消，车几乎不偏；连着几步往一边打，车才真的偏到另一条线上，才能"看到"那边是什么样。

不过 TD3 的作者发现（凭记忆），在常用的连续控制测试任务里，简单的独立高斯噪声 N(0, 0.1²)（动作范围归一化到 [−1, 1]）效果不比 OU 差，之后大家多用高斯噪声。

**DDPG 的三个问题**：

1. **高估**：actor 专门找 critic 打分高的动作，第 24 课的"优化者的诅咒"在这里一样存在；标签里用的 Q(s′, μ(s′)) 正是 actor 挑出来的"critic 认为最好的"那个，高估一层层传回去。TD3 论文测到 DDPG 的 critic 明显高估（凭记忆）。
2. **对超参数和随机种子很敏感**：同样的设置、不同的随机种子，有的学会、有的学崩。
3. **actor 会钻 critic 的"尖峰"**：critic 在某个很窄的动作区间里估错、冒出一个尖峰，actor 的梯度就会把它往尖峰上拉（28.4 节改动三的例子）。

### 28.4 TD3：三个改动

TD3（Twin Delayed DDPG；Fujimoto、van Hoof、Meger 2018，ICML）在 DDPG 上做了三个改动。名字里的 Twin（双）指改动一，Delayed（延迟）指改动二。

**改动一：两个 critic 取较小值（clipped double Q）。** 第 24.4 节已经讲过：训练两个 critic Q₁、Q₂（随机初始化不同），两个都回归到同一个标签，标签用两个目标 critic 的较小值：

> y = r + γ·min(Q₁⁻(s′, a′), Q₂⁻(s′, a′))

actor 只用 Q₁ 求梯度。效果是故意偏向低估（奖励语言），因为低估不会被 actor 利用、不会自我强化（第 24.4 节的不对称性）。

**改动二：延迟更新 actor。** critic 每一步都更新；actor 和三个目标网络每 d = 2 步才更新一次。

理由和第 23.4 节的目标网络一样：**让被追的东西慢一点**。

- actor 是对着 critic 求梯度的。critic 刚更新完、还带着很大误差时就让 actor 跟着改，actor 会追着 critic 的误差跑；
- actor 一改，critic 要估计的 Q^μ 也跟着变了（μ 变了），critic 的误差又变大；
- 两者互相追，就可能越追越偏。让 critic 多更新几次、误差降下来再改 actor，这个循环就稳一些。

TD3 论文里的说法（凭记忆）：策略固定时，critic 的估计收敛得很好；策略和 critic 每步同时更新时，估计会大幅波动甚至发散；延迟更新 actor 能减少这种情况。延迟 2 步是一个折中：再长，actor 学得太慢。

**改动三：目标策略平滑（target policy smoothing）。** 算标签时，下一步的动作不直接用目标 actor 的输出，而是加一点截断的噪声：

> a′ = clip( μ_{θ⁻}(s′) + clip(N(0, 0.2²), −0.5, 0.5), 动作下限, 动作上限 )

（0.2、0.5 是相对于动作范围的大小。动作范围归一化到 [−1, 1] 时就是这两个数。）

意思是：critic 的标签变成"下一状态附近**一小片**动作的平均价值"，而不是某一个点的价值。背后的假设是"相似的动作应该有相似的价值"，这一项相当于逼着 critic 在动作方向上变得平滑，窄尖峰长不起来。

**数例：一个尖峰。** 只有一个状态，动作 a ∈ [−1, 1]，真实价值（奖励）Q(a) = −a²，最好的动作是 a = 0、价值 0。critic 大体学对了，但在 a = 0.6 附近有一个很窄的错误尖峰（高 0.5、宽 0.03）：

> Q̂(a) = −a² + 0.5·exp(−(a − 0.6)²/(2 × 0.03²))

- **不平滑**：对 Q̂ 求 max，最高点在 a = 0.598，Q̂ = **0.141**，比 a = 0 处的 0 还高，actor 会被拉过去；但这个动作的真实价值是 −0.598² = **−0.357**。高估 **0.499**。标签直接用这个值，0.5 的高估就沿着 Bellman 方程传给上一个状态。
- **平滑**：在 0.598 附近按截断的 N(0, 0.2²) 取平均，E[Q̂] = **−0.320**，真实的平均价值 E[Q] = −0.394，高估只剩 **0.074**。
- 更关键的是，平滑之后的 Q̂ 的最高点回到了 **a = 0**（平滑后的值 −0.039）：尖峰太窄（0.03），按 0.2 的宽度一平均就被摊薄了；真实的"碗"很宽，平均以后形状基本不变。

代价是：平滑以后，连真实的部分也被平均了。a = 0 处平滑后的值是 −E[ε²] = −0.039，而真值是 0。这是一点系统性的偏差（截断后噪声的方差 E[ε²] = 0.039，比 0.2² = 0.04 略小），换来对窄尖峰的免疫。

（这一组数字已验证：200 万个噪声样本。）

**TD3 的完整训练循环**：

1. 选动作 a = clip(μ_θ(s) + N(0, 0.1²))，执行一步，存进缓冲区；
2. 从缓冲区随机抽一小批；
3. 算 a′ = 目标 actor 的输出加截断噪声；y = r + γ·min(Q₁⁻(s′, a′), Q₂⁻(s′, a′))；
4. 两个 critic 都对 (Q_i(s, a) − y)² 做一步梯度下降；
5. 每 2 步：actor 对 −Q₁(s, μ_θ(s)) 做一步梯度下降；三个目标网络（两个 critic、一个 actor）软更新，τ = 0.005（每 138 步差距减半）。

| 超参数 | TD3（凭记忆） |
|---|---|
| 网络 | 两层隐藏层，各 256 个神经元（论文最初是 400、300） |
| 学习率 | 3e−4（论文最初是 1e−3） |
| 小批 | 256（论文最初是 100） |
| τ | 0.005 |
| 探索噪声 | N(0, 0.1²) |
| 目标平滑噪声 | N(0, 0.2²)，截断到 ±0.5 |
| actor 延迟 d | 2 |
| 开头纯随机动作 | 作者后来的实现是前 25000 步；论文里是前 10000 步 |

### 28.5 熵：衡量"随机程度"的量

（第 26.2 节、第 27.5 节提到的"熵奖励"里的熵，在这里补上定义。）

一个概率分布的**熵**（entropy）：

> H(π) = −Σ_a π(a)·ln π(a)

意思是"结果有多难猜"。

| 分布 | 熵 |
|---|---|
| (0.5, 0.5) | ln 2 = 0.693 |
| (0.7, 0.3) | 0.611 |
| (0.9, 0.1) | 0.325 |
| (0.99, 0.01) | 0.056 |
| (1, 0)：完全确定 | 0 |
| 四个动作各 0.25 | ln 4 = 1.386 |

验算 (0.9, 0.1)：−[0.9 × ln 0.9 + 0.1 × ln 0.1] = −[0.9 × (−0.1054) + 0.1 × (−2.3026)] = 0.0948 + 0.2303 = 0.3251。

规律：越均匀越大，越确定越小，完全确定时是 0；k 个动作时最大是 ln k（均匀分布）。

**连续动作**：高斯分布 N(μ, σ²) 的熵（叫微分熵）是

> H = ½·ln(2πe·σ²) = 1.419 + ln σ

| σ | 1 | 0.5 | 0.2 | 0.1 | 0.089 |
|---|---|---|---|---|---|
| H | 1.419 | 0.726 | −0.191 | −0.884 | −1.000 |

两点要记住：

1. 只和 σ 有关，和均值 μ 无关：往哪边偏不影响"有多难猜"；
2. **连续分布的熵可以是负数**，而且没有下限：σ 越小越确定，σ → 0 时 H → −∞。离散分布的熵永远 ≥ 0。

这两点第 28.7 节的自动调温度、第 30 课的"去掉熵"都要用。

### 28.6 最大熵 RL：在目标里奖励"保持随机"

SAC 的出发点是把 RL 的目标改成：

> 最大化 E[ Σ_t γ^t·( r_t + α·H(π(· | s_t)) ) ]

每一步除了奖励，还额外奖励 α 乘以这一步策略的熵。α 叫**温度**（temperature）：α = 0 就是普通 RL；α 越大，越看重"保持随机"。

为什么要这样做（Haarnoja 等 2017、2018 的论点，凭记忆）：

1. **探索**：策略不会过早地变成确定的，会一直保留尝试别的动作的可能；
2. **稳健**：如果有好几种差不多好的做法，策略会给每种都留一些概率，而不是押宝在一个上；某种做法因为扰动失效时，还有别的；
3. **训练稳定**：28.4 节的尖峰问题，在随机策略下自然缓解：actor 不会精确地站在一个点上，它看到的是一小片动作的平均。

**软 Bellman 方程。** 加了熵以后，价值的定义也跟着变，叫**软价值**（soft value）：

> Q(s, a) = r(s, a) + γ·E_{s′}[ V(s′) ]
> V(s) = E_{a∼π}[ Q(s, a) − α·ln π(a | s) ]

第二行里的 −α·ln π(a | s) 对 a 取平均，就是 α·H(π(· | s))。所以 V = (Q 按策略的平均) + α × 熵。

**最优的软策略**有公式（推导：在 Σ_a π(a) = 1 的约束下最大化 Σ_a π(a)·[Q(a) − α·ln π(a)]，用拉格朗日乘子对每个 π(a) 求导令其为 0：Q(a) − α·ln π(a) − α − λ = 0，所以 π(a) ∝ exp(Q(a)/α)）：

> π(a | s) ∝ exp(Q(s, a)/α)

Q 越大的动作概率越高，但不是 100%。这叫 **Boltzmann 分布**（或 softmax）。代回去，

> V(s) = α·ln Σ_a exp(Q(s, a)/α)

这叫"软最大值"：α → 0 时它就是 max_a Q(s, a)；α 越大，比 max 越大。

**数例：两个动作，Q = (1.0, 0.5)，α = 0.5。**

- exp(1.0/0.5) = e² = 7.389，exp(0.5/0.5) = e = 2.718，和是 10.107；
- π = (7.389/10.107, 2.718/10.107) = (0.731, 0.269)；
- V = 0.5 × ln 10.107 = 0.5 × 2.3133 = **1.157**；
- 验算：Q 按策略的平均 = 0.731 × 1.0 + 0.269 × 0.5 = 0.866；熵 = −(0.731 × ln 0.731 + 0.269 × ln 0.269) = 0.229 + 0.353 = 0.582，α × 熵 = 0.291；0.866 + 0.291 = 1.157 ✓。

注意 V = 1.157 比 max Q = 1.0 还大，多出来的是熵奖励。换几个温度：

| α | π(第一个动作) | 软价值 V | Q 按策略的平均（真实拿到的） | α × 熵 |
|---|---|---|---|---|
| 0.1 | 0.993 | 1.001 | 0.997 | 0.004 |
| 0.5 | 0.731 | 1.157 | 0.866 | 0.291 |
| 2 | 0.562 | 2.152 | 0.781 | 1.371 |
| 10 | 0.513 | 7.685 | 0.756 | 6.928 |

α 越大，策略越接近各 50%，真实拿到的平均价值越低（0.997 → 0.756），软价值反而越高（1.001 → 7.685），高出来的全是熵奖励。

**走廊上的软价值**（例子六，γ = 0.9，每步奖励 −1；用软值迭代 V(s) ← α·ln Σ_a exp(Q(s, a)/α)、Q(s, a) = −1 + 0.9·V(下一格) 迭代到收敛；已验证）：

| α | 量 | s = 0 | 1 | 2 | 3 |
|---|---|---|---|---|---|
| 0（普通 RL） | V\* | −3.439 | −2.710 | −1.900 | −1.000 |
| 0.3 | 软价值 V | −3.399 | −2.704 | −1.897 | −0.999 |
| | π(右) | 0.889 | 0.989 | 0.994 | 0.997 |
| | 这个策略的真实回报 | −3.546 | −2.739 | −1.915 | −1.006 |
| 0.5 | 软价值 V | −3.220 | −2.632 | −1.859 | −0.983 |
| | π(右) | 0.742 | 0.921 | 0.951 | 0.966 |
| | 这个策略的真实回报 | −3.883 | −2.968 | −2.040 | −1.062 |
| 1.0 | 软价值 V | −1.981 | −1.751 | −1.325 | −0.735 |
| | π(右) | 0.552 | 0.644 | 0.714 | 0.767 |
| | 这个策略的真实回报 | −5.592 | −4.704 | −3.298 | −1.691 |

"真实回报"是把软策略固定下来，按第 21.4 节表格第一行（V^π 的 Bellman 方程，不含熵）解 4 元线性方程组得到的。α = 0.1 时软价值和 V\* 只差 0.001 以内，没有列出。

从表里看三件事：

1. **软价值比真实回报高**：α = 0.5 时，s = 0 处软价值 −3.220，这个软策略的真实回报只有 −3.883，差 0.664，全是熵奖励。软价值甚至比最优的 V\*(0) = −3.439 还高，而这个软策略本身比最优策略差（−3.883 比 −3.439 差）。
2. **为什么 s = 0 处 π(右) 最低**：在 0 往左是撞墙、原地多耗一步，比在别处往左（倒退一格）损失小。两个动作的 Q 之差是 0.9 × (V(1) − V(0)) = 0.9 × (−2.632 + 3.220) = 0.529，π(右) = 1/(1 + e^{−0.529/0.5}) = 1/(1 + e^{−1.058}) = 0.742。在 s = 1 处，差是 0.9 × (V(2) − V(0)) = 0.9 × 1.360 = 1.224，π(右) = 1/(1 + e^{−2.449}) = 0.921。
3. **对方向一的含义（第 30 课详讲）**：把软价值换成代价当终端价值，s = 0 处是 3.220，而这个策略真实要花 3.883，连最优策略也要花 3.439。终端价值**低估了代价**，正是"不诚实"（TJ ≤ J 不成立）的方向。所以 SAC 的 critic 拿来当终端价值以前，一定要把熵的部分去掉。

（离散动作的熵 ≥ 0，所以软价值总是偏高；连续动作的熵可以是负的，偏差的方向要看温度和策略的 σ，见 28.8 节的单摆实验。）

### 28.7 SAC 算法

SAC（Soft Actor-Critic；Haarnoja、Zhou、Abbeel、Levine 2018，ICML）。第一版除了两个 Q 还单独训练一个 V 网络、温度手调；同年 12 月的第二版（Haarnoja 等，"Soft Actor-Critic Algorithms and Applications"）去掉了 V 网络，加上了自动调温度。现在说的 SAC 一般指第二版（凭记忆）。

| 组成 | 做法 |
|---|---|
| 两个 critic | Q₁、Q₂，各有一个目标网络，软更新 τ = 0.005 |
| actor | 随机策略：网络输出均值 μ(s) 和标准差 σ(s)；抽 u = μ + σ·ξ（ξ ∼ N(0, 1)），动作 a = tanh(u) |
| 温度 α | 自动调节，让策略的熵接近目标值（默认 −动作维数） |

**critic 的标签**（软 Bellman 方程的样本版，加上第 24 课的取较小值）：

> 从**当前**策略抽 ã′ ∼ π(· | s′)
> y = r + γ·[ min(Q₁⁻(s′, ã′), Q₂⁻(s′, ã′)) − α·ln π(ã′ | s′) ]

和 TD3 比有两点不同：下一步动作从当前策略里抽（SAC 没有目标 actor）；多减一项 α·ln π(ã′ | s′)，它的平均就是 α × 熵，也就是熵奖励。

**actor 的损失**：

> 最小化 E_s E_{a∼π}[ α·ln π(a | s) − min(Q₁(s, a), Q₂(s, a)) ]

意思是：让动作在 critic 眼里好（Q 大），同时别太确定（ln π 小，即熵大）。如果对 π 不加限制，这个损失的最优解正好是 28.6 节的 Boltzmann 分布 π ∝ exp(Q/α)；实际上 π 只能是 tanh 高斯，SAC 找的是这一族里最接近 Boltzmann 分布的那个。

**重参数化技巧：怎样对"抽样"求导。** actor 损失里的期望是对 a ∼ π 取的，而 π 依赖参数。求梯度有两种办法：

1. 第 25 课的**对数导数技巧**（score function）：∇E[f(a)] = E[f(a)·∇ln π(a)]，不需要 f 的导数，但方差大；
2. **重参数化**（reparameterization）：把 a 写成 a = μ + σ·ξ，ξ ∼ N(0, 1) 和参数无关。于是 E[f(a)] = E_ξ[f(μ + σξ)]，求导可以直接移进期望里：∇_μ E[f(a)] = E_ξ[f′(μ + σξ)]。需要 f 对 a 可导；SAC 里 f 就是 critic，正好可导。

**数例**：f(a) = −(a − 1)²，a ∼ N(μ, σ²)，μ = 0、σ = 0.5。真实梯度：E[f] = −(μ − 1)² − σ²，对 μ 求导是 −2(μ − 1) = 2。每次只抽一个样本估计梯度（200 万次仿真，已验证）：

| 方法 | 单样本估计 | 平均 | 标准差 |
|---|---|---|---|
| 对数导数 | f(a)·(a − μ)/σ² | 2.002 | 4.667 |
| 对数导数 + 基线（减去 E[f] = −1.25） | (f(a) + 1.25)·(a − μ)/σ² | 2.002 | 3.243 |
| 重参数化 | f′(a) = −2(a − 1) | 2.000 | 1.001 |

（对数导数一行里的 (a − μ)/σ² 就是 ∇_μ ln N(a; μ, σ²)。）

重参数化的方差（1.00）是对数导数（21.8）的约二十分之一。它的方差可以手算：f′(a) = −2(μ + σξ − 1)，随机的部分是 −2σξ，方差 4σ² = 4 × 0.25 = 1。这就是 SAC 的 actor 比 REINFORCE 好训练得多的一个原因：它和 DDPG 一样用到了 critic 对动作的导数。

**tanh 和概率的修正。** 动作有上下限（单摆力矩 ±2，前轮转角有上限），所以 SAC 先抽 u，再用 a = tanh(u) 压到 (−1, 1)，最后乘以动作范围。压缩会改变概率密度，ln π(a) 要加一项修正：

> ln π(a) = ln N(u; μ, σ²) − ln(1 − tanh²(u))

| u | 0 | 0.5 | 1 | 2 | 3 |
|---|---|---|---|---|---|
| a = tanh(u) | 0 | 0.462 | 0.762 | 0.964 | 0.995 |
| 1 − a²（tanh 在这里的斜率） | 1 | 0.786 | 0.420 | 0.071 | 0.010 |
| 修正项 −ln(1 − a²) | 0 | 0.240 | 0.868 | 2.650 | 4.619 |

直观：在 u = 2 附近，u 变化 0.01，a 只变化 0.000707（斜率 0.0707）。同样多的概率被挤进窄 14 倍的区间，密度就高 14 倍，ln π 就大 ln 14.1 = 2.65。贴着动作边界时概率密度很高、熵很低。不加这项修正，熵就算错了，温度也会调错。

**自动调温度。** α 是很敏感的超参数：不同任务的奖励尺度差几十倍，合适的 α 也差几十倍。SAC 第二版把它变成可以学的：设一个目标熵 H̄（默认 −动作维数），用损失

> 最小化 L(α) = E_{a∼π}[ −α·(ln π(a | s) + H̄) ]

更新 α（实际更新 ln α，保证 α > 0）。看它怎么动：−ln π 的平均就是策略的熵 H，所以 L(α) = −α·(−H + H̄) = α·(H − H̄)，对 α 的导数是 H − H̄：

- 策略的熵 H 比目标 H̄ 高（太随机）：导数为正，梯度下降让 α 变小，熵奖励减少，策略变得更确定；
- 策略的熵比目标低（太确定）：导数为负，α 变大，熵奖励增加，策略变得更随机。

一维动作的目标熵 −1，对应 tanh 之前的高斯分布 σ = e^{−1 − 1.419} = **0.089**（忽略 tanh 修正）。也就是说，SAC 并不追求"很随机"，而是保持一个很小、但不为零的随机性。动作是两维（比如车辆的转角和加速度）时，目标熵是 −2。

**SAC 的完整训练循环**：

1. 从 π(· | s) 抽一个动作，执行一步，存进缓冲区；
2. 从缓冲区随机抽一小批；
3. 抽 ã′ ∼ π(· | s′)，算 y = r + γ·[min(Q₁⁻, Q₂⁻)(s′, ã′) − α·ln π(ã′ | s′)]；
4. 两个 critic 都对 (Q_i(s, a) − y)² 做一步梯度下降；
5. 用重参数化抽 ã ∼ π(· | s)，actor 对 α·ln π(ã | s) − min(Q₁, Q₂)(s, ã) 做一步梯度下降；
6. α 按上面的损失走一步；
7. 两个目标 critic 软更新。

测试（部署）时不再抽样，直接用均值动作 a = tanh(μ(s))。

| 超参数 | SAC 第二版（凭记忆） |
|---|---|
| 网络 | 两层隐藏层，各 256 个神经元 |
| 学习率 | 3e−4（actor、critic、α 相同） |
| 小批 | 256 |
| 缓冲区 | 100 万条 |
| γ | 0.99 |
| τ | 0.005 |
| 目标熵 | −动作维数 |
| 每采一步更新几次 | 1 |

### 28.8 单摆上的实验：DDPG、TD3、SAC 比一比

这一节的数字都是自己训练得到的（已验证，2026-10-25）。训练脚本当时放在会话的临时目录里，没有放进仓库；下面把设置写全，照着可以重做。

**设置**：

- **环境**：例子三的单摆，用 Gym Pendulum-v1 的方程自己实现：θ̈ = 15·sin θ + 3u，|u| ≤ 2，Δt = 0.05 s（半隐式欧拉：先更新 ω 并截断到 |ω| ≤ 8，再用新的 ω 更新 θ）。奖励 −(θ² + 0.1ω² + 0.001u²)，θ 先归一化到 [−π, π)。网络的输入是 (cos θ, sin θ, ω)。每局 200 步，起点 θ ∼ U[−π, π]、ω ∼ U[−1, 1]。
- **200 步是时间上限，不是终点**：到 200 步就换一个起点重新开始，但训练时不把它当终点，标签照常用 γ·Q(s′, ·) 自举。所以 critic 估计的是"无限往下走"的折扣价值。
- **三种算法的共同设置**：两层隐藏层，各 128 个神经元（比论文的 256 小，单摆够用）；学习率 3e−4；小批 256；γ = 0.99；τ = 0.005；缓冲区装下全部数据；前 1000 步纯随机动作；之后每采一步更新一次。动作在网络里归一化到 [−1, 1]，乘 2 得到力矩。
- **DDPG 就是"TD3 去掉三个改动"**：一个 critic、标签不加平滑噪声、actor 每步更新；探索噪声和 TD3 一样用 N(0, 0.1²)。所以 DDPG 和 TD3 的差别只来自三个改动。这和 DDPG 原论文的超参数不同；TD3 论文里也是这样做对比的（凭记忆）。
- **SAC**：目标熵 −1，α 从 1 开始自动调。
- **规模**：每种算法 3 个随机种子，每个训练 3 万步（150 局）。同样的种子重跑一遍，结果逐位相同，可以复现。
- **评估**：每 2000 步评估一次，用固定的 20 个起点（所有算法、所有种子都用这同一组），确定性策略（SAC 用均值动作 tanh(μ)）。记两样东西：
  1. **控制效果**：200 步的总奖励（不打折），20 个起点平均；
  2. **critic 准不准**：critic 在起点给出的估计 Q(s₀, μ(s₀))（TD3、SAC 用两个 critic 的较小值，也就是它们标签里用的那个），对比从 s₀ 用同一个确定性策略实际跑 1000 步算出的折扣回报（γ = 0.99；γ¹⁰⁰⁰ = 4 × 10⁻⁵，截断误差可以忽略）。

**结果一：控制效果三者差不多。**

| | DDPG | TD3 | SAC |
|---|---|---|---|
| 第一次评估回报好于 −200 的步数（3 个种子） | 6000、6000、6000 | 8000、8000、8000 | 6000、6000、6000 |
| 最后 3 次评估（2.6 万、2.8 万、3 万步）的平均回报，3 个种子再平均 | −139.0 | −137.3 | −139.4 |
| 1 万步以后，评估回报掉到 −200 以下的次数（每个种子） | 0、0、0 | 2、1、1 | 0、0、0 |

- 单摆起摆对这三个算法都不难，6000–8000 步（30–40 局）就学会了，最后的差别不到 2%。TD3 起步慢一点，可能和它的 actor 每 2 步才更新一次有关（推测）。
- TD3 在 1.2 万–1.4 万步之间，三个种子都出现过暂时的回落（这两次评估的平均回报是 −214、−450），之后恢复。所以 TD3 的改动并不保证每一步都稳；在这个简单任务上，DDPG 也没有表现出不稳定。只有 3 个种子，这些差别不能推广到别的任务。
- −137 左右是什么水平：起点是随机的，很多起点要来回摆好几次才能上去，前面摆动那一段的代价是省不掉的。通常说 Pendulum 上 −150 左右就算学会了（凭记忆）。

**结果二：critic 准不准，三者差别很大。**（最后 3 次评估的平均，20 个起点平均）

| | critic 的估计（3 个种子） | 真实折扣回报 | 差（估计 − 真实） | 相对差的平均 |
|---|---|---|---|---|
| DDPG | −89.7、−102.5、−92.5 | −120.9、−122.0、−122.4 | +31.2、+19.5、+29.9 | **+22.1%** |
| TD3 | −144.5、−135.7、−143.7 | −121.0、−121.3、−121.0 | −23.5、−14.4、−22.7 | **−16.7%** |
| SAC | −124.4、−124.0、−128.9 | −121.3、−122.1、−122.8 | −3.0、−1.8、−6.1 | **−3.0%** |

正号表示 critic 比真实乐观（奖励语言），负号表示悲观。

- **DDPG 高估 22%**，三个种子方向一致。这就是第 24 课和 28.3 节说的高估。换成代价：critic 说"从这里出发还要花 90 左右"，实际要花 121。拿来当 MPC 终端价值，就是**低估代价**，正是不诚实的方向。而 DDPG 的控制效果并不差（−139.0）：**控制得好，不代表 critic 准**。
- **TD3 低估 17%**，方向和理论一致，偏得也不少。
- **SAC 只低估 3%**。

**TD3 的低估从哪来？** 有两个可能的来源：取较小值；目标平滑。后者让 critic 估计的其实是"以后每一步都在 μ(s) 上加截断噪声"的那个策略的价值，这个策略比确定性策略差。用种子 1 拆开（3 万步时的最后一次评估）：

| 量 | 数值 |
|---|---|
| critic 的估计（两个取较小值） | −140.8 |
| 只看 Q₁ | −139.5 |
| "每步加平滑噪声"的策略的真实折扣回报（每个起点跑 10 次取平均） | −121.6 |
| 确定性策略的真实折扣回报 | −121.0 |

- 目标平滑造成的部分：−121.6 − (−121.0) = **−0.6**，很小。原先猜的"主要来自平滑"是错的；
- 剩下的 −140.8 − (−121.6) = **−19.2** 来自 critic 本身。其中两个取较小值、比单看 Q₁ 低的只有 −1.3；Q₁ 自己就已经低了 −17.9，因为两个 critic 都在往"取较小值"的标签上回归。
- 解释：每一步取较小值带来的偏低只有一点点，但它进入了标签，又通过自举一层层传下去，大约累积 1/(1 − γ) = 100 步。这和第 24.2 节高估的"层层传递"是同一个机制，只是方向朝下。

**SAC 的 3% 又是什么？** SAC 的 critic 估计的是软价值，要和"软价值的真实值"比。用蒙特卡洛把它拆开：从起点出发，第一步用均值动作，以后按随机策略抽动作，每个起点跑 10 次。（这里用 3 万步时最后一次评估的数，和上表的"最后 3 次平均"略有不同。）

| 种子 | critic 的估计 | 软价值的真实值（含熵奖励） | 同样这些轨迹、不含熵的回报 | 确定性策略的回报 | 最后的 α |
|---|---|---|---|---|---|
| 1 | −124.4 | −122.7 | −121.5 | −121.3 | 0.034 |
| 2 | −124.3 | −127.0 | −122.4 | −121.9 | 0.056 |
| 3 | −128.8 | −125.6 | −122.4 | −122.3 | 0.040 |

逐列相减：

| 种子 | critic 自身的误差（第 2 列 − 第 3 列） | 熵奖励（第 3 列 − 第 4 列） | 随机策略比确定性差多少（第 4 列 − 第 5 列） | 合计 |
|---|---|---|---|---|
| 1 | −1.7 | −1.2 | −0.2 | −3.1 |
| 2 | +2.7 | −4.6 | −0.5 | −2.4 |
| 3 | −3.2 | −3.2 | −0.1 | −6.5 |

- **熵奖励是负的**（−1.2 到 −4.6），印证了 28.5、28.6 节的说法：连续动作的目标熵是 −1，熵本身是负数，"熵奖励"反而把价值拉低。它和走廊（离散动作，熵 ≥ 0，软价值偏高）的方向正好相反。量级可以粗算：α ≈ 0.04，每步熵 ≈ −1，累积约 1/(1 − γ) = 100 步，约 0.04 × (−1) × 100 = −4。
- **critic 自身的误差**有正有负（−3.2 到 +2.7），比 TD3 小得多。为什么同样取较小值，SAC 的悲观比 TD3 小这么多，这里没有查清。
- 随机策略和确定性策略的回报只差 0.1–0.5：α 已经调得很小，策略几乎是确定的。

**对方向一的结论**：

1. 三个控制效果几乎一样的 actor，背后的 critic 可以差将近 40 个百分点（+22% 到 −17%）。所以不能用"策略学得好"推断"critic 可以直接当终端价值"。
2. 偏差的方向主要由算法决定：DDPG 的 critic 偏向不诚实（低估代价）；TD3 偏向诚实，但保守得多；SAC 接近真实，但带着熵的偏差，偏差方向取决于熵的正负。
3. 这些偏差都是相对于"打折的、这个策略自己的价值"说的。换算成 MPC 要的不打折代价，还要处理折扣，见第 30 课。
4. 训练好的种子 1 的三套网络保存在会话的临时目录里，第 30 课就是拿它们做的换算和 MPC 实验（30.3、30.4 节）；临时目录不在了的话，按上面的设置重训一遍即可。

### 28.9 DDPG、TD3、SAC 对比和怎么选

| | DDPG | TD3 | SAC |
|---|---|---|---|
| 策略 | 确定性 | 确定性 | 随机（测试时用均值） |
| critic | 1 个 | 2 个，标签取较小值 | 2 个，标签取较小值 |
| 目标 actor | 有 | 有 | 没有 |
| 探索 | 外加噪声（OU 或高斯） | 外加高斯噪声 | 策略本身的随机性，由温度自动调 |
| critic 的标签 | r + γ·Q⁻(s′, μ⁻(s′)) | r + γ·min Q⁻(s′, μ⁻(s′) + 截断噪声) | r + γ·[min Q⁻(s′, ã′) − α·ln π(ã′ \| s′)] |
| critic 估计的是 | Q^μ，容易高估 | Q^μ，偏低估 | 软 Q（含熵奖励），取较小值带来偏低估 |
| actor 怎么更新 | 每步，沿 ∂Q/∂a | 每 2 步，沿 ∂Q₁/∂a | 每步，重参数化 |
| 稳定性 | 差 | 好 | 好 |

经验上（凭记忆）：TD3 和 SAC 在常用测试任务上性能接近，SAC 在部分高维任务上更好，TD3 更简单、算得更快；SAC 因为温度自动调，对超参数更不敏感。需要确定性策略、或者希望 critic 估计的就是普通价值（不含熵）时，TD3 更直接；更看重探索和稳健时，用 SAC。

**这一家算法后来的发展**（年份已核对，见附录 C；具体做法凭记忆）：REDQ（2021，10 个 critic、每采一步更新很多次）、DroQ（2022，用 dropout 代替大集成）、CrossQ（2024，去掉目标网络、用批归一化）、以及各种"每步更新很多次 + 定期重置网络"的高样本效率方法。主线都是：在不发散的前提下，从每条数据里榨出更多的学习。

### 28.10 和 MPC、方向一的联系

1. **actor 是一个"背下来的优化器"。** DDPG、TD3 的 actor 学的是 argmax_a Q(s, a)；MPC 每一步现场求解 N 步计划的最优。两者面对同一种风险：优化器会把学出来的函数的错误当真（28.2 节的表、28.4 节的尖峰、第 8.4 节的 0.45 陷阱）。TD3 的三个改动和 SAC 的熵，都是在"不改优化器"的前提下让 critic 更难被利用；方向一则是在优化器的输出上加一道用模型做的检验。
2. **actor 可以给 MPC 当初值。** `CLAUDE.md` 记录的最强基线"长时域认证 NMPC + 学习初值"，初值就可以来自这样的 actor：把 actor 沿模型往前滚 N 步，得到一条初始计划，交给 IPOPT。AC4MPC 就是"actor 给初值 + critic 当终端代价"（摘要级）。
3. **critic 不能直接当终端价值。** 至少要处理这些问题：
   - 奖励和代价的符号、尺度（RL 常对奖励做缩放）；
   - SAC 的 critic 是软 Q，含熵奖励（28.6 节：离散动作时偏乐观；连续动作时方向不定）；
   - TD3、SAC 的标签取两个 critic 的较小值，是一种系统性偏差（第 24 课；代价语言下偏高，对"诚实"有利，但不是保证）；
   - γ = 0.99 的折扣：critic 估计的是打了折的价值，比不打折的总代价小；
   - critic 估计的是 Q^π（这个策略本身的价值），不是最优的 J\*。代价语言下 J^π ≥ J\*，而且准确的 J^π 满足 TJ^π ≤ J^π（因为 J^π(x) = g(x, π(x)) + J^π(下一状态) ≥ 在所有 u 里取最小 [g + J^π(下一状态)] = TJ^π(x)），这一点反而对"诚实"有利；
   - 状态落在训练数据外时的外推（第 24.6 节的分布偏移）。

   这些就是第 30 课换算步骤要逐条处理的内容。
4. **方向一 5a 计划里的"SAC critic"**：在单摆上训练出来的 SAC critic（28.8 节就是一个），换算成代价 J(x) 后交给学习单元，看覆盖率、检验放行率和断裂次数。28.8 节的结果提示：换算时熵这一项不能省；不同算法的 critic 偏差方向不同（DDPG 偏乐观、TD3 偏悲观），学习单元用哪种算法的 critic，会直接影响检验的放行率。

### 28.11 这一课留下的问题

TD3、SAC 都是无模型的：它们不知道 x⁺ = f(x, u)，全靠试。即使是单摆这样简单的系统，也要上万步数据；更难的任务要几十万到几百万步。而且它们每一步只"看"一步：选动作靠 actor 的一次前向计算，没有"往前想几步再决定"。

如果有模型（像 MPC 那样）、或者能从数据里学一个模型呢？这就是第 29 课：有模型的 RL，从 Dyna 到 AlphaZero、MuZero、Dreamer 和 TD-MPC。其中 TD-MPC 正是"用学来的模型做 MPC、用学来的价值当终端代价"，和方向一最接近。

## 第 29 课：有模型的 RL：Dyna、AlphaZero、MuZero、Dreamer、TD-MPC

### 这一课要解决的问题

第 22–28 课的算法都是**无模型**的：不知道 x⁺ = f(x, u)，全靠在真实环境里试。代价是数据量大：单摆这么简单的系统，第 28.8 节的三个算法也要 6000–8000 步才学会；DQN 玩 Atari 用了几千万帧。真车、真机器人上，这样试不起。

控制的人一开始就有模型（MPC 的前提就是模型已知）。RL 的人也想用模型，有两种情况：

- **模型已知**：棋类的规则、物理仿真器、车辆动力学方程；
- **模型未知、从数据里学**：记下 (x, u, x⁺)，拟合一个 f̂。

这一课回答三个问题：

1. 模型能拿来干什么？（两种用法）
2. 学来的模型有什么坑？（误差累积；规划器钻模型的空子）
3. 价值函数和规划怎样互相帮忙？（往前看几步能压住价值的误差；价值函数让规划不用看太远）

最后一个问题的答案就是 TD-MPC 一类方法，也是方向一所在的位置。

### 29.1 模型的两种用法

| 用法 | 什么时候用模型 | 做什么 | 代表 |
|---|---|---|---|
| **背景规划**（background planning） | 训练时 | 用模型生成"想象出来的数据"，拿去训练价值和策略；执行时只用策略，不再规划 | Dyna、MBPO、Dreamer |
| **决策时规划**（decision-time planning） | 每一步执行前 | 用模型从当前状态往前推演，搜索最好的动作，只执行第一步 | MPC、AlphaZero 的树搜索、MuZero、PETS、TD-MPC |

MPC 是典型的决策时规划。两种用法可以同时用：AlphaZero、TD-MPC 都是"训练时学价值和策略，执行时还要规划"。

再加上"模型已知还是学来的"，就得到这一课的地图：

| | 模型已知 | 模型学来的 |
|---|---|---|
| 背景规划 | 用仿真器生成数据训练 RL（第 28.8 节其实就是这样：单摆方程就是"已知模型"，只是算法不去用它的公式） | Dyna、MBPO、Dreamer |
| 决策时规划 | MPC、AlphaZero、POLO、方向一 | MuZero、PETS、TD-MPC |

### 29.2 Dyna：用模型生成"想象的数据"

Dyna（Sutton 1990）的想法很简单：每在真实环境里走一步，

1. 用这一步的真实数据 (s, a, r, s′) 做一次 Q-learning 更新（和第 22.4 节一样）；
2. 把这一步记进模型：model[(s, a)] = (s′, r)（确定性环境，记住就行，这就是"学模型"）；
3. **再做 n 次"想象的更新"**：从模型里随机挑一个以前见过的 (s, a)，查出 (s′, r)，照样做一次 Q-learning 更新。

第 3 步不需要真实环境，只花计算。n 越大，每条真实数据被"重放"得越多。（它和第 23.5 节的经验回放很像：确定性的表格环境里，"查模型"和"从缓冲区里抽一条旧数据"几乎是一回事。区别在于模型可以回答"没有存下来的组合"，比如学来的神经网络模型可以在新的状态上预测。）

**例子：Sutton–Barto 书里的迷宫**（第 8.2 节图 8.2 的设置，自己重算）。6 行 × 9 列的网格，7 个格子是墙，从 (2, 0) 走到 (0, 8)，最短 14 步（广度优先搜索验证）。到终点奖励 1，其余为 0；γ = 0.95，α = 0.1，ε = 0.1，Q 从 0 开始，动作取值相同时随机选。30 次独立重复，每次 50 局，表里是每局步数的平均：

| 第几局 | 1 | 2 | 3 | 5 | 10 | 20 | 30 | 50 |
|---|---|---|---|---|---|---|---|---|
| n = 0（普通 Q-learning） | 925 | 704 | 516 | 314 | 108 | 54.9 | 18.6 | 17.4 |
| n = 5 | 803 | 177 | 53.5 | 23.2 | 17.0 | 17.0 | 17.0 | 16.3 |
| n = 50 | 800 | 38.3 | 17.6 | 16.7 | 16.8 | 16.8 | 16.5 | 16.7 |

| | n = 0 | n = 5 | n = 50 |
|---|---|---|---|
| 每局平均步数第一次降到 20 以下 | 第 27 局 | 第 6 局 | 第 3 局 |
| 到那时为止用掉的真实步数 | 4710 | 1116 | 856 |
| 50 局总共的真实步数 | 5127 | 1854 | 1635 |
| 50 局总共的更新次数（计算量） | 5127 | 11125 | 83382 |

从表里看三件事：

1. **用计算换数据**：n = 50 学会只用了 856 步真实数据，普通 Q-learning 要 4710 步，少了 5.5 倍；代价是总更新次数多了 16 倍。真实数据贵、计算便宜时（真车、真机器人），这是划算的交换。
2. **第一局谁都快不了**：三种都要瞎走 800–925 步。还没碰到过终点时，模型里没有任何"奖励在哪"的信息，想象得再多也没用。规划只能放大已有的信息，不能凭空产生信息。
3. **最后稳定在 16–17 步而不是 14 步**：ε = 0.1 的随机探索每局会多走几步。这是探索的代价，不是没学会。

**Dyna 的坑**：模型错了，想象的数据就是错的。Sutton–Barto 书里的例子（第 8.3 节，凭记忆）：迷宫中途改了墙的位置，模型还记着旧地图，智能体会长时间按旧地图规划。改进版 Dyna-Q+ 给"很久没试过"的动作加一点奖励，鼓励回去确认模型还对不对。

### 29.3 学来的模型的两个坑

表格模型"记住就行"。连续状态（单摆、车辆）的模型要拟合一个函数 f̂(x, u)，这就带来两个问题。

**坑一：多步预测时误差会累积。** 例子一，真实系统 x⁺ = 2x + u；学到的模型 x̂⁺ = 2.02x + u，只差 1%。从 x₀ = 1 出发，用真实的最优控制 u = −1.618x 走出一条轨迹，记下这串控制量，然后在模型里预测：

| 第几步 | 1 | 2 | 3 | 5 | 10 |
|---|---|---|---|---|---|
| 真实状态 | 0.382 | 0.146 | 0.0557 | 0.0081 | 6.6 × 10⁻⁵ |
| **开环预测**（模型里重放同一串控制量） | 0.402 | 0.194 | 0.156 | 0.419 | 13.8 |
| 开环预测的误差 | +0.020 | +0.048 | +0.100 | +0.410 | +13.8 |
| **闭环预测**（模型里每步按 u = −1.618x 重新算控制） | 0.402 | 0.162 | 0.0650 | 0.0105 | 1.1 × 10⁻⁴ |
| 闭环预测的误差 | +0.020 | +0.016 | +0.0092 | +0.0024 | +4.4 × 10⁻⁵ |

（已验证。）

- **开环预测**：误差满足 e_{k+1} = 2.02·e_k + 0.02·x_k，每步大约翻倍。第 10 步预测 13.8，真实值几乎是 0。原因是系统本身不稳定（每步乘 2），模型 1% 的误差被一路放大。
- **闭环预测**：模型里也有反馈，误差跟着状态一起衰减。

MPC 优化的是一串开环控制量，所以在它的预测时域内，模型误差是按开环的方式累积的；它靠"每一步都重新规划"把误差纠正回来，相当于在真实系统上闭了环。所以用学来的模型做 MPC 时，**预测时域越长，越不可信**。这就是 TD-MPC 只往前看 3–5 步、MBPO 只做 1–几步的短推演的原因。

**坑二：规划器会钻模型的空子。** 这是第 28.2 节"优化器把学出来的函数的错误当真"在模型上的翻版：模型在没见过数据的地方瞎外推，如果它碰巧预测"往那边走代价很低"，规划器就会专门往那边走。

对策之一是**集成**（ensemble）：训练几个模型，看它们意见是否一致。例子：真实的下一状态是 f(x) = 2x − 0.3x³，只在 x ∈ [−0.5, 0.5] 里有 20 个数据点（噪声标准差 0.01）。训练 5 个模型，每个在数据的一个自助重采样（有放回地抽 20 个）上拟合一个 4 次多项式：

| 查询点 x | 0 | 0.4 | 0.7 | 1.0 | 1.5 |
|---|---|---|---|---|---|
| 在不在数据范围里 | 在 | 在 | 外 | 外 | 外 |
| 真实值 | 0 | 0.781 | 1.297 | 1.700 | 1.988 |
| 5 个模型的平均 | 0.003 | 0.775 | 1.368 | 2.205 | 5.284 |
| 平均值的误差 | 0.003 | 0.006 | 0.071 | 0.505 | 3.30 |
| 5 个模型之间的标准差（分歧） | 0.001 | 0.014 | 0.153 | 0.766 | 4.36 |

（已验证。）

数据范围里，模型准，彼此也一致；一出数据范围，误差变大，分歧也同步变大。**分歧可以当作"模型自己知不知道"的信号**：规划时惩罚分歧大的地方，或者干脆不信。这种不确定性叫**认知不确定性**（epistemic uncertainty，来自数据不够，多收集数据就能减小）；另一种是**偶然不确定性**（aleatoric uncertainty，来自系统本身的随机性，比如路面颠簸，收集多少数据都去不掉）。

两个代表作（年份、发表处已核对；网络个数、时域等细节凭记忆）：

- **PETS**（Chua 等 2018）：5 个概率神经网络组成集成，每个网络输出均值和方差（方差管偶然不确定性，集成管认知不确定性），用采样式 MPC（交叉熵法，CEM，29.8 节）规划，时域约 30 步，不学价值函数。在几个连续控制任务上，用远少于 SAC、PPO 的数据达到接近的性能（出自摘要：在 half-cheetah 上，所需样本分别比 SAC、PPO 少 8 倍和 125 倍）。
- **MBPO**（Janner 等 2019）：同样用模型集成，但不在执行时规划，而是从真实状态出发，只用模型往前推演很短的几步（常常就 1 步），生成的想象数据和真实数据混在一起训练 SAC。论文给出的理论说明：推演越长，模型误差的累积越大，所以要短。

### 29.4 往前看几步，能压住价值的误差

这一节是这一课的核心，也是 AlphaZero、TD-MPC 和方向一共同的基础。

**设定**：例子一，模型准确（就用真实的 x⁺ = 2x + u），终端价值是一个可能有误差的 p₀·x²（真值 p\* = 4.236）。MPC 往前看 N 步，不考虑约束。

**往前看 N 步等于什么**：N 步 MPC 的预测值是 T^N(p₀·x²)，T 是 Bellman 算子（第 3.3 节）。它的第一步动作，等于"对 T^{N−1}(p₀·x²) 贪心"：

- 先算 p = T^{N−1}(p₀)，T(p) = 1 + 4p/(1 + p)（第 3.3 节）；
- 再对 p·x² 贪心：min_u [x² + u² + p·(2x + u)²]，对 u 求导：2u + 2p·(2x + u) = 0，得 u = −2p/(1 + p)·x，增益 k = 2p/(1 + p)；
- 闭环总代价系数 (1 + k²)/(1 − (2 − k)²)（第 2.5 节）。

| 终端价值 p₀ | N = 1 | N = 2 | N = 3 | N = 4 | N = 5 |
|---|---|---|---|---|---|
| 0（没有终端价值） | 发散（k = 0，x⁺ = 2x） | 不收敛（k = 1，x⁺ = x） | 4.3333（+2.30%） | 4.2381（+0.048%） | 4.2361（+0.001%） |
| 2（对代价乐观，不诚实） | 5.0（+18.0%） | 4.25（+0.33%） | 4.2364（+0.007%） | 4.2361 | 4.2361 |
| 4.0（乐观 5.6%） | 4.2381（+0.048%） | 4.2361（+0.001%） | 4.2361 | 4.2361 | 4.2361 |
| 8（对代价悲观） | 4.3766（+3.32%） | 4.239（+0.069%） | 4.2361（+0.001%） | 4.2361 | 4.2361 |

（已验证。表中是闭环总代价系数，括号里是比最优 4.2361 多出的百分比；没写百分比的格子多出不到 0.001%。）

逐格验算 p₀ = 2、N = 2：p = T(2) = 1 + 8/3 = 3.667；k = 7.333/4.667 = 1.571；闭环系数 (1 + 2.469)/(1 − 0.429²) = 3.469/0.816 = 4.25。

从表里看三件事：

1. **每多看一步，价值误差缩小到大约 0.146 倍**。0.146 就是第 23.2 节算过的 T 在 p\* 处的导数（= 0.382²）。终端价值从 2 错到 8，往前看 3 步以后，控制效果都和最优差不到 0.01%。
2. **终端价值相当于额外的时域**：没有终端价值时要看 3 步才稳得住，有一个粗糙的终端价值（p₀ = 2），看 1 步就稳、看 2 步就只差 0.33%。
3. **乐观和悲观都会被压下去**，但这里有两个前提：模型准确、没有约束。真实问题里还有约束和非线性，误差缩小的速度不一定这么快；方向一的命题 5 猜想（`CLAUDE.md`："ε·κ(N) ≤ 1 − α 则永不断裂"）说的就是这件事的一般形式：κ(N) 是 N 步的收缩因子，时域越长，能容忍的价值误差越大。

**两个方向的权衡**：往前看得越远，

- 价值函数的误差影响越小（上表，按 0.146^N 衰减）；
- 但模型的误差影响越大（29.3 节，开环按 2^N 放大），计算量也越大。

模型学来的（TD-MPC）时，两头都要顾，所以选 3–5 步的短时域；MPQ(λ)（Bhardwaj 等 2021）干脆把不同时域的结果按 λ 加权混合，和第 27.5 节 GAE 的 λ 是同一个思路。模型已知、准确时（方向一的设定），模型这一头的代价只剩计算量。这也是 `CLAUDE.md` 记录的止损条件"同等计算量的长时域 MPC 追平本方法"在单摆上已经触发的原因：单摆上长时域不贵，学习价值的好处就显不出来。

### 29.5 AlphaZero：模型已知 + 树搜索 + 学来的价值和策略

**演进**（年份和发表处已核对，见附录 C 的 C59–C61）：AlphaGo（2016，Nature）用人类棋谱 + RL + 树搜索打败李世石；AlphaGo Zero（2017，Nature）完全不用人类棋谱，只靠自我对弈；AlphaZero（2017 年 arXiv，2018 年 Science）同一套算法下围棋、国际象棋、将棋。

**组成**：

- 模型：棋规，已知、准确；
- 一个网络 f_θ(s) 输出两样东西：策略 p(a | s)（每个走法的先验概率）和价值 v(s)（从这个局面出发的胜率估计，在 −1 到 1 之间）；
- 每走一步之前，做**蒙特卡洛树搜索**（MCTS）：从当前局面出发，模拟 800 次（凭记忆），每次沿树往下走，走到一个还没展开的局面，就用网络的 v 估计它的价值（**不再随机下到终局**），然后把这个值沿路往回传。

**往下走时选哪个分支（PUCT 公式）**：

> 选使 Q(s, a) + c·P(s, a)·√N(s)/(1 + N(s, a)) 最大的 a

- Q(s, a)：这个分支到目前为止的平均价值（"看起来多好"）；
- P(s, a)：网络给的先验概率（"直觉上多好"）；
- N(s)：这个局面一共被访问了几次，N(s, a)：这个分支被访问了几次；第二项随 N(s, a) 增大而变小（"试得越多，越不需要再试"）。

**数例**：c = 1.5，局面已被访问 10 次。分支 A：试了 8 次，平均价值 0.1，先验 0.8；分支 B：试了 2 次，平均价值 0.3，先验 0.2。

- A：0.1 + 1.5 × 0.8 × √10/9 = 0.1 + 0.4216 = 0.5216；
- B：0.3 + 1.5 × 0.2 × √10/3 = 0.3 + 0.3162 = 0.6162。

选 B：它试得少，而且目前看起来不错，值得再试。这是"利用"（选看起来好的）和"探索"（试试试得少的）之间的折中，和第 22.4 节 ε-贪心解决的是同一个问题，只是更聪明。

**和 MPC 的对应**：AlphaZero 的树搜索就是"往前看几步 + 叶子上用学来的价值"，正是 29.4 节的结构：

| AlphaZero | MPC / 方向一 |
|---|---|
| 树搜索往前看的那些步 | 预测时域里的 N 步 |
| 叶子上用网络的 v | 终端价值 J(x_N) |
| 网络的先验 p 决定先搜哪些分支 | 初值（热启动）决定求解器从哪里开始找 |
| 棋规 | 已知模型 |

**训练（自我对弈）**：

1. 用"网络 + 树搜索"自己和自己下棋；
2. 每一步，树搜索结束后各分支的访问次数比例 π 记下来（访问越多说明搜索认为越好）；一局结束后的胜负 z（+1 或 −1）记下来；
3. 训练网络：让 v(s) 接近 z（回归），让 p(· | s) 接近 π（模仿搜索的结果）；
4. 用新网络继续自我对弈。

关键在第 3 步：**搜索的结果比网络的直觉好**，网络就去模仿搜索；网络变好了，下一次搜索又更好。这叫把搜索当作"策略改进算子"。控制里也有对应的做法：离线解很多次 MPC，训练一个网络去模仿 MPC 的解（近似显式 MPC、模仿学习），然后用这个网络给 MPC 当初值。

（规模。出自摘要：从随机下棋开始，除了规则不给任何领域知识，24 小时内在国际象棋、将棋、围棋上都达到超人水平，并分别击败了当时的世界冠军程序。凭记忆的细节：国际象棋自我对弈 4400 万局，用了 5000 个 TPU 生成对局；训练约 4 小时后超过当时最强的国际象棋程序 Stockfish。）

### 29.6 MuZero：连模型也学，而且只学对决策有用的部分

AlphaZero 需要知道规则。Atari 游戏、真实世界没有现成的规则。MuZero（Schrittwieser 等，2019 年 arXiv，2020 年 Nature）把模型也学出来。它有三个函数：

| 函数 | 输入 → 输出 | 作用 |
|---|---|---|
| 表示 h | 观测（棋盘、画面） → 隐状态 s⁰ | 把观测压成一个向量 |
| 动力学 g | (sᵏ, aᵏ) → (奖励 rᵏ, 下一隐状态 sᵏ⁺¹) | 学来的"模型"，在隐空间里推演 |
| 预测 f | sᵏ → (策略 pᵏ, 价值 vᵏ) | 和 AlphaZero 的网络一样 |

树搜索完全在隐空间里进行：从 h(观测) 出发，用 g 往前推，用 f 在叶子上估值。

**最关键的设计**：隐状态**不要求能还原出画面**。训练时只要求从真实轨迹出发、在隐空间里往前展开 K = 5 步（凭记忆）后，预测出的奖励、价值、策略和真实的（或搜索得到的）一致。模型只需要对"决策要用的那几个量"正确，这叫**价值等价**（value equivalence）。

为什么这样做：一帧 Atari 画面有几万个像素，背景里飘过的云、分数的字体，对决策毫无用处，但"还原画面"的模型要花大量容量去学它们；只学奖励和价值，容量全花在有用的地方。

结果（与摘要一致）：在 57 个 Atari 游戏上取得当时最好的成绩；在围棋、国际象棋、将棋上不知道规则，也达到了知道规则的 AlphaZero 的超人水平。后续：EfficientZero（2021，NeurIPS）在 Atari 100k 基准上只用约 2 小时的实时游戏经验，达到人类水平的平均 194.3%、中位数 109.0%（出自摘要）；Sampled MuZero（2021，ICML）只在采样出的一部分动作上规划，用于动作空间很大或连续动作的问题（与摘要一致）。

**和 WAM（方向三）的联系**：世界模型要不要还原观测，是一个设计选择。MuZero、TD-MPC 不还原；Dreamer（29.7 节）还原。驾驶场景里"还原未来画面"的视频世界模型很流行，但对规划来说，只预测"对决策有用的量"可能更省、更准。

### 29.7 Dreamer：在想象里训练 actor-critic

Dreamer 系列（Hafner 等；年份和发表处已核对，见附录 C 的 C65–C68；每句的主要结论与各自的摘要一致，PlaNet 用 CEM、下面的 H = 15 等细节凭记忆）：PlaNet（2019，ICML）在学来的隐空间模型里用 CEM 做 MPC；Dreamer（2020，ICLR）改成在想象里训练 actor-critic；DreamerV2（2021，ICLR）在 55 个 Atari 游戏上达到人类水平；DreamerV3（2023 年 arXiv，2025 年 Nature）用同一套配置做了 150 多个任务，并且是第一个不用人类数据、在 Minecraft 里从零开始挖到钻石的算法。

**世界模型**（RSSM，循环状态空间模型）：隐状态分成确定的一部分（用循环神经网络记住历史）和随机的一部分；训练时要求能还原观测、预测奖励，并让"只看过去推出来的随机部分"和"看了当前观测推出来的随机部分"接近（KL 项）。

**在想象里训练**：

1. 从真实数据里取一些隐状态当起点；
2. 用 actor 选动作、用世界模型往前推 H = 15 步（凭记忆），得到一条"想象的轨迹"，每步都有预测的奖励；
3. critic 学这些想象轨迹的 λ 回报（第 22.3 节、第 27.5 节的 λ）；
4. actor 让想象轨迹的 λ 回报尽量大。第一版 Dreamer 把梯度直接穿过世界模型往回传（模型是神经网络，可以求导）。这和第 28.7 节的重参数化是一个思路：用模型对动作的导数，而不是只靠"试一试、看结果"。

执行时只用 actor，不再规划。所以 Dreamer 是**背景规划**：本质上是 Dyna，只不过在隐空间里、用 actor-critic、推演 15 步。

### 29.8 采样式 MPC：MPPI 和 CEM

学来的模型是神经网络，非凸、可能不光滑，梯度型求解器（IPOPT）不一定好用；而且 GPU 很擅长"同时算几百条轨迹"。所以 RL 里的决策时规划多用**采样式**方法：

**MPPI**（模型预测路径积分；Williams 等，ICRA 2016，信息论推导见同一组作者 2018 年的 T-RO 长文；下面是常见的写法，各家实现的细节不同）每一轮：

1. 在当前均值 μ 附近抽 K 条动作序列：u⁽ⁱ⁾ = μ + σ·ε⁽ⁱ⁾；
2. 每条序列在模型里推演，算总代价 c⁽ⁱ⁾；
3. 权重 w⁽ⁱ⁾ ∝ exp(−(c⁽ⁱ⁾ − c_min)/λ)；
4. 新均值 μ = Σ w⁽ⁱ⁾·u⁽ⁱ⁾，回到第 1 步（通常同时缩小 σ）。

第 3 步的权重就是第 28.6 节的 Boltzmann 分布：代价越低权重越大，λ 是温度。λ → 0 时只取最好的那条；λ 大时各条差不多平均。

**CEM**（交叉熵法）：第 3 步换成"选代价最低的前若干条（精英），用它们的均值和标准差作为下一轮的 μ、σ"。PlaNet、PETS 用 CEM；TD-MPC 是两者的混合（先选精英，再按 exp 加权）。

**数例一：三条候选，手算。** 例子一，x₀ = 0.4，往前看 1 步，终端价值 J_B = (13/3)·x²（第 5.3 节：最优 u = −0.65，预测值 0.680）。代价 c(u) = 0.16 + u² + (13/3)·(0.8 + u)²：

- u = −0.4：0.16 + 0.16 + 4.333 × 0.16 = 1.0133；
- u = −0.6：0.16 + 0.36 + 4.333 × 0.04 = 0.6933；
- u = −0.8：0.16 + 0.64 + 0 = 0.8000。

λ = 0.1：exp(−(1.0133 − 0.6933)/0.1) = e^{−3.2} = 0.0408；exp(0) = 1；exp(−(0.8 − 0.6933)/0.1) = e^{−1.067} = 0.344。归一化以后权重是 (0.029, 0.722, 0.249)。

新均值 = 0.029 × (−0.4) + 0.722 × (−0.6) + 0.249 × (−0.8) = **−0.644**，离最优 −0.65 已经很近：三条候选里没有一条正好是 −0.65，加权平均却落在了它们"之间"的好位置上。

**数例二：随机抽样迭代**（每轮抽 64 个，λ = 0.05，σ 从 0.4 开始每轮减半；已验证）：

| 第几轮 | 1 | 2 | 3 | 4 | 5 |
|---|---|---|---|---|---|
| 抽样的 σ | 0.4 | 0.2 | 0.1 | 0.05 | 0.025 |
| 新均值 | −0.501 | −0.640 | −0.644 | −0.651 | −0.655 |
| 有效样本数 1/Σw² | 5.7 | 20.2 | 46.1 | 58.4 | 63.2 |

5 轮以后在 −0.65 附近（剩下的 ±0.005 是抽样噪声）。"有效样本数"说明有多少个样本真正起了作用：第一轮 σ 大，64 个样本里只有约 6 个代价低的在起作用。

**采样式和梯度式的对比**：

| | 采样式（MPPI、CEM） | 梯度式（IPOPT、SQP） |
|---|---|---|
| 需要导数吗 | 不需要 | 需要 |
| 非凸、不光滑 | 不怕，自带一点全局搜索 | 容易陷在局部最优（第 7.3 节） |
| 约束 | 只能截断动作、或把状态约束写成罚函数，难以严格满足 | 能严格处理 |
| 维数高时 | 需要的样本数增长很快 | 好 |
| 精度 | 一般（上面 5 轮还差 0.005） | 高 |
| 硬件 | 适合 GPU 并行 | 适合 CPU |

方向一用的是梯度式 NMPC（CasADi/IPOPT），因为证书需要可行性和较高的精度；TD-MPC 用采样式。

### 29.9 TD-MPC：学来的模型 + 短时域规划 + 学来的终端价值

TD-MPC（Hansen、Wang、Su 2022，ICML）和 TD-MPC2（Hansen、Su、Wang 2024，ICLR）。年份和发表处已核对；"学来的隐空间模型做短时域轨迹优化、学来的终端价值管长期回报、两者都用 TD 学习"这个总体结构与摘要一致；以下细节凭记忆。

**学五样东西**（都在隐空间里）：

| 组成 | 作用 |
|---|---|
| 编码器 h | 观测 → 隐状态 z |
| 隐空间动力学 d | (z, a) → 下一个 z |
| 奖励预测 R | (z, a) → 奖励 |
| Q 函数（TD-MPC2 是 5 个组成的集成） | (z, a) → 价值，规划时当终端价值 |
| 策略 π | z → 动作，规划时提供一部分候选序列（相当于初值） |

模型不还原观测（和 MuZero 一样），训练损失三项：隐状态一致性（d 预测的下一个 z 要和编码器从真实下一观测算出的 z 接近）、奖励预测、Q 的 TD 误差（带目标网络，第 23.4 节）。策略用类似 DDPG/SAC 的方式最大化 Q（第 28 课）。

**每一步怎样选动作**：

> 最大化 E[ Σ_{t=0}^{H−1} γ^t·R(z_t, a_t) + γ^H·Q(z_H, π(z_H)) ]

- H = 5（TD-MPC）或 3（TD-MPC2），很短；
- 用 MPPI 在隐空间里搜索：每轮几百条候选序列，其中一部分由策略 π 生成；迭代 6 轮；
- 只执行第一个动作，下一步重新规划（滚动时域）；上一步的解平移一格作为下一步的初始均值（第 6.4 节的"移位候选"）。

把它和第 5 课的 MPC 逐项对照：

| TD-MPC | 第 5–6 课的 MPC |
|---|---|
| 隐空间动力学 d（学来的） | 模型 x⁺ = f(x, u)（已知） |
| 奖励预测 R（学来的） | 阶段代价 g（设计的） |
| Q(z_H, π(z_H))（学来的） | 终端代价 J_f(x_N)（离线证明诚实） |
| γ = 0.99 打折 | 通常不打折 |
| 只看 3–5 步 | N 步，按问题选 |
| MPPI | QP 求解器 / IPOPT |
| 没有终端集合、没有保证 | 终端集合 + 下降条件 → 稳定性保证 |

结果（出自摘要）：TD-MPC2 用一套超参数，在 4 个领域的 104 个在线 RL 任务上明显超过基线，还训练了一个 3.17 亿参数、同时会做 80 个任务的单一智能体。

**TD-MPC 的已知问题**：TD-M(PC)²（2025 年 arXiv，2026 年 L4DC；摘要级，`论文idea` 第 2.1 节已收录）报告，TD-MPC 类方法里的价值**持续高估**（对代价就是低估），原因之一是规划器实际执行的动作和策略 π 不一致，Q 在规划器常去、但数据少的动作上估不准；规划器又专门挑 Q 高的地方（29.3 节坑二、第 24 课的优化者诅咒）。这和第 28.8 节 DDPG 的 critic 高估 22% 是同一类现象。

### 29.10 方向一在这张地图上的位置

方向一的设定：**模型已知 + 决策时规划（MPC）+ 学来的终端价值**。这一格里的邻居（描述均为摘要级或凭记忆，和 `论文idea_CCFB选题汇总与前沿对比.md` 第 2.1 节一致；年份已核对，见附录 C 的 C72–C78）：

| 工作 | 模型 | 规划 | 终端价值 | 检验或保证 |
|---|---|---|---|---|
| POLO（2019） | 已知（仿真器） | MPPI | 价值函数集成，乐观聚合（为了探索） | 无 |
| MPQ(λ) / Blending MPC & VFA（2021） | 已知但有偏 | MPPI | 学来的 Q，按 λ 混合不同时域 | 无 |
| LOOP（2021） | 学来的 | 短时域，actor 引导 | off-policy 学来的 critic | 无 |
| TD-MPC / TD-MPC2（2022 / 2024） | 学来的隐空间模型 | MPPI，3–5 步 | 学来的 Q | 无 |
| AC4MPC（2026） | 已知 | 两个梯度型 NMPC 并行 | 一个 critic | 依赖 critic 误差上界，在线查不了 |
| **方向一** | 已知 | 并行 NMPC：认证单元 + 学习单元 | 多个学来的价值 | 每个学习单元在终点检验 TJ − J ≤ (1 − α)·g；断裂监测锁定；定理 1、2 |

从这张表看方向一的定位：

1. **"检验"必须靠已知模型**。检验要算 TJ(x_N) = min_u [g(x_N, u) + J(f(x_N, u))]，用的是真实的 f。模型是学来的（TD-MPC），检验只能证明"在学来的模型里诚实"，对真实系统没有保证。这就是 `论文idea` 把"学习世界模型"放到第二篇、并要求加"值差裕量"的原因。
2. **RL 这边的工作都不检验终端价值**，它们用的是悲观（取较小值、集成）或者短时域来减轻价值误差的危害。方向一的卖点就是用模型检验代替悲观（第 24.5 节的对比表）。
3. **29.4 节的权衡是方向一必须正面回答的问题**：模型准确时，加长时域本身就能压住价值误差。所以方向一的价值，只能出现在"长时域太贵"或"长时域难解"（求解器初值不好，`CLAUDE.md` 已记录：朴素初值下长时域认证 NMPC 覆盖率只有 70–81%）或"价值带有模型算不出的信息"的场景里。这就是 `CLAUDE.md` 下一步 5b 对主实验设定的三条要求。

### 29.11 这一课留下的问题

到这里，"学价值、学模型、怎样规划"都讲过了。还剩一个方向一绕不开的具体问题：**手里有一个 RL 训练出来的 critic（比如第 28.8 节单摆上的 SAC critic），怎样把它变成 MPC 能用的终端价值 J(x)？** 符号、尺度、熵、折扣、Q 变 V、两个 critic、截断、交给检验，每一步怎么做、为什么。这是第 30 课。第 30 课还会在单摆上实际试一下：拿换算后的 critic 做短时域 MPC 的终端价值，看检验能拦下什么。

### 30.1 critic 和终端价值：同一个东西的两种说法

先把两边放在一起看：

| | RL 的 critic | MPC 的终端价值 |
|---|---|---|
| 语言 | 奖励，越大越好 | 代价，越小越好 |
| 尺度 | 训练时奖励常被缩放（比如除以 10） | 必须和 MPC 的阶段代价 g 同一个尺度 |
| 输入 | 状态和动作 Q(s, a) | 只有状态 J(x) |
| 估的是什么 | 当前策略的价值 Q^μ（DDPG、TD3）；SAC 是软价值，含熵奖励 | 理想是最优的 J\*；最低要求是诚实 TJ ≤ J |
| 折扣 | γ = 0.99 | 通常不打折 |
| 平衡点处的值 | 是什么就是什么（单摆上三个 critic 分别给出 −15.95、4.39、1.24） | 通常取 0（J\*(x_eq) = 0）；定理 1 严格说只要求处处 J ≥ 0 |
| 有几个 | TD3、SAC 有两个 | 一个函数（或者多个学习单元，每个一个） |
| 在哪里可信 | 只在训练数据附近 | MPC 会把计划的终点推到任何可行的地方 |

八个步骤就是逐行处理这张表。最后一行（外推）换算不掉，交给第 8 步的检验。

复习一下要用的记号（第 3、12 课）：

- Bellman 算子：TJ(x) = min_u [g(x, u) + J(f(x, u))]，意思是"先走一步、付这一步的代价，然后按 J 估计剩下的"。
- 诚实：TJ(x) ≤ J(x)。记 **h(x) = TJ(x) − J(x)**，叫 Bellman 残差。h ≤ 0 就是诚实。
- 方向一的检验（松弛形式）：学习单元的计划终点 x_N 上，h(x_N) ≤ (1 − α)·g(x_0, u_0)。右边叫**预算**，α 越大预算越小、检验越严。

还有一个本课要反复用的事实：**诚实而且非负的 J，一定不低于 J\***。证明只要两行：按 J 贪心地走，每一步 J(x_t) ≥ g(x_t, u_t) + J(x_{t+1})，从 0 加到 T − 1，左右相消得 J(x_0) ≥ Σ_{t<T} g_t + J(x_T) ≥ Σ_{t<T} g_t；让 T → ∞，J(x_0) 不小于这条轨迹的总代价，而 J\*(x_0) 是所有轨迹里最小的总代价，所以 J(x_0) ≥ J\*(x_0)。反过来说：**一个 J 只要在某个状态上低于 J\*，从那个状态出发的贪心轨迹上就一定有不诚实的地方**。这让"和 J\* 比"有了明确的意义：低于 J\* 不只是"不准"，而是一定有地方 h > 0（至于检验拦不拦，还要看 h 和预算比谁大）。

### 30.2 八个步骤

每一步按"做什么 → 为什么 → 例子 → 做错了会怎样"来讲。例子一里 critic 都假设是精确的，这样看到的误差全部来自换算本身。

#### 步骤 1：符号和尺度

**做什么**：训练时如果奖励是 r = −g/c（c 是缩放系数），那么 critic 估的是"−（代价）/c"，换算回来是

> J(x) = −c·V(x)

第 28 课的单摆奖励就是 −g，没有缩放，c = 1，只要变号。

**为什么**：RL 的实现里常把奖励除以一个常数，让 critic 的输出落在 1 附近，网络好训练。这个常数不影响 RL 学到的策略（所有动作的价值同比例缩放，排序不变），但 MPC 要把 J 和自己的阶段代价 g 相加，尺度必须一致。

**例子**（例子一，x⁺ = 2x + u，g = x² + u²）：假设训练时奖励是 −g/10，最优策略的 critic 是 V(x) = −0.4236x²。

| 换算 | J | h 的系数 T(p) − p | 检验 α = 0.5 的预算系数 | N = 1 的 MPC | N = 2 | N = 3 |
|---|---|---|---|---|---|---|
| 正确：J = −10·V | 4.236x² | 0 | 1.809 | 4.2361（最优） | 4.2361 | 4.2361 |
| 忘了乘 10：J = −V | 0.4236x² | +1.767（不诚实） | 0.677，不通过 | 发散 | 4.7536（+12.2%） | 4.2460（+0.23%） |
| 忘了变号：J = V，截断成 0 | 0 | +1（不诚实） | 0.5，不通过 | 发散 | 不收敛 | 4.3333（+2.3%） |

（预算系数是 0.5 × (1 + k²)，k 是按这个 J 贪心的增益，也就是检验右边 (1 − α)·g(x, u) 除以 x²。表中 MPC 几栏是闭环总代价系数，算法同第 29.4 节：先算 p = T^{N−1}(p₀)，再按 p·x² 贪心，增益 k = 2p/(1 + p)，闭环系数 (1 + k²)/(1 − (2 − k)²)，|2 − k| ≥ 1 时发散。已验证。）

逐格验算"忘了乘 10、N = 1"：k = 2 × 0.4236/1.4236 = 0.595，闭环 x⁺ = (2 − 0.595)x = 1.405x，每步放大 1.4 倍，发散。终端价值太小，MPC 以为"以后几乎不花钱"，这一步就不肯多用控制。

#### 步骤 2：同一个阶段代价

**做什么**：逐项核对 RL 的奖励是不是正好等于 MPC 阶段代价的相反数：权重、角度怎么归一化、时间步长 Δt、动作的单位。

**为什么**：critic 估的是"按训练时的那个代价累计"，MPC 拿它和自己的 g 相加。两个代价哪怕只差一个权重，J 就不再是 MPC 那个问题的价值。

**例子一：权重不一致。** critic 在训练时用的是 g = x² + r·u²，r 和 MPC 用的 r = 1 不同；critic 对它自己的问题是精确的（就是那个问题的 LQR 价值）：

| 训练时的 r | critic 的 p | 拿到 MPC（r = 1）里：T(p) | h 的系数 T(p) − p | 检验的预算系数 α = 0.5 / 0.9 | N = 1 的 MPC | 结论 |
|---|---|---|---|---|---|---|
| 1（一致） | 4.2361 | 4.2361 | 0 | 1.809 / 0.362 | 4.2361（最优） | 正好 |
| 2 | 7.2749 | 4.5166 | −2.758 | 2.046 / 0.409 | 4.3455（+2.6%） | 诚实，但比真值高 72%，MPC 偏保守 |
| 0.5 | 2.6861 | 3.9149 | +1.229 | 1.562 / 0.312 | 4.4275（+4.5%） | 不诚实；α = 0.5 放过，α = 0.9 拦下 |

（已验证。p 是 Riccati 方程 p = 1 + 4p·r/(r + p) 的不动点。）

critic 本身一点没错，错在"它估的是另一个问题"。

**单摆上要核对的四项**（第 28.8 节的设置）：

1. **权重**：θ² + 0.1ω² + 0.001u²，MPC 用同样的。
2. **角度归一化**：奖励里的 θ 先归一化到 [−π, π)；critic 的输入是 (cos θ, sin θ, ω)，本来就是周期的。MPC 的阶段代价也必须用归一化的角度，否则 θ = 2π（转了一整圈回到顶上）时，MPC 认为这一步代价是 (2π)² = 39.5，critic 认为是 0。
3. **时间步长**：critic 每 0.05 s 累计一次代价。MPC 也必须用 Δt = 0.05 s 和同样的积分方式（半隐式欧拉，先截断 ω 再更新 θ）。如果 MPC 用 0.1 s 一步，同样一段时间里 MPC 只加一半的项，而 critic 的折扣也是按 0.05 s 一步打的，J 就和 MPC 的代价对不上。
4. **动作的单位**：critic 的动作输入是归一化的 a = u/2 ∈ [−1, 1]，阶段代价里的 0.001u² 换成 a 是 0.004a²。把力矩 u 直接喂进 critic，critic 就会看到训练时从没见过的 a = 2，结果是外推。

#### 步骤 3：Q 变 V：用 actor 的动作，不要对动作取 max

**做什么**：

> J(x) = −Q(x, μ(x))

μ 是 actor（SAC 用均值动作 tanh(μ)）。TD3、SAC 有两个 critic 时先按第 7 步合成一个。

**为什么不用 −max_a Q(x, a)**：看上去 max_a Q 才是"从 x 出发最好能拿多少"，但有两个问题。

1. **critic 只在 a ≈ μ(x) 附近被训练过**。DDPG、TD3 的标签是 r + γ·Q(s′, μ(s′))，只在 actor 选的动作上自举；离 μ(x) 远的动作，Q 只是网络顺带外推出来的值。对动作取 max，就是在这些没训练过的地方挑最高的，正是第 24.1 节的"优化者的诅咒"和第 28.4 节的尖峰。
2. **理论上也不对**：critic 估的是 Q^μ，Q^μ(x, μ(x)) = V^μ(x) 才是"按这个策略走下去的价值"；max_a Q^μ(x, a) 是"这一步换一个动作、以后还按 μ 走"的价值，它不是任何一个策略的价值。

**单摆上的对比**（详见 30.3 节结果五）：有 37–43% 的状态，critic 认为最好的动作和 actor 差 0.5 以上；但用 max 只让 J 平均低 0.4–0.7，检验通过率降 0–4 个百分点。单摆上影响不大，原则上仍然应该用 actor 的动作。

#### 步骤 4：SAC 要去掉熵

**做什么**：SAC 的 critic 是软价值（第 28.6 节）。把软 Bellman 方程沿着轨迹展开：

> Q_软(s₀, a₀) = r₀ + γ·[r₁ + α·H(s₁)] + γ²·[r₂ + α·H(s₂)] + …

H(s_k) 是策略在 s_k 处的熵。第 0 步的动作已经给定，没有熵项；从第 1 步起每一步多一份 α·H。所以

> Q_普通(s₀, a₀) = Q_软(s₀, a₀) − E(s₀)，E(s₀) = α·Σ_{k≥1} γ^k·H(s_k)

换成代价（J = −Q）：

> J_普通(x) = J_软(x) + E(x)

**E 的符号**：离散动作的熵 ≥ 0，E > 0，软价值偏高（对代价就是偏低，不诚实）；连续动作的熵可以是负的（SAC 一维动作的目标熵是 −1），E 可以 < 0。

**为什么常数部分可以不管**：如果 E(x) 对所有状态都差不多（比如每一步的熵都等于目标熵 −1），它就是一个常数：

> E ≈ α·H·γ/(1 − γ)

单摆的 SAC：α = 0.0340。按目标熵 −1 算，E = 0.0340 × (−1) × 99 = **−3.37**；按策略在轨迹状态上实际的平均熵 −0.176 算，E = **−0.594**。但常数会在第 6 步的"归零"里整个消掉（T(J + c) = TJ + c，见第 6 步），所以**真正要管的只是 E(x) 随状态变化的那部分**。

**走廊上的例子**（第 28.6 节，α = 0.5，离散动作）：软价值和这个软策略的真实回报之差，s = 0 处 0.663，s = 3 处 0.079，随状态变化很大，减一个常数去不掉。

**单摆上 E(x) 随状态变多少**（详见 30.3 节结果六）：变化很大，从 −7.38 到 +0.99，而且顶上附近是正的（+0.79）、远处是负的（平均 −0.54）。上面两种常数修正连符号都不对。不过 α = 0.034 很小，修正前后检验通过率只差不到 1 个百分点。

#### 步骤 5：处理折扣

**做什么**：先弄清楚折扣会带来多大的不诚实，再决定要不要处理。

**推导**：critic 估的是打折的价值 J_γ(x) = g(x, μ(x)) + γ·J_γ(x⁺)，x⁺ = f(x, μ(x))。检验用的 T 不打折：

> TJ_γ(x) = min_u [g(x, u) + J_γ(f(x, u))] ≤ g(x, μ(x)) + J_γ(x⁺) = J_γ(x) + (1 − γ)·J_γ(x⁺)

（不等号：取 u = μ(x) 不一定是最小的。等号：把第一个式子里的 g(x, μ(x)) 换成 J_γ(x) − γ·J_γ(x⁺)。）所以

> h(x) ≤ (1 − γ)·J_γ(x⁺)

**一个完全准确的打折 critic，最多也会不诚实"下一状态剩余代价的 1%"**（γ = 0.99）。

**例子一**：γ = 0.99 时的 LQR 价值 p_γ = 4.2288，比不打折的 4.2361 低 0.17%。h 的系数 T(p_γ) − p_γ = +0.00624，上界 (1 − γ)·p_γ·(2 − k)² = 0.00629（k = 1.6144 是打折 LQR 的增益，x⁺ = (2 − k)x），上界几乎是紧的。和预算比：α = 0.9 时预算是 0.1 × g ≈ 0.36x²，0.006 只占不到 2%。例子一里折扣无关紧要。

**单摆上折扣的麻烦大得多**，原因是第 28 课的三个 actor 都没有正好停在顶上（30.3 节的表）：DDPG 停在偏 0.051 rad 的地方、用 −0.257 的力矩撑着，每步代价 0.0027。这样一来：

- 这个 actor 不打折的总代价是无穷大（每步 0.0027，永远付下去），根本没有"不打折的 J^μ"可以换算；
- 打折的价值在顶上是 0.0027/(1 − γ) = 0.27，(1 − γ)·J_γ(x⁺) ≈ 0.0027，正好等于每步代价，而顶上附近的预算 (1 − α)·g 也是这个量级。折扣带来的不诚实和预算一样大。

具体数字见 30.3 节。处理办法有三种：

1. **训练时用更大的 γ**（比如 0.999），上界缩小 10 倍，但 critic 更难训练（误差按 1/(1 − γ) 累积，第 28.8 节 TD3 的 −17% 就是这样来的）；
2. **把 actor 训练到正好停在平衡点**，或者在平衡点附近换成 LQR（第 7 课），让 J^μ 不打折也有限；
3. **不处理，交给检验**：远离平衡点时 (1 − γ)·J_γ(x⁺) 约 0.8，而 α = 0.5 的预算 (1 − α)·g 约 2.4（单摆远处 g 的中位数约 4.7），检验放得过去；平衡点附近放不过去，那里交给认证单元。

方向一走第 3 条，30.3、30.4 节的数字说明它在单摆上是怎样分工的。

#### 步骤 6：归零后截断

**做什么**：

> J(x) ← max( J(x) − J(x_eq), 0 )

x_eq 是平衡点（单摆是 θ = 0、ω = 0）。先减去 critic 在平衡点的值，让 J(x_eq) = 0；再把负值截成 0。

**为什么要归零、截断**：MPC 的代价在平衡点是 0，最优的 J\*(x_eq) = 0，归零让 J 在平衡点和真值对上；定理 1 的证明要用到 v_T ≥ 0（第 12 课），所以 J 不能是负的，要截断。（严格说定理 1 只要求 J ≥ 0，不要求 J(x_eq) = 0：闭环总代价有限，就推出 g_t → 0、状态收敛到平衡点。所以还有一种不截断的做法"减去 J 的最小值"，30.3 节结果四和 30.4 节试了它。）critic 在平衡点的值却可以是任何数：单摆上 DDPG 给出 −15.95（意思是"从顶上出发还能赚 15.95 的奖励"，而奖励都 ≤ 0，这不可能）；TD3 给出 4.39，SAC 给出 1.24。

**为什么减常数不影响 MPC，也不影响检验**：

> T(J + c)(x) = min_u [g(x, u) + J(f(x, u)) + c] = TJ(x) + c

所以 h = T(J + c) − (J + c) = TJ − J，**h 和常数无关**；MPC 的目标也只差一个常数，选出来的控制不变。例子一：J = 4.236x² + 5，T(J) = 4.236x² + 5，h = 0，和不加 5 一样。

这也是第 4 步"熵的常数部分可以不管"的原因：归零把它和别的常数一起减掉了。

**截断的代价**：critic 在平衡点附近不准时，会出现"比平衡点还便宜"的状态（J(x) < J(x_eq)），截断后这些地方 J = 0，形成一块**平地**。平地里的 x ≠ x_eq，TJ(x) ≥ min_u g(x, u) > 0 = J(x)，所以平地里处处不诚实。

**例子一：J = max(J\* − 0.05, 0)。** 这相当于一个"整体乐观 0.05"的 critic 归零截断以后的样子。平地是 |x| ≤ √(0.05/4.236) = 0.1086。

#### 步骤 7：两个 critic 怎么合

TD3、SAC 都有两个 critic。可选的做法：

| 做法 | 代价语言 | 说明 |
|---|---|---|
| 取较悲观的 | J = max(J₁, J₂)（对奖励取 min） | 和训练时标签的做法一致 |
| 只用一个 | J = J₁ | |
| 取平均 | J = (J₁ + J₂)/2 | |
| 各当一个学习单元 | 两个单元分别检验，在通过检验的单元里取最小 | 方向一的结构 |

**一个容易想错的地方：两个都诚实时，取较悲观的不保证诚实，取较乐观的反而保证。** 第 24.5 节说"悲观在例子一里恰好等价于诚实"，那是因为二次函数只有一个参数。一般情况：

- **两个诚实的 J 取较小值，还是诚实的**。证明：T 是单调的（J 处处变小，TJ 也处处变小），所以 T(min(J₁, J₂)) ≤ TJ₁ ≤ J₁，同样 ≤ J₂，于是 T(min(J₁, J₂)) ≤ min(J₁, J₂)。这正是 Parallel MPC 在多个认证单元里取最小的道理。
- **两个诚实的 J 取较大值，不一定诚实**。反例：从 a 出发有三条路：经 b 到终点（两步各花 1）、经 c 到终点（两步各花 1）、直接到终点（花 10）。J\*(a) = 2，J\*(b) = J\*(c) = 1。
  - critic 1 对 b 是准的、对 c 很悲观：J₁ = (a: 2, b: 1, c: 100)。检验：TJ₁(a) = min(1 + 1, 1 + 100, 10) = 2 ≤ 2，TJ₁(b) = 1 ≤ 1，TJ₁(c) = 1 ≤ 100，诚实。
  - critic 2 反过来：J₂ = (a: 2, b: 100, c: 1)，同样诚实。
  - 取较大值：M = (a: 2, b: 100, c: 100)。TM(a) = min(101, 101, 10) = 10 > 2，**不诚实**。两个 critic 各自对一条路悲观，取较大值把两条路都堵死了，却还说 a 只要花 2。

所以第 24.5 节说的"先取 max(J₁, J₂) 当一个学习单元，再做检验"是可以的，但 max 本身不提供保证，保证来自检验。如果两个 critic 都要用，**让它们各当一个学习单元**更好：各自检验，通过的里面取最小，正好用上"取较小值保持诚实"。代价是多解一个 MPC。

单摆上三种合法的比较见 30.3 节的表。

#### 步骤 8：交给检验

**做什么**：学习单元解完自己的 N 步计划以后，在终点 x_N 上多解一个一步问题：

> TJ(x_N) = min_u [g(x_N, u) + J(f(x_N, u))]

f 是真实的模型。算出 h = TJ(x_N) − J(x_N)，满足 h ≤ (1 − α)·g(x_0, u_0) 才放行。移位候选也要检验（`CLAUDE.md` 方向一的第 2 条）。

一步问题用局部求解器解，得到的是 TJ 的上界（找到的不一定是全局最小），所以 h 只会算大、不会算小，检验只会更保守，不会放过不该放的。单摆上用 81 个力矩取值（−2 到 2，间隔 0.05）枚举，也是上界。

**检验能放过什么、拦下什么？** 用例子一的两种误差说明（J^μ 是某个策略 μ 的准确价值，满足 J^μ(x) = g(x, μ(x)) + J^μ(x⁺)）。

**乘性误差**：J = (1 − e)·J^μ，e > 0 表示乐观（对代价估低）。

> TJ(x) ≤ g_μ(x) + (1 − e)·J^μ(x⁺) = g_μ(x) + (1 − e)·(J^μ(x) − g_μ(x)) = (1 − e)·J^μ(x) + e·g_μ(x)

所以 **h(x) ≤ e·g_μ(x)**：乘性误差造成的不诚实，和这一步的代价成正比。预算也和这一步的代价成正比，所以大致是 **e ≲ 1 − α 就能通过**，和离平衡点远近无关。

例子一，J^μ = J\* = 4.236x²（g_μ = 3.618x²）：

| e | J 的系数 | h 的系数 | 上界 e·g_μ | 贪心那一步的 g | 预算 α = 0.5 | 预算 α = 0.9 |
|---|---|---|---|---|---|---|
| +0.22（乐观 22%） | 3.3041 | +0.7665 | 0.7960 | 3.3572 | 1.6786，通过 | 0.3357，不通过 |
| +0.05（乐观 5%） | 4.0243 | +0.1796 | 0.1809 | 3.5662 | 1.7831，通过 | 0.3566，通过 |
| −0.17（悲观 17%） | 4.9562 | −0.6278 | −0.6151 | 3.7696 | 通过 | 通过 |

（已验证。系数都乘 x²。）

**加性误差**：J = J^μ + d(x)，d 是一个随状态变化的误差。

> TJ(x) ≤ g_μ(x) + J^μ(x⁺) + d(x⁺) = J^μ(x) + d(x⁺)

所以 **h(x) ≤ d(x⁺) − d(x)**：检验看的是误差**沿着轨迹的变化**，不是误差本身。

- d 是常数：h ≤ 0，通过（第 6 步的表里 x ≥ 0.3 的几行）；
- d 在某一段上变大（从乐观变成不那么乐观）：那一段 h > 0。最常见的情形就是归零：远处乐观一个常数，到平衡点必须回到 0，这个"回到 0"的过程就落在平衡点附近，而那里预算最小。

这和 `CLAUDE.md` 里 `break_search.py` 的结果对得上：乘性误差从未造成断裂，断裂全部来自加性乐观误差（目标区域置零、局部乐观带）。

**八个步骤一览**：

| 步骤 | 做什么 | 做错的后果（例子一或单摆） |
|---|---|---|
| 1 符号和尺度 | J = −c·V | 忘了乘 10：N = 1 发散 |
| 2 同一个代价 | 核对权重、角度、Δt、动作单位 | 训练时 r = 0.5：h 系数 +1.229 |
| 3 Q 变 V | J = −Q(x, μ(x)) | 用 max_a：单摆上 J 平均低 0.4–0.7，检验通过率降 0–4 个百分点 |
| 4 去掉熵（SAC） | J_普通 = J_软 + E(x)，只管 E 随状态变化的部分 | 走廊上状态间差 0.663 − 0.079 = 0.584 |
| 5 折扣 | h ≤ (1 − γ)·J_γ(x⁺)，交给检验 | 单摆 actor 停在偏处，平衡点附近的不诚实和预算一样大 |
| 6 归零后截断 | J ← max(J − J(x_eq), 0) | 截断出平地，N = 1 停在平地边上 |
| 7 两个 critic | 各当一个学习单元，或取 max 再检验 | max 本身不保证诚实（三条路的反例） |
| 8 交给检验 | h(x_N) ≤ (1 − α)·g(x_0, u_0) | — |

### 30.3 单摆上的换算：和真值比

这一节和下一节的数字都是自己算的（已验证，2026-10-25）。脚本放在会话的临时目录里，没有入库；设置写全如下，照着可以重做。

**设置**：

- **critic**：第 28.8 节种子 1 训练 3 万步后的三套网络（DDPG 一个 critic，TD3、SAC 各两个）。
- **换算**：按 30.2 节。c = 1；阶段代价和训练时完全相同（同一个模型、同样的权重、Δt = 0.05 s）；Q 变 V 用 actor 的确定性动作（SAC 用 tanh(μ)）；两个 critic 先取较悲观的（代价取 max，和训练时一致）；最后归零、截断。熵和折扣先不处理，单独量它们有多大。
- **真值 J\***：值迭代。网格是 θ 200 格 × ω 161 格（−8 到 8），力矩取 41 个值，双线性插值，不打折，迭代到最大变化小于 10⁻⁷，共 591 轮。核对：在第 28.8 节的 20 个评估起点上，表给出的 J\* 平均 133.48，按表贪心实际跑出来 133.61，单个起点最大相对差 4.5%（插值误差）。J\*(最低点、静止) = 307.35。
- **两组状态**：
  - 轨迹组：每个 actor 自己从 200 个随机起点各跑 200 步，每 5 步取一个，共 8000 个。actor 起摆以后一直待在顶上，所以约 85% 的状态在顶上附近；
  - 均匀组：θ ∈ [−π, π)、ω ∈ [−8, 8] 上均匀抽 4000 个。
- **近处和远处**："近处"指 |θ| < 0.5 且 |ω| < 1；其余状态里 J\* > 1 的叫"远处"。为什么取 0.5：力矩上限 2 最多静止撑住 sin θ = 3 × 2/15 = 0.4，也就是 θ = 0.41 rad；θ = 0.5 静止时已经撑不住，要先倒下去再摆上来，J\*(0.5, 0) = 123.70。
- **检验**：这一节在同一个状态上检验，h(x) ≤ (1 − α)·g(x, u_T)，u_T 是算 TJ 时找到的最小点，TJ 用 81 个力矩取值枚举。这相当于"N = 0"的检验，比 MPC 里的检验（预算用计划第一步的代价，30.4 节）更严。

1. **J\* 的表本身也只有 97–99% 通过**，不是 100%。原因是插值误差，加上 TJ 只在 81 个力矩里找最小（是上界）。这给出了这套测量的"底"：低于 97% 的部分才是 critic 自己的问题。
2. **DDPG 远处 95% 左右的状态低于 J\***，中位数低 23–28%。按 30.1 节的事实，低于 J\* 的状态出发，贪心轨迹上一定有不诚实的地方。但它在远处仍有 62–75% 的状态通过 α = 0.5 的检验：检验看的是局部一致性，整体偏低一个"差不多的量"并不妨碍通过（30.2 节步骤 8 的加性误差）。
3. **TD3 和真值最接近**（中位数 −12% 到 +2%），远处通过率也最高；SAC 在 DDPG 和 TD3 之间（中位数 −15% 到 −8%，通过 77–82%）。第 28.8 节说 TD3 的 critic 比它自己 actor 的折扣价值低估 17%（奖励语言，悲观）；这里和不打折的 J\* 比，悲观和"折扣让价值变小"正好部分抵消。
4. **α = 0.9 时通过率掉到 37–71%**。α = 0.9 只给 0.1·g 的预算，要求 J 的局部误差小于这一步代价的 10%。

**结果四：截断损失了多少。** 同样的状态，归零截断以前（直接用 critic，允许负值）和以后：

| | 组 | 远处 α = 0.5：截断前 → 后 | 近处 α = 0.5：截断前 → 后 |
|---|---|---|---|
| DDPG | 轨迹组 | 83.7% → 61.5% | 98.6% → 2.6% |
| DDPG | 均匀组 | 79.5% → 75.2% | 77.1% → 40.0% |
| TD3 | 轨迹组 | 93.5% → 77.3% | 98.1% → 95.6% |
| TD3 | 均匀组 | 90.3% → 88.3% | 95.7% → 82.9% |
| SAC | 轨迹组 | 88.4% → 77.3% | 99.4% → 5.2% |
| SAC | 均匀组 | 83.1% → 81.8% | 82.9% → 65.7% |

截断前的 critic 只差一个常数就和"归零"一样（常数不影响 h），所以这一列反映的是 critic 自己的局部一致性：DDPG 在它自己 actor 常待的顶上附近，98.6% 通过。截断以后掉到 2.6%：DDPG 顶上附近 63.6% 的格点被截成 0，正是平地里处处不诚实。

能不能不截断？一个想法是不减 J(顶上)，而减 J 在整个状态空间上的最小值，这样 J ≥ 0 处处成立、不用截断，h 和截断前完全一样。定理 1 并不要求 J(x_eq) = 0：它只用到 J ≥ 0；闭环总代价有限就推出 g_t → 0，状态照样收敛到平衡点。30.4 节试了这个做法，结论是：它在 N = 1 时改善了 DDPG 和 TD3，但在 N = 5 时反而更差。原因就是上面那张表：critic 的最小值在"正朝顶上摆过来"的状态，不截断时 MPC 会被那里吸过去。**截断不是问题的根源，critic 在顶上附近的形状不对才是**；换算修不好，只能交给检验和认证单元。

**结果五：Q 变 V 时用 max 会怎样。**（轨迹组远处；max 在 81 个动作上取；检验通过率在 1/8 的子样本上算，约 150 个远处状态）

| | DDPG | TD3 | SAC |
|---|---|---|---|
| J 降低多少（中位数 / 平均 / 90% 分位） | 0.14 / 0.60 / 2.16 | 0.22 / 0.68 / 1.92 | 0.12 / 0.38 / 1.06 |
| critic 挑的动作和 actor 差 0.5 以上的比例 | 42.6% | 42.5% | 36.9% |
| 检验通过 α = 0.5：用 actor 的动作 → 用 max | 65.8% → 63.9% | 78.0% → 74.2% | 76.3% → 75.0% |
| 检验通过 α = 0.9：用 actor 的动作 → 用 max | 43.7% → 39.2% | 57.2% → 57.2% | 50.6% → 48.7% |

- 有 37–43% 的状态，critic 认为"换一个差了 0.5 以上的力矩会更好"，和 actor 的选择不一致。这说明 critic 在动作方向上并不精确：如果 critic 准、actor 也学到了它的最大值，两者应该基本一致。
- 但在单摆上，用 max 只让 J 平均低 0.4–0.7（J 本身是几十到上百），检验通过率只降 0–4 个百分点。影响不大，原因可能是这个 critic 在动作方向上比较平，没有尖峰（推测）。
- 结论：按理应该用 actor 的动作（理由见 30.2 节步骤 3），单摆上用 max 也不会坏太多；但这只是一个例子，不能推广。

**结果六：SAC 的熵到底有多大。** α = 0.0340。先看每个状态上策略的熵 H(s)（在这个状态上抽 40–200 个动作，取 −ln π 的平均）：

| 状态 | H(s) |
|---|---|
| actor 停的位置 (θ, ω) = (0.0934, 0) | +0.26 |
| 轨迹组的近处，平均 | +0.17 |
| 轨迹组的远处，平均 | −2.19 |
| 远处里动作接近饱和的（\|a\| > 0.95，占远处的 40%），平均 | −4.58 |
| 轨迹组全体，平均 | −0.18 |

顶上附近，策略保留了相当的随机性（网络在停的位置输出 σ = 0.37，tanh 之前；高斯部分的熵 1.419 + ln 0.37 = 0.42，减去 tanh 修正约 0.16，得 0.26），因为那里力矩抖一点代价很小；起摆时力矩顶在 ±2，a = tanh(u) 接近 ±1，第 28.7 节的 tanh 修正项让 −ln π 变得很负。目标熵 −1 只是一个**平均**的约束：有的地方高、有的地方低。

再算熵的部分 E(x) = α·Σ_{k≥1} γ^k·H(s_k)：从 x 出发用均值动作沿模型走 500 步，每一步抽 8 个动作估 H(s_k)。在轨迹组的 8000 个状态上：

| 量 | 数值 |
|---|---|
| 平均 / 标准差 | +0.59 / 0.72 |
| 最小 / 最大 | −7.38 / +0.99 |
| 近处平均 / 远处平均 | +0.79 / −0.54 |

三点结论：

1. **常数修正连符号都不对。** 按目标熵算是 −3.37，按全体平均熵算是 −0.59；而顶上附近真正的 E 是 +0.79。不过常数本来就会在归零时消掉，符号错了也无所谓。
2. **E(x) 随状态变化很大**（−7.38 到 +0.99），这部分归零消不掉。
3. **但它对检验几乎没有影响。** 把 J_软 换成 J_软 + E(x)（都不归零截断），远处 α = 0.5 的通过率 88.4% → 88.2%，α = 0.9 60.8% → 60.5%，近处 99.4% → 99.7%；和 J\* 的相对误差 −8.9% → −8.5%。原因还是 30.2 节第 8 步：检验只看 E(x⁺) − E(x)，E 沿着轨迹变得慢；而且 α = 0.034 很小，E 和远处几十上百的 J 比是小量。

所以：SAC 训练到最后、α 已经很小时，熵的修正可以省掉，交给检验；α 大时（走廊里 α = 0.5，状态间差 0.663 − 0.079 = 0.584）就要像这里一样用模型算 E(x)。这个计算很贵：每个状态要往前滚 500 步、每步抽 8 个动作；给这个版本算 TJ 要对 8000 × 81 个下一状态各滚一遍，SAC 这一组静态分析因此跑了 34 分钟（当时 CPU 上还有别的任务）。

**结果七：折扣带来的不诚实有多大。** 把每个 actor 自己的、准确的折扣价值 J_γ（从每个状态用模型跑 700 步算出来，γ⁷⁰⁰ = 0.0009，截断误差小于 10⁻⁵）当成 J，看它诚不诚实。这排除了 critic 自身的误差，只剩折扣的影响。算 TJ 时除了 81 个力矩，再加上 actor 自己的动作，这样 h ≤ (1 − γ)·J_γ(x⁺) 必须成立。（轨迹组 1/8 子样本，1000 个状态，其中约 840 个在近处。）

| | DDPG | TD3 | SAC |
|---|---|---|---|
| 顶上的 J_γ（= c/(1 − γ)） | 0.279 | 0.601 | 0.876 |
| 诚实（h ≤ 0）的比例 | 9.8% | 86.1% | 4.5% |
| 远处：h 的中位数 / 上界 (1 − γ)·J_γ(x⁺) 的中位数 / 这一步代价的中位数 | 0.43 / 0.83 / 4.77 | 0.29 / 0.82 / 4.64 | 0.38 / 0.83 / 4.72 |
| 近处：h 的中位数 / 上界的中位数 / 这一步代价的中位数 | 0.0026 / 0.0027 / 0.0028 | −0.025 / 0.0062 / 0.0052 | 0.0079 / 0.0089 / 0.0097 |
| 远处通过 α = 0.5 / 0.9 | 94.3% / 61.0% | 94.4% / 64.2% | 94.3% / 61.0% |
| 近处通过 α = 0.5 / 0.9 | 13.2% / 10.5% | 99.8% / 99.5% | 9.4% / 6.0% |

（上界数值上成立：极少数状态超出上界，超出量是 700 步截断的量级；DDPG、TD3 核对过，不超过 6.4 × 10⁻⁶。）

- **远处**：折扣带来的 h 约 0.3–0.4，只占这一步代价（约 4.7）的 6–9%，α = 0.5 的预算放得过去（94%），α = 0.9 的预算（10%）就紧了（61–64%）。
- **近处**：DDPG 和 SAC 的 h 几乎等于上界，也几乎等于这一步的代价（三个数都在 0.003 或 0.009 左右）。原因是 30.2 节步骤 5 说的：actor 停在偏处，每步付 c，(1 − γ)·J_γ ≈ c，而这一步的代价也是 c。**哪怕 critic 完美地学到了自己 actor 的价值，近处也有 87–91% 通不过 α = 0.5 的检验。**
- TD3 是例外：它的 actor 在顶上来回抖（力矩在 −1.84 和 +1.38 之间跳），浪费很多，一步贪心就能省下不少，所以 TJ 比 J_γ 低得多（h 的中位数 −0.025），把折扣带来的那点不诚实盖过去了。这再次说明 30.1 节的道理：**策略越差，它的价值越"诚实"**（J^μ ≥ J\*，离 J\* 越远，越容易满足 TJ ≤ J）。

**结果八：两个 critic 怎么合。**（检验通过率，远处，α = 0.5 / α = 0.9；都不归零截断，只比较三种合法本身）

| | 组 | 取较悲观（代价 max） | 只用 Q₁ | 取平均 |
|---|---|---|---|---|
| TD3 | 轨迹组 | 93.5% / 74.8% | 90.4% / 72.8% | 93.3% / 73.1% |
| TD3 | 均匀组 | 90.3% / 73.3% | 89.0% / 72.2% | 90.4% / 73.6% |
| SAC | 轨迹组 | 88.4% / 60.8% | 88.0% / 61.1% | 89.3% / 62.6% |
| SAC | 均匀组 | 83.1% / 59.5% | 80.0% / 56.3% | 83.0% / 58.3% |

三种做法的差别不超过 3.1 个百分点。原因是两个 critic 用同样的数据、同样的标签训练，差别本来就小（在顶上：TD3 的 Q₁ 给 4.09、两个取较悲观的给 4.39；SAC 是 0.82 和 1.24）。在单摆上怎么合并不重要；方向一里如果要用两个，按 30.2 节步骤 7 的建议，各当一个学习单元。

### 30.4 短时域 MPC 用换算后的 critic 当终端价值

**设置**：

- 模型、阶段代价、力矩上限 |u| ≤ 2 和第 28.8 节完全相同；20 个评估起点也是第 28.8 节那一组；每个起点跑 200 步，记闭环总代价 Σg（不打折）。
- 每一步解 min Σ_{k<N} g(x_k, u_k) + J(x_N)。N = 1 时把 81 个力矩取值逐个试；N > 1 时用投影 Adam（学习率 0.05，迭代 50 次，每次迭代后把力矩截回 [−2, 2]），从三个初值出发取最好的：actor 沿模型往前滚 N 步、全零、上一步的计划平移一格（末尾补 actor 的动作）。
- 终端价值五种：0（不用终端价值）、J\* 的表（值迭代）、DDPG、TD3、SAC 换算后的 critic（按 30.3 节的换算，归零截断）。
- 每一步在计划终点 x_N 上做方向一的检验 h(x_N) = TJ(x_N) − J(x_N) ≤ (1 − α)·g(x_0, u_0)，α = 0.5 和 0.9。**这里只记录检验通不通过，不据此切换**：这是"学习单元单独用"的诊断，看它自己的检验会在哪里放行、哪里拦下，不是方向一的完整方法（完整方法里检验不通过就换认证单元）。
- "近处""远处"按当前状态 x_0 分：近处 |θ| < 0.5 且 |ω| < 1。
- "立住"：200 步后 |θ| < 0.1 且 |ω| < 0.5。

5. **近处的检验几乎都不通过，连 J\* 的表在 N = 1 时也只通过 54%。** 分两种情况。critic 在 N = 1 时停在平地边上，h 几乎等于这一步的代价（DDPG 的中位数 0.074 对 0.076），预算只有代价的一半或十分之一，当然通不过。立住以后（J\* 的表各个 N、critic 在 N ≥ 5 时），顶上附近 h 和预算都只有 10⁻⁵ 到 10⁻⁸ 的量级，表格插值、81 个力矩的网格，误差就比预算大。J\* 的表在 N = 10 时近处通过 99.7%：时域长了，计划终点 x_N 比当前状态 x_0 离平衡点近得多，终点的 h 相对于起点的预算就小了（这正是命题 5 猜想里 κ(N) 的作用）。critic 在 N = 10 时近处也只通过 18–33%：它的平地让计划终点没有被拉向平衡点（推测：平地里 J 处处为 0，MPC 只要让 x_N 留在平地里就行，不必往平衡点走）。

N = 1 时减最小值大多更好（TD3 甚至 20 个全部立住），N = 5 时却全部更差，而且一个都没立住：200 步后 |θ| 的中位数 0.14–0.28。原因是 30.3 节那张"最小值在哪里"的表：不截断，critic 原本的形状就全部保留下来，包括"正朝顶上摆过来的状态最便宜"这个错误，时域长了，MPC 更有办法往那里凑。**两种做法都修不好 critic 在顶上附近的错误形状**，这是估计误差，不是换算误差。

### 30.5 检验拦下了什么；对方向一意味着什么

**1. 检验拦下的是"误差在变化"的地方。** 远处，critic 的误差大体像一个平移（DDPG 整体比 J\* 低 25% 左右），检验仍然放过 60–90%；近处，critic 的形状不对（最小值不在顶上，归零以后又截出一块平地），检验几乎全部拦下。这和 30.2 节第 8 步的分析一致：加性误差的 h ≤ d(x⁺) − d(x)，误差不变的地方通过，误差变化的地方不通过。也和 `CLAUDE.md` 里 `break_search.py` 的结论一致：断裂全部来自加性乐观误差。

**2. 这正好就是方向一要的分工。** 方向一里，学习单元负责认证短时域覆盖不到的远处（单摆起摆），认证单元（LQR 终端代价加可认证的椭球，`pendulum_headroom.py` 里已有）负责顶上附近。检验在近处不放行学习单元，不是缺陷，而是把那里交给认证单元。单摆的数据说明这个分工是自然发生的：学习单元在远处通过 83–91%（α = 0.5、N = 5 或 10），在近处基本不通过。

**3. "critic 准不准"和"能不能当终端价值"是两回事。** DDPG 的 critic 在远处比 J\* 低 25%，按 30.1 节的事实一定有不诚实的地方，但它当终端价值时，N = 10 的闭环总代价只比 J\* 多 3%，远处检验也通过 83%。反过来，J\* 的表在近处、N = 1 时也只通过 54%。检验关心的是局部一致性，不是绝对精度。

**4. 不能只在 actor 自己走过的状态上评价 critic。** TD3 的 critic 在它自己 actor 的轨迹上，近处静态检验通过 95.6%（30.3 节结果三）；放进 MPC 以后，近处只通过 4.7%（N = 1）到 32.9%（N = 10）。因为 MPC 是优化器，会主动走到 critic 最便宜的地方，也就是 critic 错得最厉害的地方（第 24.1 节的优化者的诅咒，第 8.4 节的 0.45 陷阱）。这就是检验必须在线做、在 MPC 实际给出的计划终点上做的原因。

**5. 对方向一 5a 实验的具体建议**（`CLAUDE.md` 下一步第 5 项）：

- 学习单元的 critic 先用 TD3 或 SAC（远处通过率 77–91%），DDPG 偏乐观、通过率最低，可以拿来当"坏 critic"的对照；
- 换算按 30.2 节的八步；熵、折扣不单独修正，交给检验；
- 顶上附近交给 LQR 认证单元，不指望学习单元在那里通过；
- α 先取 0.5（α = 0.9 时远处通过率只有 17–67%）；
- 时域取 N = 10（`CLAUDE.md` 原计划），远处 α = 0.5 通过 83–90%；
- 除了覆盖率、检验通过率、断裂次数，还要报告"闭环里实际走到的状态上的通过率"，静态统计会高估；
- 对照组：不检验直接取最小；只用认证单元；不用终端价值、N = 20 的长时域（136.2）。最后这一组在单摆上已经和学习单元差不多好，所以 5a 只能当机制验证，证明不了方向一的价值；主实验（5b）要换到长时域昂贵或难解的设定。

### 30.6 这一课留下的问题

1. **能不能训练出"在平衡点附近也诚实"的 critic？** 几个可能的方向（都还没试过）：
   - 在平衡点附近把 critic 和 LQR 的二次价值拼起来；
   - 训练时 γ 更接近 1，或者改用平均代价的写法，减小折扣带来的不诚实；
   - 模型已知时，训练损失里直接加上 Bellman 残差 h(x) = TJ(x) − J(x) 的惩罚，把"检验"写进训练。这和第 23.2 节的拟合 Q 迭代很像，只是目标从"拟合得准"变成"拟合得诚实"。
2. **命题 5 的定量形式**（`CLAUDE.md` 下一步第 4 项）：单摆的数据给了一个直观的例子。J\* 的表局部误差小，时域从 1 加到 10，近处通过率从 54% 升到 99.7%；critic 的局部误差在近处和预算一样大甚至更大，时域加到 10 也只有 18–33%。命题 5 要回答的就是：局部误差多大、时域多长，检验就一定通过。
3. **为什么 TD3 在 N = 5 时只立住 9 个**，为什么 α = 0.9 时远处通过率和 N 的关系不单调。这两个现象这里没有查清。

**第五部分到这里结束。** 第 21–30 课讲了 RL 怎样估价值、怎样选动作、怎样训练得稳，有模型时怎样规划，最后落到方向一要的那一步：把 critic 换算成终端价值，并用模型检验它。接下来可以回到研究（方向一的 5a 实验，或者精读近邻论文），也可以继续学世界模型和 WAM（方向三）。

### 二、六条主线

#### 主线一：价值怎么估

一句话：从"用模型算期望"走到"用样本估、用自己的估计补"，再走到"用神经网络推广"，每走一步都换来一个新的误差来源。

| 阶段 | 怎么估 | 代价 | 例子里的数字 |
|---|---|---|---|
| 动态规划 | 用模型对每个动作、每个下一状态算期望 | 要模型；维数灾难 | 第 3 课值迭代：p 依次是 1、3、4、4.2、4.2308…… |
| 蒙特卡洛 | 走完一整局，取实际回报的平均 | 无偏，方差大，要等一局结束 | 打滑走廊从 3 出发：平均 −1.2195（就是真值），标准差 0.4796 |
| TD | 走一步，用 r + γ·V(s′) 当目标 | 有偏，方差小 | 走廊 α = 0.5：第 8 局 V(0) = −3.02，真值 −3.439；信息从终点一格一格往回传 |
| 函数近似 | 用一组参数表示所有状态的价值 | 能推广，但可能发散 | 例子一的在线半梯度 Q-learning：所有步长都发散 |
| 冻住标签 | 拟合 Q 迭代、目标网络 | 每段时间都要把回归解好 | 拟合 Q 迭代每轮误差 ×0.146；目标网络在 η = 0.05 时，C = 500 收敛、C = 200 发散 |
| 往前看几步 | 用模型展开 N 步，终点用学来的价值 | 要模型；模型的误差随 N 放大 | 每多看一步，终端价值的误差 ×0.146 |
| 换算成终端价值 | 把 critic 按八步换成 MPC 的 J(x)，用的时候在线检验 | "说法"上的差别能换算掉，critic 自己的形状误差换算不掉 | 单摆：critic 的最小值不在顶上，而在"正朝顶上摆过来"的状态；N = 1 的 MPC 因此停在偏 0.11–0.23 rad 处 |

和 MPC 的对应：MPC 的终端价值 J(x_N) 就是"估出来的价值"。第 29.4 节说明，MPC 往前看的那 N 步本身就在修正终端价值的误差；方向一的检验 TJ(x_N) − J(x_N) ≤ (1 − α)·g 则是在"用的时候"查一次这个估计诚不诚实。第 30 课把这条线走到了头：RL 估出来的价值和 MPC 要的价值在符号、尺度、Q 和 V、熵、折扣、平衡点处的常数上都不一样，这些可以换算；换算以后剩下的误差，只能靠检验在用的时候拦下。

#### 主线二：动作怎么选

一句话：从"在表里挑最大的"走到"学一个会挑的网络"，又走回"每一步现场规划"。

1. **argmax Q**（Q-learning、DQN）：只能处理离散动作；两个 Q 只差 0.01 也会整个换动作，策略跳变（25.1）。
2. **直接学随机策略**（REINFORCE、A2C、PPO）：参数变一点，概率变一点，行为平滑；连续动作用高斯分布（25.1）。
3. **确定性 actor 当"背下来的求 max 器"**（DPG、DDPG、TD3）：a = μ(s)，一次前向计算。actor 学到的就是 critic 的 argmax，critic 错它也跟着错（28.2 的表：第 2 轮的 critic 声称代价系数只有 3.0，actor 据此学出一个根本稳不住系统的控制律）。
4. **Boltzmann 策略**（SAC）：π ∝ exp(Q/α)，Q 高的动作概率高，但不是 100%；α → 0 时退回 argmax（28.6）。
5. **决策时现场规划**（AlphaZero 的树搜索、PETS、TD-MPC 的 MPPI）：每一步用模型往前推演再决定；网络给的策略退为"先搜哪些分支""从哪个初值开始"（29.5、29.9）。

和 MPC 的对应：MPC 就在第 5 步这一端。第 3 步的 actor 可以给 MPC 当初值（`CLAUDE.md` 里的基线 10"长时域认证 NMPC + 学习初值"）；MPPI 的权重和第 4 步的 Boltzmann 分布是同一个公式（29.8）。

#### 主线三：训练怎么稳

一句话：几乎所有的稳定化手段都是同一个想法：**让被追的东西慢一点，每一步别走太远**。

| 手段 | 让什么慢下来 | 例子里的数字 |
|---|---|---|
| 目标网络（硬同步） | 标签 | η = 0.05 时 C = 500、2000 收敛，C = 50、200 发散；回归解了一半就同步最糟 |
| 软更新 τ | 标签 | τ = 0.005 时每 138 步差距减半；例子一里 τ = 0.001、η = 0.05 刚好在稳定的边缘 |
| 经验回放 | 数据分布的变化 | 打乱以后拟合误差从 0.503 降到 0 |
| TRPO 的 KL 约束 | 策略 | KL ≤ 0.01 时 π 从 0.5 最多改到 0.570 |
| PPO 的裁剪 | 策略 | 卡在差臂上的比例 7% → 0% |
| TD3 的延迟更新 | actor（让 critic 先把误差降下来） | 每 2 步更新一次 actor |
| SAC 的自动温度 | 策略变成确定性的速度 | 一维动作目标熵 −1，对应 σ ≈ 0.089 |

要记住的一点：这些都是**实用手段，不是保证**。例子一里目标网络照样会发散；单摆上 TD3 在 1.2 万–1.4 万步之间，三个种子都出现过暂时的回落（28.8）。方向一的断裂监测也是"出了问题就收紧"，区别在于它背后有定理 1、定理 2。

#### 主线四：偏差和方差

一句话：每一种新的估计方法，都是在"无偏但噪声大"和"噪声小但可能有偏"之间换一个位置。

| 手段 | 换来了什么 | 付出了什么 | 例子里的数字 |
|---|---|---|---|
| TD 代替 MC | 方差小、走一步就更新 | V 不准时有偏 | 见主线一 |
| n 步回报、TD(λ) | 在两者之间连续调 | 要选 n 或 λ | critic 乐观 20% 时：λ = 0 偏差 +0.611，λ = 1 偏差 −0.002 |
| 基线 | 方差大降，不引入偏差 | 要估一个基线 | 方差 2525 → 0；学反方向的比例 49% → 0% |
| critic 估优势 | 方差再降 | critic 不准时有偏 | 梯度估计的标准差 8.61 → 2.82 |
| GAE | λ 连续可调 | 要调 λ | λ = 0.95：偏差 0.07，标准差比 λ = 1 小 12% |
| 组内平均当基线（GRPO、RLOO） | 不用 critic | 要能从同一状态重新采样 | 奖励 (1, 0, 0, 0) 时优势 (+1.732, −0.577, −0.577, −0.577) |
| 重参数化 | 方差比对数导数小得多 | 需要 critic 对动作可导 | 单样本标准差 4.667 → 1.001 |

和 MPC 的对应：MPC 的预测时域 N 也起着"λ"的作用。N 越长，越少依赖终端价值（价值的误差按 0.146^N 衰减），但越多依赖模型（学来的模型开环误差按 2^N 放大）。MPQ(λ) 把这个对应写成了算法（29.4）。

#### 主线五：估计误差怎么防

一句话：**优化器会把学出来的函数的错误当真**（28.2），所以误差的危害不在于"有误差"，而在于"被优化器挑中"。对策从"消掉偏差"走到"故意悲观"，方向一走的是第三条路：用模型检验。

1. **问题的来源**：取 max 会挑中碰巧估高的（优化者的诅咒：2 个动作偏高 0.333，100 个动作偏高 0.98）；自举又把偏高一层层往回传（24.1、24.2）。
2. **消掉偏差**：Double Q 把"挑"和"估"分开，偏差约为 0（24.3）。
3. **故意悲观**：TD3、SAC 取两个 critic 的较小值（2 个动作时偏低 0.167）；REDQ、TQC 用集成和分位数截断控制悲观的程度；离线 RL 的 CQL 等直接压低数据外的 Q（24.4、24.6）。
4. **用分歧判断"知不知道"**：模型集成的分歧在数据范围外同步变大（x = 1.5 处分歧 4.36、误差 3.30），PETS、MBPO 据此少信模型（29.3）。
5. **用模型检验**（方向一）：在计划终点算 TJ(x_N) − J(x_N) ≤ (1 − α)·g。检验用的是真实模型，和 critic 的训练数据无关，所以能挡住两个 critic 共同的盲区（24.5 的对比表）。
6. **检验看的是局部一致性，不是绝对精度**（第 30 课）：乘性误差 J = (1 − e)·J^μ 造成的不诚实 h ≤ e·g_μ，和这一步的代价成正比，e ≲ 1 − α 就通过；加性误差 J = J^μ + d 造成的不诚实 h ≤ d(x⁺) − d(x)，误差不变的地方通过，误差变化的地方（尤其是平衡点附近，误差必须回到 0）不通过。单摆上，三个 critic 在远处的检验通过 83–91%（α = 0.5，N = 5 或 10），在顶上附近几乎都不通过，那里要交给认证单元。

要记住的数字：

- 400 个带噪声的 critic：单个诚实的比例 47.5%，两个取较悲观的 70.5%，取较乐观的 24.5%（24.5）；
- 单摆上控制效果几乎一样的三个算法，critic 的偏差是 DDPG +22.1%、TD3 −16.7%、SAC −3.0%（奖励语言，正号表示乐观）（28.8）。"策略学得好"推不出"critic 可以直接当终端价值"。
- 反过来，"critic 不准"也推不出"不能当终端价值"：DDPG 的 critic 换算后在远处比 J\* 低 23–28%，当终端价值时 N = 10 的闭环总代价只比 J\* 多 3.0%，远处检验通过 83%（30.3、30.4）。
- 完美地学到自己 actor 的折扣价值也不够：actor 停在偏离平衡点 0.05–0.09 rad 的地方，折扣带来的不诚实在顶上附近和这一步的代价一样大，DDPG、SAC 有 87–91% 通不过 α = 0.5 的检验（30.3 结果七）。

#### 主线六：数据怎么省

一句话：从"每条数据用一次就扔"走到"每条数据用很多次"，再走到"用模型代替一部分真实数据"。

| 阶段 | 做法 | 例子里的数字 |
|---|---|---|
| on-policy | 只能用当前策略的数据，用完就扔 | PPO 通常要几百万到几十亿步 |
| off-policy + 经验回放 | 旧数据反复用 | DQN 里每条数据平均被用 8 次 |
| 高更新比 | 每采一步更新很多次，用集成和取较小值防止发散 | REDQ 的更新比远大于 1 |
| 用模型生成数据（背景规划） | Dyna、MBPO、Dreamer | 迷宫：学会只用 856 步真实数据（普通 Q-learning 4710 步），代价是更新次数多 16 倍 |
| 决策时规划 | 每一步用模型往前推演 | PETS 在 half-cheetah 上样本比 SAC 少 8 倍；EfficientZero 只用约 2 小时的游戏经验 |

和 MPC 的对应：MPC 的模型已知，根本不需要试错数据，只付计算。方向一的学习单元从离线训练（值迭代或 RL）得到价值，在线也只付计算。所以在方向一的设定里，"省数据"不是卖点，卖点只能是"省计算"和"有保证"。

### 三、和你的课题的对应

1. **方向一在这张地图上的位置**：模型已知 + 决策时规划 + 学来的终端价值 + 用模型检验（29.10）。第五部分讲清了三件事：学来的终端价值从哪来（critic，第 22–28 课）；它会错在哪（高估、熵、折扣、分布偏移；对代价乐观就不诚实）；RL 自己怎么防（悲观、集成、短时域）。
2. **方向一相对 RL 工作的卖点**：用模型检验代替悲观。好的估计照单全收，坏的估计在终点被拦下，而且有定理 1、2。RL 这边的近邻（POLO、MPQ(λ)、LOOP、TD-MPC、AC4MPC）都不在线检验终端价值。
3. **方向一必须正面回答的问题**：模型准确时，加长时域本身就能压住价值误差（29.4：每多看一步误差 ×0.146）。所以方向一的价值只能出现在长时域太贵、长时域难解（初值不好），或者价值带有模型算不出的信息的场景里，也就是 `CLAUDE.md` 下一步 5b 的三条要求。
4. **方向一阶段 1（5a）要用的 critic**：第 28.8 节已经在单摆上训练出 DDPG、TD3、SAC 三套网络，偏差方向各不相同。第 30 课把它们换算成终端价值，放进短时域 MPC 试了：远处检验大多放行，顶上附近几乎全部拦下，正好对应"学习单元管起摆、认证单元管顶上"的分工；但不用终端价值、N = 20 时总代价也只有 136.2，单摆只能当机制验证（30.5 节有 5a 的具体建议）。
5. **WAM（方向三）**：世界模型要不要还原观测是一个设计选择。MuZero、TD-MPC 只预测对决策有用的量（价值等价），Dreamer 还原观测（29.6、29.7）。

### 答案

1. 往左到 1，再往右经 2、3 到 4，一共 4 步：G = −1 − 0.9 − 0.81 − 0.729 = −3.439。它是 Q\*(2, 左) = −1 + 0.9 × V\*(1) = −1 + 0.9 × (−2.71) = −3.439（21.3 节的表）。比 V\*(2) = −1.9 差 1.539，这就是优势 A\*(2, 左)。
2. Q-learning 的目标里是 max_{a′} Q(s′, a′)，学的是最优策略的价值，和实际怎么走无关；SARSA 的目标里是实际选的下一个动作 a′，学的是"带探索噪声的那个策略"的价值。执行时一定带扰动的话，SARSA 式的价值把扰动算了进去，学出来的路线更保守、更安全（悬崖行走的例子，22.5）。
3. 函数近似、自举、off-policy。半梯度每次只沿一个样本的特征方向走一小步，而标签用的是当前参数，参数一动标签也跟着动，而且标签动得比预测还多（例子一里约 4.6 倍），线性化矩阵有正特征值 +1.444，误差按指数增长。拟合 Q 迭代每一轮先把标签冻住、把回归解到底，等于在函数族里精确地做了一次 Bellman 算子，所以按 T 的收缩率 0.146 收敛（23.2、23.3）。
4. (k − 1)/(k + 1) = 2/4 = 0.5。Double Q 用 A 挑、用 B 估，B 的误差和"A 挑中了谁"无关，偏差约为 0（24.1、24.3）。
5. 不用基线：样本是 +50.5 或 −50，各占一半，平均 0.25，方差 50.25² = 2525.06。用基线 b = 100.5：两种情况样本都是 +0.25，方差为 0。期望不变是因为 E[∇log π(a)·b] = b·Σ_a ∇π(a) = b·∇(Σ_a π(a)) = b·∇1 = 0（25.3）。
6. λ = 0 是一步 TD 误差 δ_t = r_t + γ·V(s_{t+1}) − V(s_t)；λ = 1 是 MC 回报减基线 G_t − V(s_t)。λ = 0 时目标里直接用了 V(s_{t+1})，critic 的误差原样带进来（打滑走廊里 critic 乐观 20%，偏差 +0.611 = 0.9 × 0.2 × 3.396）；λ = 1 时只把 critic 当基线，不用它的值补回报，没有偏差（27.5）。
7. 不裁剪 r·Â = −0.5，裁剪后 clip(0.5, 0.8, 1.2) × (−1) = −0.8，取 min 得 −0.8。这时起作用的是裁剪后的那一项，它对参数是常数，梯度为 0，不会继续压低（27.4 表的第三行）。
8. 对 u 求导：12x + 8u = 0，u = −1.5x，增益 k = 1.5。critic 声称的代价系数 13 − 12²/(4 × 4) = 13 − 9 = 4.0；实际 (1 + 1.5²)/(1 − 0.5²) = 3.25/0.75 = 4.333。critic 低估了代价，actor 照单全收（28.2 的表，第 3 轮）。
9. 拆开种子 1：目标平滑只占 −0.6；剩下的 −19.2 来自 critic 本身，其中"两个取较小值"比单看 Q₁ 低的只有 −1.3，Q₁ 自己就低了 −17.9。原因是每一步取较小值带来的那一点偏低进入了标签，又通过自举累积了大约 1/(1 − γ) = 100 步。SAC 的 critic 估计的是软价值；连续动作的熵可以是负的（目标熵 −1），所以"熵奖励"α·H 是负数，把价值拉低了（每步约 0.04 × (−1)，累积约 100 步，约 −4）（28.8）。
10. H = 1.419 + ln 0.2 = 1.419 − 1.609 = −0.191。目标熵 −1：ln σ = −1 − 1.419 = −2.419，σ = e^{−2.419} = 0.089（28.5、28.7）。
11. 开环时误差满足 e_{k+1} = 2.02·e_k + 0.02·x_k，系统本身每步乘 2，误差一路被放大。闭环时模型里也有反馈 u = −1.618x，模型的闭环系数是 2.02 − 1.618 = 0.402，误差跟着状态一起按约 0.4 的系数衰减。MPC 在预测时域内用的是开环的控制序列，所以预测时域越长越不可信；它靠每一步重新规划，在真实系统上闭环。用学来的模型时只能看短时域，这就是 TD-MPC 只看 3–5 步的原因（29.3）。
12. N = 1：直接对 2x² 贪心，k = 2 × 2/3 = 1.333，闭环系数 (1 + 1.778)/(1 − 0.667²) = 2.778/0.556 = 5.0（+18%）。N = 2：先算 p = T(2) = 1 + 8/3 = 3.667，k = 7.333/4.667 = 1.571，闭环系数 4.25（+0.33%）。0.146 是 T(p) = 1 + 4p/(1 + p) 在 p\* 处的导数 4/(1 + p\*)²，也等于最优闭环收缩系数 0.382 的平方。对方向一的意思：模型准确时，多看几步就能把价值误差压掉，所以方向一的收益只能来自长时域太贵、太难解，或者价值带有模型算不出的信息的场景（29.4、29.10）。
13. 权重正比于 exp(−(c − 0.6933)/0.1) = (0.0408, 1, 0.344)，归一化为 (0.029, 0.722, 0.249)。新均值 = 0.029 × (−0.4) + 0.722 × (−0.6) + 0.249 × (−0.8) = −0.644。λ → 0 时只剩最好的那条，新均值 −0.6（29.8）。
14. 语言模型可以对同一个题目回答 64 次，从完全相同的状态重新采样，用组内平均当基线；真车回不到完全相同的状态，不能试 64 种开法再比较。MPC 里是模型扮演这个角色：用模型从当前状态出发，试很多个计划再比较（27.8）。
15. TD-MPC 的模型是学来的，不检验终端价值，没有稳定性保证；方向一的模型已知，在每个学习单元的计划终点检验 TJ(x_N) − J(x_N) ≤ (1 − α)·g，配合断裂监测，有定理 1、2。检验要算 TJ(x_N) = min_u [g(x_N, u) + J(f(x_N, u))]，必须用真实的 f；用学来的模型只能证明"在学来的模型里诚实"，对真实系统没有保证（29.10）。
16. 按 0.4236x² 贪心：k = 2 × 0.4236/1.4236 = 0.595，闭环 x⁺ = (2 − 0.595)x = 1.405x，每步放大 1.4 倍，发散。检验：h 的系数 T(0.4236) − 0.4236 = 1 + 4 × 0.4236/1.4236 − 0.4236 = +1.767；预算系数 0.5 × (1 + 0.595²) = 0.677。1.767 > 0.677，拦下。N = 2 时闭环系数 4.7536（+12.2%），N = 3 时 4.2460（+0.23%）（30.2 步骤 1）。
17. T(J + c)(x) = min_u [g + J(f) + c] = TJ(x) + c，所以 h = T(J + c) − (J + c) = TJ − J 不变；MPC 的目标也只差一个常数，最小点不变。归零以后还要截断，是因为定理 1 的证明要 v_T ≥ 0，J 不能是负的。截断的问题是留下一块 J = 0 的平地：平地里 TJ ≥ min g > 0 = J，处处不诚实；短时域 MPC 会停在平地边上不往里走（例子一 J = max(J\* − 0.05, 0)：N = 1 停在 x = 0.1086，每步付 0.0236）（30.2 步骤 6）。
18. 乘性误差：h ≤ e·g_μ(x)，和这一步的代价成正比，预算也和代价成正比，所以大致 e ≲ 1 − α 就处处通过，和离平衡点远近无关。加性误差：h ≤ d(x⁺) − d(x)，误差不变的地方通过，误差沿轨迹变化的地方不通过；平衡点附近误差必须回到 0，而那里预算最小，最容易不通过。单摆顶上附近更像加性误差（准确地说是形状误差）：critic 的最小值不在顶上，归零截断以后还有一块平地（30.2 步骤 8、30.3）。
19. T 是单调的：J 处处变小，TJ 也处处变小。所以 T(min(J₁, J₂)) ≤ TJ₁ ≤ J₁，同理 ≤ J₂，于是 T(min(J₁, J₂)) ≤ min(J₁, J₂)。取较大值没有这个推导，反例是"三条路"：两个 critic 各对一条路悲观，各自诚实，取较大值把两条路都堵死，TM(a) = 10 > M(a) = 2。Parallel MPC 在多个认证单元里取最小，靠的正是"诚实取最小仍诚实"（30.2 步骤 7）。
