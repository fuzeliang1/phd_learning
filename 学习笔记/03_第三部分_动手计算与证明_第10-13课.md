## 第 10 课：把 MPC 写成一个优化问题，手算一遍

第 5 课说过，MPC 每一步要"求一个最优的控制序列"。这一课把它完整地写出来，亲手解一次。

### 10.1 例子

还是 x⁺ = 2x + u，阶段代价 x² + u²，约束 |u| ≤ 1、|x| ≤ 2。从 x₀ = 0.4 出发，这次往前看 **N = 2** 步。终端代价用 J_B = (13/3)·x²，终端集合是 |x| ≤ 2/3。

### 10.2 第一步：确定决策变量

要决定的是两步的控制量：**u₀ 和 u₁**。这两个数叫**决策变量**，优化问题就是要找到它们的最佳取值。

### 10.3 第二步：用模型把未来的状态写成决策变量的函数

- x₁ = 2 × 0.4 + u₀ = 0.8 + u₀
- x₂ = 2x₁ + u₁ = 2 × (0.8 + u₀) + u₁ = 1.6 + 2u₀ + u₁

### 10.4 第三步：写出目标函数

两步的阶段代价，加上终端代价：

> 目标 = x₀² + u₀² + x₁² + u₁² + (13/3)·x₂²
> = 0.16 + u₀² + (0.8 + u₀)² + u₁² + (13/3)·(1.6 + 2u₀ + u₁)²

把括号逐项展开：
- (0.8 + u₀)² = 0.64 + 1.6·u₀ + u₀²
- (1.6 + 2u₀ + u₁)² = 2.56 + 6.4·u₀ + 3.2·u₁ + 4u₀² + 4u₀u₁ + u₁²

乘上 13/3 再合并同类项：

| 项 | 来源 | 系数 |
|---|---|---|
| 常数 | 0.16 + 0.64 + (13/3) × 2.56 | 11.893（= 892/75） |
| u₀ | 1.6 + (13/3) × 6.4 | 29.333（= 88/3） |
| u₁ | (13/3) × 3.2 | 13.867（= 208/15） |
| u₀² | 1 + 1 + (13/3) × 4 | 19.333（= 58/3） |
| u₁² | 1 + 13/3 | 5.333（= 16/3） |
| u₀u₁ | (13/3) × 4 | 17.333（= 52/3） |

所以：

> 目标 = 11.893 + 29.333·u₀ + 13.867·u₁ + 19.333·u₀² + 5.333·u₁² + 17.333·u₀u₁

这是一个关于 (u₀, u₁) 的二次函数。

**它是"碗"而不是"马鞍"**：二次项可以写成矩阵形式 [u₀, u₁]·M·[u₀, u₁]ᵀ，其中 M = [[19.333, 8.667], [8.667, 5.333]]（交叉项 17.333 平分到两个非对角元）。M 的两个对角元都为正，行列式 19.333 × 5.333 − 8.667² ≈ 28 > 0，所以 M 是正定的，函数图像是一个碗，只有一个最低点。碗形的函数叫**凸函数**。

### 10.5 第四步：写出约束

| 原约束 | 展开成 u₀、u₁ 的不等式 |
|---|---|
| \|u₀\| ≤ 1 | u₀ ≤ 1，−u₀ ≤ 1 |
| \|u₁\| ≤ 1 | u₁ ≤ 1，−u₁ ≤ 1 |
| \|x₁\| ≤ 2 | 0.8 + u₀ ≤ 2（即 u₀ ≤ 1.2），−(0.8 + u₀) ≤ 2（即 u₀ ≥ −2.8） |
| 终端集合 \|x₂\| ≤ 2/3 | 1.6 + 2u₀ + u₁ ≤ 2/3，−(1.6 + 2u₀ + u₁) ≤ 2/3 |

注意 |x₁| ≤ 2 这一行：已经有 |u₀| ≤ 1 了，u₀ ≤ 1.2 和 u₀ ≥ −2.8 自动满足。这种"被别的约束蕴含、去掉也不影响结果"的约束叫**冗余约束**。第 11 课计算不变集时，要不断去掉冗余约束。

"凸的二次目标 + 线性不等式约束"，这种问题就叫**二次规划（QP）**。求解器通常要求的标准形式是：

> 最小化 ½·zᵀHz + fᵀz，要求 Gz ≤ h

本例中 z = (u₀, u₁)，H = [[38.667, 17.333], [17.333, 10.667]]（即 2M），f = (29.333, 13.867)，G 和 h 由上表的不等式排成。

### 10.6 第五步：求解

**先不管约束，找碗底。** 对 u₀、u₁ 分别求偏导，令其为 0：

> ∂/∂u₀：29.333 + 38.667·u₀ + 17.333·u₁ = 0
> ∂/∂u₁：13.867 + 17.333·u₀ + 10.667·u₁ = 0

这是一个二元一次方程组。用克莱姆法则：
- 系数行列式 = 38.667 × 10.667 − 17.333² = 412.44 − 300.44 = **112**（精确值：(116/3)(32/3) − (52/3)² = (3712 − 2704)/9 = 112）；
- u₀ = [(−29.333) × 10.667 − (−13.867) × 17.333] ÷ 112 = (−312.89 + 240.36) ÷ 112 = **−0.6476**（精确值 −68/105）；
- u₁ = [38.667 × (−13.867) − 17.333 × (−29.333)] ÷ 112 = (−536.18 + 508.44) ÷ 112 = **−0.2476**（精确值 −26/105）。

**再检查约束**：
- |u₀| = 0.648 ≤ 1 ✓，|u₁| = 0.248 ≤ 1 ✓；
- x₁ = 0.8 − 0.648 = 0.152（精确值 16/105），|x₁| ≤ 2 ✓；
- x₂ = 1.6 − 1.295 − 0.248 = 0.057（精确值 2/35），在 2/3 以内 ✓。

约束全部满足，所以碗底就是答案。代回目标函数，最优值 = **0.6781**（精确值 356/525）。

**如果碗底违反了某个约束**（比如本部分自测题第 1 题把终端集合改成 |x₂| ≤ 0.01），最优解就会落在约束的边界上，需要求解器来处理。求解器做的就是这件事，只是变量多时用矩阵算。

### 10.7 第六步：只执行第一步

执行 u₀ = −0.648，到下一个状态后重新列式、重新解。

### 10.8 "往前看几步"的效果

| 做法 | 从 0.4 出发的预测值 |
|---|---|
| 往前看 1 步（第 5 课） | 0.6800 |
| 往前看 2 步（本课） | 0.6781 |
| 真实最优 J\* | 0.6778 |

看得越远越接近最优。在这个例子里，看 1 步就已经很接近了，因为终端代价 J_B 本身就很好。

### 10.9 两种写法：压缩写法和稀疏写法

本课把 x₁、x₂ 代入、消掉了，只留下 u 作为变量，这叫**压缩写法**（condensed）。

另一种写法是把 x₁、x₂ 也当作变量，再加上等式约束"x₁ = 0.8 + u₀"和"x₂ = 2x₁ + u₁"，这叫**稀疏写法**（sparse）。系统是非线性时，这种写法也叫**多重打靶**（multiple shooting）。两种写法的答案相同，但稀疏写法变量多、矩阵稀疏，时域长或系统非线性时数值上更稳。单摆实验用 CasADi 写的 NMPC 就是多重打靶。

## 第 11 课：不变集是怎么算出来的

第 6 课说不变集是"进去了就出不来、而且在里面一直合法"的区域。这一课看它到底怎么算。

### 11.1 一维的情况为什么太简单

在主例子里，局部控制律 u = −1.5x，约束 |u| ≤ 1、|x| ≤ 2：
- 先要求"现在合法"：|1.5x| ≤ 1 且 |x| ≤ 2，即 |x| ≤ 2/3；
- 再检查"下一步也合法"：x⁺ = 0.5x，|0.5x| ≤ 1/3 ≤ 2/3，自动满足。

所以 |x| ≤ 2/3 一步就是不变集，看不出算法的作用。下面换一个二维的例子。

### 11.2 二维例子

原论文例 4.1 的系统（可以理解成一个简化的小车，x₁ 像位置，x₂ 像速度）：

> x₁⁺ = x₁ + x₂ + u
> x₂⁺ = x₂ + 0.5u

约束：|x₁| ≤ 5，|x₂| ≤ 5，|u| ≤ 1。

局部控制律用 LQR（权重 Q = 单位矩阵，R = 1）：**u = −0.520·x₁ − 0.940·x₂**。代进去，闭环系统是：

> x₁⁺ = 0.480·x₁ + 0.060·x₂
> x₂⁺ = −0.260·x₁ + 0.530·x₂

它的特征值大小是 0.52，小于 1，所以是稳定的：不管从哪里出发，状态都会缩向 0。

问题是：**从哪些状态出发，用这个控制律一直走下去，都不会违反约束？**

### 11.3 第 0 轮：先满足"现在不违反"

先要求当前这一步合法：

> |x₁| ≤ 5，|x₂| ≤ 5，|0.520·x₁ + 0.940·x₂| ≤ 1

最后一条说的是"控制量不超限"。这个区域记作 Ω₀。

Ω₀ 只有 4 条边，因为 |x₂| ≤ 5 是冗余的：在 |x₁| ≤ 5 的范围内，|0.520·x₁ + 0.940·x₂| ≤ 1 已经要求 |x₂| ≤ (1 + 0.520 × 5)/0.940 = 3.83 < 5。所以 Ω₀ 是一个平行四边形：左右两条边是 x₁ = ±5，上下两条边是"控制量刚好等于 ±1"的直线。它的面积 = 宽 10 × 竖直方向的厚度 2/0.940 = **21.3**（整个 10×10 的盒子面积是 100）。

**Ω₀ 还不是不变集。反例**：x = (−1.65, 1.95)。
- 现在：u = −0.520 × (−1.65) − 0.940 × 1.95 = −0.975，合法，所以 x 在 Ω₀ 里；
- 下一步：x⁺ = (−0.675, 1.462)，这时控制律要求 u = −1.024，超过了 1。

现在合法，下一步就不合法了。这种点要去掉。

### 11.4 迭代：一轮轮"往前看一步"

规则：

> Ω₁ = {在 Ω₀ 里，**并且**下一步也在 Ω₀ 里的点}
> Ω₂ = {在 Ω₁ 里，**并且**下一步也在 Ω₁ 里的点}
> ……一直到某一轮不再变化为止

每一轮只是加几条线性不等式。设 Ω_k 写成 H·x ≤ h，闭环矩阵是 A_cl，那么"下一步也在 Ω_k 里"就是 H·(A_cl·x) ≤ h，即 (H·A_cl)·x ≤ h。把这些新不等式加进去，再去掉冗余的，就得到 Ω_{k+1}。

判断一条不等式 a·x ≤ b 是否冗余：在其余不等式围成的区域里求 a·x 的最大值（这是一个线性规划，LP），如果最大值不超过 b，它就是冗余的。

| 轮次 | 边数 | 面积 |
|---|---|---|
| Ω₀ | 4 | 21.3 |
| Ω₁ | 6 | 14.7 |
| Ω₂ | 6 | 13.7 |
| Ω₃ | 和 Ω₂ 相同，停止 | 13.7 |

两轮之后就不变了：Ω₂ 里的每一个点，下一步都还在 Ω₂ 里。所以 Ω₂ 就是**最大的不变集**，论文里记作 S₁。

### 11.5 为什么会停下来

因为闭环系统每步把状态缩小到大约一半（特征值 0.52）。会违反约束的点，一般在头几步就违反了；能撑过头几步的点，之后已经缩得很小，不会再违反。所以迭代很快收敛。

### 11.6 和论文、代码的对应

- 论文附录 A 说"S₁ 用 MPT 工具箱的 `invariantSet()` 计算"，做的就是这个迭代。复现时用 Python 重写成了 `idea_checks/pr_mpc_repro.py` 里的 `max_invariant` 函数，算出的 S₁ 正是 6 条边。
- 另一种做法：用椭圆 {x : xᵀPx ≤ c} 做终端集。椭圆是 Lyapunov 函数的"等高线"，等高线以内的点，Lyapunov 函数只降不升，自然出不去。单摆实验里的认证椭圆就是这样构造的：在很多采样点上检查下降条件，取所有采样点都满足的最大等高线。

## 第 12 课：松弛系数 α 和定理 1 的完整证明

这一课把方向一的定理 1 逐行证明一遍。证明很短，但每一步都有讲究。

### 12.1 先回顾第 6 课的结论

如果终端价值诚实，那么每走一步：

> 今天的预测值 ≤ 昨天的预测值 − 昨天付的阶段代价

记作 v_{t+1} ≤ v_t − g_t，其中 v_t 是第 t 步 MPC 的预测值（最优值），g_t 是第 t 步实际付的阶段代价。

### 12.2 为什么要"放宽"：引入 α

学来的价值不精确，要求每一步"降够整整一个 g"太苛刻。方向一放宽成：

> v_{t+1} ≤ v_t − α·g_t，其中 0 < α ≤ 1

- α = 1 就是原来的严格条件；
- α = 0.5 的意思是：每走一步，预测值至少降下这一步代价的一半就行。

相应地，终端检验也放宽成：

> TJ(x_N) − J(x_N) ≤ (1 − α)·g(x_t, u_0)

意思是允许学习价值有一点自相矛盾，但矛盾的程度不能超过当前一步代价的 (1 − α) 倍。

**数例：一个略偏乐观的价值也能通过。**

取 J(x) = 4.0·x²，比真实的 4.236x² 低 5.6%。按第 3.5 节的表，它不满足严格的 TJ ≤ J（TJ 的系数是 4.2 > 4.0）。
- MPC（往前看 1 步）在 x = 0.4 处：最小化 0.16 + u² + 4·(0.8 + u)²，求导 2u + 8·(0.8 + u) = 0，得 u = −0.64，终点 x₁ = 0.16，当前一步的代价 g = 0.16 + 0.4096 = 0.5696。
- 在终点检验：TJ(0.16) − J(0.16) = (4.2 − 4.0) × 0.16² = 0.2 × 0.0256 = **0.0051**。
- 允许的上限：(1 − 0.5) × 0.5696 = **0.285**。
- 0.0051 远小于 0.285，**通过**。

对比第二部分的陷阱：自相矛盾的程度 0.404，上限 0.051，**不通过**。

所以检验对"处处有点偏差"很宽容，只拦"局部大错"。这正是我们想要的。

### 12.3 定理 1 的陈述

> 如果从第 0 步到第 T−1 步，断裂监测一次都没有报警（每一步都满足 v_{t+1} ≤ v_t − α·g_t），那么这 T 步的总代价 g₀ + g₁ + … + g_{T−1} ≤ v₀ / α。

### 12.4 逐行证明

**第一步：写出每一步的不等式。**

> v₁ ≤ v₀ − α·g₀
> v₂ ≤ v₁ − α·g₁
> ……
> v_T ≤ v_{T−1} − α·g_{T−1}

**第二步：把它们全部加起来。** 左边是 v₁ + v₂ + … + v_T，右边是 v₀ + v₁ + … + v_{T−1} − α·(g₀ + … + g_{T−1})。两边相同的项 v₁ 到 v_{T−1} 抵消，剩下：

> v_T ≤ v₀ − α·(g₀ + g₁ + … + g_{T−1})

这种"中间项全部抵消"的求和叫**伸缩求和**（telescoping sum）。

**第三步：移项。**

> α·(g₀ + … + g_{T−1}) ≤ v₀ − v_T

**第四步：用"预测值不会是负数"。** 因为 v_T ≥ 0，所以 v₀ − v_T ≤ v₀：

> α·(g₀ + … + g_{T−1}) ≤ v₀

两边除以 α，证毕。T 可以任意大，所以无穷多步的总代价也不超过 v₀/α。

**第四步的讲究**：这一步要求预测值永远 ≥ 0。阶段代价本身是非负的，但学出来的价值网络可能输出负数。如果某处输出 −1，第四步就只能得到 α·(总代价) ≤ v₀ + 1，原来的界就失效了。所以方向一规定学习价值必须**截断为非负**（负数一律当 0）。这种"证明里用到的小条件"，正是读论文时要特别留意的。

**另一个讲究**：定理的条件"断裂监测没有报警"是在运行中逐步检查的。也就是说，这个保证是"边跑边确认"的，每一步都知道它还成立不成立。

### 12.5 用玩具例子的真实数字走一遍

方向一玩具例子里，从 x₀ = 0.2 出发、加检验的那次运行（α = 0.5），每一步的记录：

| 步 | 状态 | 选中单元 | 预测值 v | 这一步代价 g | 检查 v_{下一步} ≤ v − 0.5g |
|---|---|---|---|---|---|
| 0 | 0.2 | D | 0.1696 | 0.1456 | 下一步 0.0239 ≤ 0.0968 ✓ |
| 1 | 0.075 | C | 0.0239 | 0.0200 | 下一步 0.0038 ≤ 0.0139 ✓ |
| 2 | 0.03 | C | 0.0038 | 0.0034 | 下一步 0.0004 ≤ 0.0021 ✓ |
| 3 | 0.01 | B | 0.0004 | 0.0003 | 下一步 0.0001 ≤ 0.00025 ✓ |

每一步都满足，没有断裂。定理 1 给出：总代价 ≤ 0.1696 / 0.5 = **0.339**。实际总代价 **0.1695**。

界成立，但松了一倍，因为 α = 0.5。这就是"1/α 因子在 α 小时会很松，实验里必须同时报告实际代价"的原因。

### 12.6 断裂了怎么办：定理 2

如果在第 b 步报警，就锁定只用认证单元。总代价分成两段：
- 报警之前花的：用前面的伸缩求和算出上界 (v₀ − v_{b−1})/α，再加上第 b−1 步的代价；
- 报警之后花的：认证单元诚实，用第 6 课的结论，不超过认证单元在报警时刻的预测值。

两段相加，就是一个"事后算得出来"的上界。

**数例**（`idea_checks/break_search.py` 里 α = 0.9 的一次真实断裂）：
- 实际总代价 3.165；
- 定理 2 给出的界 3.170；
- 定理 1 的界 v₀/α = 3.193（断裂后它不再保证成立）。

定理 2 的界几乎贴着实际值。

### 12.7 为什么不能保证"永远不断裂"

断裂需要三件事同时发生：
1. 学习单元新解的终点检验失败；
2. 移位候选的检验也失败；
3. 其他候选又都不够低。

玩具实验里只在 α = 0.9 时出现过，而且只来自"在目标附近整体偏低一个常数"这类误差。什么条件下一定不会断裂，就是还没证明的**命题 5**，也是这个方向真正的理论难点。

## 第 13 课：怎么读原论文 Parallel MPC

到这里，读原论文（仓库里的 `Parallel Model Predictive Control for Deterministic Systems.pdf`）需要的概念都已经讲过了。这一课把论文的符号和命题，一一对上前面的课。

### 13.1 符号对照

| 论文写法 | 意思 | 对应的课 |
|---|---|---|
| X，U(x) | 所有状态的集合；在状态 x 处允许的控制 | 第 1 课 |
| f(x, u) | 模型：下一状态 | 第 1 课 |
| g(x, u) | 阶段代价 | 第 2 课 |
| δ_C | 指示函数：在集合 C 里为 0，在外面为 ∞ | 见下面 |
| E⁺(X) | 所有取值在 [0, ∞] 的函数 | 价值函数都在这里面 |
| μ，J_μ | 控制律；控制律 μ 的总代价 | 第 2.4 节的方法甲、乙、丙 |
| T | Bellman 算子，往前试走一步 | 第 3.3 节 |

两个读论文的关键点：

1. **"违反约束 = 代价无穷大"。** 论文把约束写进代价里：g(x, u) = x² + u²（如果 |x| ≤ 2），否则 g = ∞。这样约束和代价合成了一个函数，公式更简洁。终端集合也一样：单元 B 的终端价值写成 J₂(x) = (13/3)·x²（如果 |x| ≤ 2/3），否则 ∞；用指示函数写就是 (13/3)·x² + δ_{|x| ≤ 2/3}(x)。
2. **"T^ℓ J 就是 MPC 的预测值"。** 第 5 课的 0.680 就是 (T J_B)(0.4)，第 10 课的 0.6781 就是 (T² J_B)(0.4)。

### 13.3 把命题 3.3 的证明翻译成白话

论文的证明用算子写，看起来很抽象，其实就是第 6 课的移位论证。记 W = T^{ℓ−1} J̄（"少看一步的预测值"）。

**论文第一行**：g(x, μ̃(x)) + W(下一状态) = (T^ℓ J̄)(x) ≤ W(x)。
- 白话："这一步的代价 + 下一状态的 W"就是 MPC 的预测值；而 J̄ 诚实，所以多看一步不会更差，预测值 ≤ W(x)。
- 数例（ℓ = 1，W = J_B，x = 0.4）：这一步的代价 0.5825 + J_B(0.15) = 0.5825 + 0.0975 = 0.680 ≤ J_B(0.4) = 0.693。

**论文第二步**：按命题 2.1(b)，W 就像一笔"存款"：按 MPC 走一步、付掉 g 之后，存款不增加。所以真实总代价 ≤ W。

**论文第三步**：真实总代价 = 这一步的 g + 从下一状态起的真实总代价 ≤ g + W(下一状态) = 预测值。

结论：从 0.4 出发，这个 MPC 的真实总代价 ≤ 0.680。

### 13.4 读这类论文的方法

`学习路线_WAM车载智能体.md` 里写过读法，这里再具体一点：

1. **第一遍**：只读摘要、引言最后一段（贡献列表）、每个命题的陈述和实验表格。搞清楚"它声称做到了什么"。
2. **第二遍**：每个命题记四样东西：假设、结论、证明思路、对应到算法里的哪个部件。像 13.2 节那样列成表。
3. **第三遍**：挑核心命题，用一个最小的数例走一遍证明，像 13.3 节那样。走不通的地方，往往就是你还没懂、或者论文没写清楚的地方。
4. **最后**：复现一个表格。复现表 I 时发现了附录里三处不一致（列序、K₃ 的数值、S₄ 的范围，见 `idea_checks/README.md`），这种发现只有亲手算才能得到。

## 自测题

1. 第 10 课的问题里，如果把终端集合改成 |x₂| ≤ 0.01，碗底的解 x₂ = 0.057 还能用吗？最优值会变大还是变小？
2. 第 11 课的迭代里，为什么 Ω₁ 一定包含在 Ω₀ 里面？
3. 定理 1 的证明里，哪一步用到了"学习价值截断为非负"？如果不截断，可能出什么问题？
4. 第 10.5 节里，为什么说 |x₁| ≤ 2 是冗余约束？

## 答案

1. 不能用。0.057 超出了 0.01，最优解会被"推"到边界 x₂ = 0.01 上。约束更严，可选的范围更小，最优值只会变大（或不变），不会变小。
2. 因为 Ω₁ 的定义是"在 Ω₀ 里，**并且**下一步也在 Ω₀ 里"，比 Ω₀ 多了一个条件，所以只会更小，不会更大。每一轮都是这样，所以各轮的区域一层套一层，越来越小。
3. 第四步：用 v_T ≥ 0 把 v₀ − v_T 放大成 v₀。如果价值网络某处输出负数，比如 v_T = −1，那么只能得到 α·(总代价) ≤ v₀ + 1，原来的界 v₀/α 就不成立了。
4. 因为 x₁ = 0.8 + u₀，而 |u₀| ≤ 1 已经让 x₁ 落在 [−0.2, 1.8] 里，必然满足 |x₁| ≤ 2。去掉这条约束，可行的 (u₀, u₁) 一个都不会变多，最优解也就不变。
