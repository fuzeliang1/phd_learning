## 一、课程地图

方向一用到的背景知识是一条链，每一环都建立在前一环上：

1. 系统模型：用数学描述"现在的状态 + 施加的控制 → 下一刻的状态"。
2. 最优控制：给"好坏"定一个分数（代价），找让总分最低的控制方法。
3. 价值函数和 Bellman 方程："从某个状态出发，最少还要花多少"。这是整条链的核心。
4. LQR：没有约束时，最优控制有现成的公式解。
5. MPC：有约束时没有公式解，只能"边走边算"，每一步只往前看几步。
6. MPC 为什么可靠：终端代价、终端集合、不变集。方向一里的"诚实""检验""下降"都来自这里。
7. 非线性系统和求解器：为什么非线性 MPC 要看初值。
8. 强化学习里的价值函数：critic 是什么，为什么会估错。
9. 把学来的价值放进 MPC：原论文和方向一在这条链上的位置。
10. 动手算和证明：手解一个 MPC、算一个不变集、证明定理 1、读原论文。
11. 车辆模型和车辆 MPC：把前面的东西用到你的课题对象——汽车上。
12. 强化学习算法的演进：从 MC、TD、Q-learning、DQN 到策略梯度、Actor-Critic 和 PPO，理解价值函数训练及其与 MPC 终端价值的联系（第 21–27 课已整理，第 28–30 课待补写）。

## 三、贯穿全课程的例子

为了减少记忆负担，整个课程只用少数几个例子，后面的课不断回到它们。

**例子一：一维系统 x⁺ = 2x + u**（第 1–13 课的主力）

- 每一步状态翻倍，不加控制会发散。
- 阶段代价 g(x, u) = x² + u²。
- 约束（从第 4 课开始考虑）：|u| ≤ 1，|x| ≤ 2。
- 关键数字：
  - 无约束最优价值 J\*(x) = (2 + √5)·x² ≈ 4.236·x²，最优控制 u = −1.618·x（第 3、4 课）。
  - "每步减半"的控制律 u = −1.5x，总代价 (13/3)·x² ≈ 4.333·x²。它在 |x| ≤ 2/3 内满足 |u| ≤ 1，这就是原论文的单元 B：J_B(x) = (13/3)·x²，终端集合 |x| ≤ 2/3（第 2、6 课）。
  - 单元 A：往前看 2 步，第 2 步必须正好到达 0（附录 A）。
  - 从 x = 0.4 出发：真实最优 0.678；往前看 1 步、终端用 J_B 的 MPC 预测值 0.680；往前看 2 步为 0.6781（第 5、10 课）。

**例子二：直线上的小车**（第 1 课）

状态是位置 p 和速度 v，控制是加速度 u，每 0.1 秒更新一次。

**例子三：单摆**（第 7 课，以及方向一的余量扫描实验）

强化学习常用的 Gym Pendulum-v1 模型：θ = 0 表示竖直朝上，力矩 |u| ≤ 2，力矩不够直接把摆撑起来，必须来回摆动蓄能。

**例子四：原论文例 4.1 的二维系统**（第 11 课）

x₁⁺ = x₁ + x₂ + u，x₂⁺ = x₂ + 0.5u，约束 |x₁|, |x₂| ≤ 5，|u| ≤ 1。

**例子五：教科书参数的轿车**（第 14–20 课）

m = 1500 kg，I_z = 3000 kg·m²，重心到前轴 1.2 m、到后轴 1.6 m，轴距 2.8 m，前后轴侧偏刚度都是 80000 N/rad。这是常见量级，不是极氪的真实参数。

**例子六：五格走廊**（第五部分，第 21–27 课）

状态是 0–4 五个格子，4 是终点；动作是向左或向右，每走一步奖励 −1，折扣因子 γ = 0.9。用来手算回报、V/Q、TD 误差、策略与优势。

**例子七：双臂老虎机**（第五部分，第 25–27 课）

同一状态下选择两个动作之一，执行一次得到带噪声的奖励。用来解释策略梯度、基线、PPO 裁剪和训练稳定性。

## 四、怎样用这份笔记

1. 按顺序读，每一课只解决一个问题。读不懂的地方，先回到这一课开头的例子，用纸笔把数字重算一遍。
2. 每一部分末尾都有自测题和答案。先自己做，再看答案。
