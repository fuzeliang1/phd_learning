## 一、术语表

### 1. 控制基础（第一部分）

| 中文 | 英文 | 一句话解释 | 首次出现 |
|---|---|---|---|
| 状态 | state | 描述系统此刻所需的最少信息；知道状态和接下来的控制，就能算出未来 | 第 1.1 节 |
| 控制量、输入 | control input | 我们能施加的量，比如加速度、力矩、转角 | 第 1.1 节 |
| 离散时间、采样周期 Δt | discrete time, sampling period | 每隔 Δt 测一次状态、算一次控制 | 第 1.2 节 |
| 前向欧拉法 | forward Euler | 新值 = 旧值 + 变化率 × Δt 的离散化方法 | 第 1.2 节 |
| 稳定 / 不稳定 / 临界 | stable / unstable / marginally stable | 不加控制时状态趋于 0 / 发散 / 既不趋于 0 也不成倍放大 | 第 1.4 节 |
| 特征值 | eigenvalue | 多维线性系统里决定稳定性的数；绝对值全部小于 1 才稳定 | 第 1.4 节 |
| 阶段代价 | stage cost | 每一步的花费，例如 x² + u² | 第 2.1 节 |
| 权重 | weight | 代价里各项的系数，决定"更在乎精度还是更在乎省力" | 第 2.2 节 |
| 总代价 | total cost | 按某个控制方法一直走下去，所有阶段代价之和 | 第 2.3 节 |
| 最优控制 | optimal control | 让总代价最小的控制方法 | 第 2.4 节 |
| 价值函数、最优代价函数、剩余代价 | value function, optimal cost, cost-to-go | 从某个状态出发，最少还要花多少，记作 J\*(x) | 第 3.1 节 |
| Bellman 方程 | Bellman equation | J\*(x) = 在所有 u 里取最小 [g(x, u) + J\*(下一状态)] | 第 3.2 节 |
| 动态规划 | dynamic programming | 利用 Bellman 方程求最优控制的方法 | 第 3.2 节 |
| Bellman 算子 T | Bellman operator | (TJ)(x) = 在所有 u 里取最小 [g(x, u) + J(下一状态)]，"往前试走一步，再用 J 估计剩下的" | 第 3.3 节 |
| 不动点 | fixed point | 满足 J = TJ 的函数；J\* 就是 T 的不动点 | 第 3.3 节 |
| 值迭代 | value iteration | 从一个粗糙的 J 开始反复用 T，逼近 J\* | 第 3.4 节 |
| 诚实（L-region） | L-region | 满足 TJ ≤ J 的终端价值，是真实最少花费的上界 | 第 3.5 节 |
| LQR（线性二次调节器） | linear quadratic regulator | 线性系统、二次代价、无约束时最优控制的公式解 u = −Kx | 第 4.1 节 |
| Riccati 方程 | Riccati equation | LQR 中矩阵 P 满足的方程，就是把二次函数代进 Bellman 方程的结果 | 第 4.1 节 |
| 增益 | gain | 线性控制律 u = −Kx 中的 K | 第 4.1 节 |
| 约束 | constraint | 控制量或状态必须满足的限制，例如 \|u\| ≤ 1 | 第 4.2 节 |
| 截断（饱和） | saturation, clipping | 控制量超限时直接取限值 | 第 4.2 节 |
| MPC（模型预测控制） | model predictive control | 每一步往前预测 N 步、求最优、只执行第一步 | 第 5.1 节 |
| 预测时域 | prediction horizon | MPC 往前看的步数 N（论文里写作 ℓ） | 第 5.1 节 |
| 滚动时域 | receding horizon | 计划总往前看 N 步，每次只执行一步，然后重新规划 | 第 5.2 节 |
| 终端代价、终端价值 | terminal cost, terminal value | 对第 N 步之后剩余代价的估计 J_f(x_N) | 第 5.1 节 |
| 终端集合 | terminal set | 第 N 步的终点必须落在的安全区 X_f | 第 6.2 节 |
| 不变集 | invariant set | 用某个控制律，进去了就出不来、而且在里面一直满足约束的区域 | 第 6.2 节 |
| 局部控制律 | local controller | 在终端集合里使用的已知控制律，例如 u = −1.5x | 第 6.3 节 |
| 下降条件 | decrease condition | J_f(下一状态) + g ≤ J_f(当前状态) | 第 6.3 节 |
| 移位候选 | shifted candidate | 上一步的计划去掉第一步、末尾补一步得到的候选计划 | 第 6.4 节 |
| Lyapunov 函数 | Lyapunov function | 只降不升且不小于 0 的量，保证系统稳定 | 第 6.5 节 |
