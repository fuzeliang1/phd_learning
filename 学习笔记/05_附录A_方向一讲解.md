## 一、例子：一个会"自己跑掉"的系统

**系统**：x 是一个数（状态），u 是每一步施加的控制量。规则是

> 下一步的状态 = 2 × 现在的状态 + 控制量，即 x⁺ = 2x + u。

控制量受限：|u| ≤ 1。

不加控制，x 每步翻倍：0.2 → 0.4 → 0.8 → 1.6……这是一个不稳定的系统。我们的任务是把 x 拉回 0。（第 1 课）

**代价**：每走一步付出 g = x² + u²。偏离 0 越远、用力越大，付出越多。

> 例：x = 0.225 时取 u = −0.225，下一步 x⁺ = 0.45 − 0.225 = 0.225（原地不动）。这一步的代价是 0.225² + 0.225² = 0.101。

**目标**：从起点出发，一直走下去，所有步的代价加起来最小。这个最小总代价记作 **J\*(x)**，叫"最优价值"。例如 J\*(0.2) = 0.169，J\*(0.45) = 0.858，J\*(0.9) = 4.975。（第 2、3 课）

## 二、MPC 在做什么：只往前看几步，末尾"估一下"

无限多步没法直接算。MPC 的做法是：

1. 只往前规划 N 步（例子里 N = 1 或 2）；
2. 第 N 步的终点 x_N 之后还剩无穷多步，代价用一个函数 J(x_N) **估计**，这个 J 叫**终端价值**；
3. 求出"N 步代价 + J(x_N)"最小的方案，但**只执行第一步**；
4. 到了新状态，重新规划。

所以终端价值 J 决定了 MPC 的好坏。（第 5 课）

- **J 估高了**（悲观）：MPC 会保守一点，但不会出大事。
- **J 估低了**（乐观）：MPC 会被骗。它以为某处"剩下的路几乎不花钱"，就拼命往那里跑。

---

## 三、什么样的终端价值算"诚实"

传统 MPC 理论要求 J 是**诚实的上界**：确实存在一个具体的控制办法，从 x 出发真能做到代价不超过 J(x)。

**例子（论文里的单元 B）**：取控制律 u = −1.5x，每步 x 变成原来的一半（2x − 1.5x = 0.5x）。

- 每步代价是 x² + (1.5x)² = 3.25x²；
- 之后每步代价变成上一步的 1/4，总和 = 3.25x² ÷ (1 − 1/4) = (13/3)·x²。

所以 J_B(x) = (13/3)·x² 是诚实的：用 u = −1.5x 就真能做到。但它只在 |x| ≤ 2/3 时成立，因为再大的话 |u| = 1.5|x| 会超过 1。超出这个范围就令 J_B = ∞，表示"这里我不保证"。

**怎么检验诚实（这是方向一的核心工具）**：在某个状态 x 上"往前试走一步"，看看 J 是否自相矛盾。

- 试走一步的结果记作 **TJ(x)**，意思是"最好地走一步的真实代价 + 用 J 估计下一步之后的代价"。
- 如果 J 诚实，那么"多走一步再估"不会比"直接估"更差，即 **TJ(x) ≤ J(x)**。论文把满足这个条件的 J 叫做在 "L-region" 里，可以理解为"诚实条件"。（第 3.5 节）

> 数例：x = 0.3 时，J_B(0.3) = 13/3 × 0.09 = 0.390。试走一步，最优取 u ≈ −0.49，算出 TJ_B(0.3) = 0.3825。0.3825 ≤ 0.390，检验通过，J_B 在这里是诚实的。

## 四、原论文 Parallel MPC 做了什么

原论文的想法：同时准备**好几个 MPC**（论文叫"单元"）。每个单元的时域和终端价值各不相同，并行求解，**谁预测的总代价最低，就执行谁的第一步**。

例子里有两个单元，都是诚实的：

| 单元 | 往前看几步 | 终端价值 |
|---|---|---|
| A | 2 步 | 必须在第 2 步正好到达 0，此后代价为 0 |
| B | 1 步 | J_B = 13/3 · x²，只在 \|x\| ≤ 2/3 内有效 |

**原论文的保证**：只要每个单元的 J 都诚实，实际总代价 ≤ 开始时预测的最低值。

**它的局限**：诚实的 J 必须离线设计出来，所以往往很保守、覆盖范围小。

### 为什么 19 个起点里只有 17 个能用

先分清两个东西：
- **单元**：A 和 B，是两个 MPC；
- **起点**：系统从哪里开始走。实验取了 19 个起点：−0.9, −0.8, −0.7, …, 0, …, 0.7, 0.8, 0.9，每隔 0.1 取一个。

**一个起点算"能用"的条件**：A 和 B 里至少有一个能从这里出发算出合法的计划。两个都算不出来，这个起点才算"不能用"。

由于对称，看正半边就够了，负半边结论相同。

**单元 A 能用的范围**：两步后 x₂ = 4x + 2u₀ + u₁ 必须等于 0。2u₀ + u₁ 最多能抵消 2 × 1 + 1 = 3，所以需要 4x ≤ 3，即 **x ≤ 0.75**。

**单元 B 能用的范围**：一步后 x₁ = 2x + u 必须落在 2/3 ≈ 0.667 以内。u 最多抵消 1，所以需要 2x − 1 ≤ 0.667，即 **x ≤ 0.833**。

| 起点 | A：4x 是否 ≤ 3 | B：2x − 1 是否 ≤ 0.667 | 这个起点能用吗 |
|---|---|---|---|
| 0, 0.1, …, 0.7 | 能（0.7 时 4x = 2.8 ≤ 3） | 能 | 能 |
| 0.8 | 不能（3.2 > 3） | 能（1.6 − 1 = 0.6 ≤ 0.667） | 能，靠 B |
| 0.9 | 不能（3.6 > 3） | 不能（1.8 − 1 = 0.8 > 0.667） | **不能** |

以 0.7 为例，A 确实能在两步内到 0：取 u₀ = −1，x₁ = 1.4 − 1 = 0.4；再取 u₁ = −0.8，x₂ = 0.8 − 0.8 = 0。

数一下：正半边只有 0.9 不能用，负半边同理只有 −0.9 不能用。19 个起点里有 2 个不能用，所以 19 − 2 = **17 个能用**。

（最初讲的时候把"0.9 这个起点上两个单元都失败"说成了"两个单元不能用"，容易误解。准确的说法是：0.9 和 −0.9 这**两个起点**上，**两个单元都**算不出计划。讲"可行域"时要分清单元和起点。）

## 五、想用"学出来的"价值，会出什么事

现实中有很多**学出来的**价值函数：强化学习的 critic、用数据拟合的神经网络、世界模型的价值头。它们的优点是覆盖范围大，大部分地方也接近真实值；缺点是**没人保证它诚实**，某些地方可能偏低。（第 8 课）

例子里人为造了两个学习单元（都往前看 2 步）：

- **C**：大部分地方等于 J\*，但在 x ≈ 0.45 附近有一个"假坑"：J_C(0.45) = 0.026，而真实值 J\*(0.45) = 0.858。它把那里的代价估低了 30 多倍。
- **D**：处处有 ±15% 的误差，但没有坑。

**如果把 A、B、C、D 放在一起直接取最小**，从 x = 0.2 出发会发生这样的事：

- 轨迹为 0.2 → 0.215 → 0.22 → 0.225 → 0.225 → 0.225 → ……，卡住不动。
- 原因：在 0.225 处，单元 C 每次都计划"这一步取 u = −0.225 原地不动，下一步取 u = 0 跳到 0.45 的坑里"，预测总代价只有 0.178，看起来最低，于是被选中。
- 但 MPC 只执行第一步，也就是"原地不动"。下一时刻又做同样的计划，又只执行"原地不动"……
- 结果每步白付 0.101 的代价，永远到不了 0。走 40 步共花 **4.22**，而最优只要 **0.169**，差了 25 倍。

19 个起点汇总：不检验直接取最小时，平均比最优差 312%，最坏 24.9 倍。

**结论**：MPC 本身是一个优化器，会**主动寻找**学习价值估错的地方去利用。学习价值不能直接拿来乐观地取最小。

## 六、方向一的做法：先检验，再取最小

单元分成两类：

- **认证单元**：离线证明诚实的，如 A、B。它们永远可用，是保底。
- **学习单元**：学出来的，如 C、D。每次用之前都要现场检验。

每个时刻做五件事。

### 第 1 件：各单元并行求解

每个单元给出三样东西：预测总代价、要执行的第一步控制、计划的终点 x_N。

### 第 2 件：终端检验（只检验学习单元）

不需要检验整个函数，**只在这一次计划的终点 x_N 上**做第三节那个"试走一步"的检验。为了现实中能通过，允许一点误差，误差上限和当前这一步的代价挂钩：

> TJ(x_N) − J(x_N) ≤ (1 − α) × 当前这一步的代价

α 是一个 0 到 1 之间的数，例子里取 0.5。式子的意思是："学习价值在终点自相矛盾的程度，不能超过当前这一步代价的一半。"（第 12.2 节）

> **数例：看检验怎么识破那个坑。** 在 x = 0.225 处，单元 C 的计划终点是 0.45。
> - 学习价值说：J_C(0.45) = 0.026。
> - 试走一步：TJ_C(0.45) = 0.430。其实光是 0.45 这一步本身就要付 0.45² = 0.2025，已经远超 0.026。
> - 自相矛盾的程度：0.430 − 0.026 = 0.404。
> - 允许的上限：(1 − 0.5) × 0.101 = 0.051。
> - 0.404 > 0.051，**检验不通过，这次不许用 C。**

检验只多花一次"走一步"的小优化，计算量很小。

### 第 3 件：上一步的计划也算一个候选，但同样要检验

上一步选中的计划已经执行了第一步，剩下的部分去掉第一步、末尾补一步，就是这一步的一个现成候选，叫**移位候选**。（第 6.4 节）

它也必须在新终点上做同样的检验。第一版代码漏了这一点，结果单元 C 的计划通过移位候选"偷渡"进来，又把轨迹带进坑里卡住。修正后才正常。这个漏洞本身可以写进论文，说明为什么移位候选也必须检验。

### 第 4 件：在"通过检验的学习单元 + 移位候选 + 认证单元"中取最小

和原论文一样，取预测代价最低的那个，执行第一步。

### 第 5 件：断裂监测

正常情况下，每走一步，"预测的剩余总代价"至少要下降 α × 这一步的代价：

> 这一步的预测值 ≤ 上一步的预测值 − α × 上一步的代价

如果某一步没有降够，就说明"证书链断了"。此后锁定为**只用认证单元**。

## 七、检验之后的效果

还是从 x = 0.2 出发，加了检验：

| 步 | 状态 | 被选中的单元 |
|---|---|---|
| 1 | 0.2 | D |
| 2 | 0.075 | C |
| 3 | 0.03 | C |
| 4 | 0.01 | B |
| 5 | 0.005 | A |

总代价 **0.1695**，最优是 0.1694，几乎完全一样。注意 C 并没有被永久拉黑：它的计划终点远离 0.45 时，检验能通过，照样被选用。从 x = 0.9 出发时，前三步选的都是 C，因为 C 在远处是准的。

19 个起点汇总：

| 做法 | 可行的起点 | 平均比最优差 | 最坏是最优的几倍 |
|---|---|---|---|
| 原论文，只用 A、B | 17 / 19 | 0.03% | 1.002 |
| 加上 C、D，不检验直接取最小 | 19 / 19 | 312% | 24.9 |
| 加上 C、D，先检验再取最小（方向一） | 19 / 19 | 0.49% | 1.05 |

这张表说明了方向一想要的两件事同时达到了：

1. **得到学习价值的好处**：可行起点从 17 个扩大到 19 个，学习单元覆盖了认证单元管不到的地方（±0.9）。
2. **挡住学习价值的坏处**：坑被检验挡住，代价没有失控。

后来又做了更大的测试（`idea_checks/break_search.py`）：给学习单元设计了 66 种不同的错误。不检验时，有 21 种让最坏代价超过最优的 1.5 倍，最高 15.2 倍；检验后，66 种全部不超过 1.067 倍。

## 八、能证明什么

**定理 1（不断裂时）**：如果每一步预测值都至少下降 α × 当步代价，那么实际总代价 ≤ 开始时的预测值 ÷ α。（完整证明见第 12.4 节）

道理很简单：预测值不会小于 0；每步至少下降"α × 代价"；这些下降量加起来不可能超过一开始的预测值。

> 数例：x = 0.2，加检验的那次运行。开始时预测值是 0.1696，α = 0.5，所以保证总代价 ≤ 0.1696 ÷ 0.5 = 0.339。实际总代价是 0.1695，在保证之内。

**定理 2（断裂后）**：断裂并锁定之后，仍能用运行中实际算出的量，给出一个事后的总代价上界。（第 12.6 节）

**命题 5（什么时候永远不会断裂）**：这是论文真正需要的理论贡献，目前还是猜想，没有证明。猜想的形式是：如果学习价值的误差是"按比例"的（例如处处误差在 ±15% 以内），而且时域足够长，就永远不会断裂。

测试结果支持这个猜想：按比例的误差一次断裂都没有；断裂只出现在 α = 0.9 时，而且只来自"在目标附近整体偏低一个常数"这类误差。另外，即使断裂了，在玩具例子里也没有造成实际损失。所以目前只能说断裂监测在理论上必要，**不能**说它改善了性能。

## 九、复现原论文时得到的两条新认识

1. **取最小只能保证上界，不能保证比最好的单个单元好。** 在原论文例 4.1 里，从 (−5, 2.7) 出发：
   - 单元 3 单独使用，总代价 59.717；
   - 并行取最小，总代价 60.163。

   原因是取最小时看的是预测值：单元 1 预测 60.2，比单元 3 的 60.9 低，所以选了单元 1，但单元 1 实际跑出来的结果不如单元 3。方向一用的是同样的取最小规则，所以论文里不能声称"一定优于每个单元"。

2. **原论文的三个例子几乎没有改进空间。** 那些例子里，并行 MPC 离最优只差 0 到 0.9%，学习价值再好也只能改进这么一点。所以下一步实验必须换一个"短时域 MPC 明显不够好"的系统。

（更新：之后做的余量扫描发现，认证 MPC 只要能算出计划就接近最优，学习价值的收益主要在"覆盖率"；而且在单摆上，长时域认证 MPC 并不比短时域贵多少，最强的对手是"长时域认证 MPC + 学来的初值"。详见第 9.5 节和 `idea_checks/README.md`。）

## 十、和别人的工作有什么不同

以下比较基于摘要，原文没能下载到，是否真的新还要等精读全文确认。

| 工作 | 做了什么 | 和方向一的区别 |
|---|---|---|
| 原论文 Parallel MPC | 多个单元并行，取最小 | 要求每个价值离线证明诚实，不能用学习价值 |
| AC4MPC（2026） | 学出的 critic 作终端价值，两个 MPC 并行取低者 | 只有一个学习价值，**没有在线检验** |
| Krener 自适应时域 MPC | 在线检验一个终端价值是否可信 | 只有一个、而且是解析写出的价值，用检验来调时域 |
| Simplex 架构 | 学习控制器不安全就整体切换到保底控制器 | 只管安全，不管性能；整机切换，粒度粗 |

方向一的组合是：**多个学习价值 + 每步在线检验 + 并行取最小 + 可计算的性能界**。目前没有检索到同时做这几件事的工作。

## 十一、和你的课题（车载 WAM）怎么连起来

车载世界模型（WAM）的特点是语义理解强，但运行慢，还可能"幻觉"。底层的 MPC 的特点是快、能处理约束。

方向一提供了两者之间的一个接口：
- WAM 给出"从这个状态出发，后面大概还要花多少"的估计，作为 MPC 的候选终端价值；
- 检验负责在 WAM 估错时把它挡掉，由认证单元保底。

这一点可以作为学位论文的总框架，但第一篇论文不需要真的接入 WAM。
