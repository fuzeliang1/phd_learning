## 第 14 课：描述一辆车需要哪些量

### 14.1 两套坐标

**大地坐标**：站在地面上看，车在哪里、朝哪个方向。
- X、Y：车的位置（米）；
- ψ（读作"psi"）：车头朝向和 X 轴的夹角，叫**航向角**（弧度）。

**车身坐标**：站在车上看，车在怎么动。
- v_x：沿车头方向的速度，叫**纵向速度**；
- v_y：垂直于车头方向的速度，叫**横向速度**。它表示车"侧着走"的速度，正常行驶时很小；
- r：车身转动的快慢，叫**横摆角速度**（rad/s），就是 ψ 的变化率。

### 14.2 输入

驾驶员（或自动驾驶系统）能控制的是：
- δ（读作"delta"）：**前轮转角**，方向盘转动后前轮偏转的角度。方向盘转角大约是前轮转角的 15 倍左右（这个比值叫转向传动比，不同车不同）；
- a：**纵向加速度**，也就是油门和刹车。

### 14.3 为什么叫"自行车模型"

真实的车有四个轮子。左右两个前轮的作用差不多，把它们合成一个放在车的中线上；后轮也一样。这样车就变成了"一前一后两个轮子"，像一辆自行车。

这个简化忽略了车身侧倾、左右轮的载荷转移、左右轮转角的细微差别等因素。在正常驾驶时这些影响不大，所以自行车模型是车辆控制里最常用的模型。

## 第 15 课：运动学自行车模型

### 15.1 核心假设：车轮不打滑

**每个车轮的速度方向，就是它所指的方向。** 就像冰刀：只能沿刀刃方向滑，不能侧着滑。

### 15.2 转弯半径是怎么来的

车转弯时，整辆车在绕某一个点转动，这个点叫**瞬时转动中心**。用"车轮不打滑"可以把它找出来：

1. 后轮指向车头方向，它的速度也沿车头方向，所以转动中心在"过后轮、垂直于车身"的直线上。
2. 前轮偏转了 δ，它的速度沿前轮方向，所以转动中心在"过前轮、垂直于前轮方向"的直线上。
3. 两条直线的交点就是转动中心。转动中心、后轮、前轮构成一个直角三角形：直角在后轮处，两条直角边分别是轴距 L 和转弯半径 R（转动中心到后轮的距离），而转动中心处的那个角恰好等于 δ。
4. 所以 tan δ = L / R，即 **R = L / tan δ**。

车以速度 v 沿半径 R 的圆走，车身转动的快慢就是 ψ̇ = v / R = v·tan δ / L。

### 15.3 方程（以后轴中点为参考点）

> Ẋ = v·cos ψ
> Ẏ = v·sin ψ
> ψ̇ = v·tan δ / L
> v̇ = a

前两行：后轴中点沿车头方向前进。第三行：上面刚推出来的转动快慢。第四行：速度的变化就是加速度。

### 15.4 数例

车速 v = 10 m/s（36 km/h），前轮转角 δ = 0.05 rad（约 2.9°）：
- 转弯半径 R = 2.8 / tan(0.05) = **56.0 m**；
- 横摆角速度 ψ̇ = 10 / 56 = **0.179 rad/s**；
- 侧向加速度 a_y = v²/R = 100/56 = **1.79 m/s²**（约 0.18 个重力加速度），乘客能感觉到被轻轻往外推。

**离散化**（第 1 课的前向欧拉法，Δt = 0.1 s），从 (X, Y, ψ) = (0, 0, 0) 出发：
- 第 1 步后：X = 0 + 0.1 × 10 × cos 0 = 1.0，Y = 0 + 0.1 × 10 × sin 0 = 0，ψ = 0 + 0.1 × 0.179 = 0.0179；
- 第 2 步后：X = 2.0，Y = 0 + 0.1 × 10 × sin(0.0179) = 0.0179，ψ = 0.0357。

注意 Y 比 ψ 晚一步才开始变：**先转车头，车才开始横移**。后面列路径跟踪 MPC 时，这个"先转头再横移"的结构会反复出现。

### 15.5 以重心为参考点的版本

有时需要知道重心的运动（比如和动力学模型对比）。这时重心的速度方向和车头方向之间有一个小夹角 β，叫**质心侧偏角**：

> β = arctan(l_r·tan δ / L)
> Ẋ = v·cos(ψ + β)，Ẏ = v·sin(ψ + β)，ψ̇ = v·sin β / l_r

数例：δ = 0.05 时 β = arctan(1.6 × 0.05004 / 2.8) = 0.0286 rad，ψ̇ = 10 × sin(0.0286) / 1.6 = 0.179 rad/s，和后轴版本几乎一样。

### 15.6 适用范围

"不打滑"只在低速、转弯不急时成立。常用的经验是：侧向加速度不超过 0.5·μ·g 时，运动学模型够用（Polack 等，IEEE IV 2017）。

μ 是**路面附着系数**：干燥柏油路约 0.9，湿路更小，冰面约 0.1。g = 9.81 m/s²。干路上这个上限约 0.5 × 0.9 × 9.81 = 4.4 m/s²。

优点：
- 参数只有一个轴距 L；
- 速度为 0 时也不会出问题；
- 适合停车、低速跟车、城市道路。

## 第 16 课：动力学自行车模型

### 16.1 为什么需要它：轮胎其实会"侧滑"

车速一高、转弯一急，轮胎就不再完全沿着所指的方向走。轮子所指的方向和轮子实际运动方向之间的夹角，叫**轮胎侧偏角** α。

关键事实：**轮胎的侧向力就是靠侧偏角产生的。** 可以把轮胎想成一根弹簧：侧偏角越大，侧向力越大。小角度时近似成正比：

> 侧向力 F_y = C·α

C 叫**侧偏刚度**（单位 N/rad）。数例：C_f = 80000 N/rad，侧偏角 1°（0.01745 rad），前轴侧向力 = 80000 × 0.01745 = **1396 N**。

### 16.2 轮胎力有上限

轮胎能提供的侧向力不能超过"附着系数 × 压在轮胎上的重量"：F_y ≤ μ·F_z。

- 前轴分到的重量：F_zf = m·g·l_r / L = 1500 × 9.81 × 1.6 / 2.8 = **8409 N**（重心离前轴更近，所以前轴分得多）。
- **干路**（μ = 0.9）：前轴侧向力最多 0.9 × 8409 = 7568 N。按 F = C·α，正比关系大约在侧偏角 7568/80000 = 0.0946 rad（**5.4°**）以内成立。整车侧向加速度最多约 μ·g = **8.8 m/s²**。
- **冰面**（μ = 0.1）：前轴最多 841 N，侧偏角 **0.6°** 就到顶了；侧向加速度最多约 **0.98 m/s²**。

同一辆车，冰面上能"转弯"的能力只有干路的九分之一。第 19 课会看到这对 MPC 意味着什么。

真实轮胎在饱和附近是一条平滑的曲线（常用 Pacejka 的"魔术公式"描述），本课用"直线 + 到上限截断"作简化。

### 16.3 方程（纵向速度 v_x 不变，只看横向运动）

> m·(v̇_y + v_x·r) = F_yf + F_yr    （横向的牛顿第二定律）
> I_z·ṙ = l_f·F_yf − l_r·F_yr     （绕重心的转动方程）

其中两个侧偏角由几何关系算出：

> α_f = δ − (v_y + l_f·r) / v_x
> α_r = −(v_y − l_r·r) / v_x

逐项解释：
- 第一行的 v_x·r：车在转弯时，即使横向速度不变，速度方向也在转，需要向心加速度 v_x·r。所以"横向的加速度"是 v̇_y + v_x·r，而不只是 v̇_y。
- 第二行：前轮的侧向力推车头，后轮的侧向力推车尾，两者的力矩之差决定车身转得多快。
- 侧偏角：前轮所在位置的横向速度是 v_y + l_f·r（车身转动让车头额外往侧面走），除以 v_x 就是前轮"实际运动方向"的角度；再用"前轮所指的方向 δ"减去它，就是前轮侧偏角。后轮所在位置的横向速度是 v_y − l_r·r，后轮指向车头方向（角度 0），同理得到后轮侧偏角。

**写成线性状态方程**：把 F_yf = C_f·α_f、F_yr = C_r·α_r 代进去，整理得：

> v̇_y = −(C_f + C_r)/(m·v_x)·v_y + [(l_r·C_r − l_f·C_f)/(m·v_x) − v_x]·r + (C_f/m)·δ
> ṙ = (l_r·C_r − l_f·C_f)/(I_z·v_x)·v_y − (l_f²·C_f + l_r²·C_r)/(I_z·v_x)·r + (l_f·C_f/I_z)·δ

以第一行为例说明代入过程：F_yf + F_yr = C_f·δ − C_f·(v_y + l_f·r)/v_x − C_r·(v_y − l_r·r)/v_x，两边除以 m，再减去 v_x·r，就得到第一行。

代入本部分的车：
- v_x = 10 m/s 时：A = [[−10.67, −7.87], [1.07, −10.67]]，B = [53.3, 32.0]；
- v_x = 20 m/s 时：A = [[−5.33, −18.93], [0.53, −5.33]]，B = [53.3, 32.0]。

状态是 (v_y, r)，输入是 δ，又回到了 ẋ = Ax + Bu 的形式。

### 16.4 和运动学模型比：车速越高，差得越多

同样的前轮转角，稳态时车身转得多快？

| 车速 | 动力学模型 / 运动学模型（横摆角速度之比） |
|---|---|
| 10 m/s（36 km/h） | 0.91 |
| 20 m/s（72 km/h） | 0.72 |
| 30 m/s（108 km/h） | 0.54 |

高速时，真实的车只转到运动学模型预测的一半多一点。这种"转得比预想少"的特性叫**不足转向**，大多数乘用车都被设计成这样，因为它更稳。

**不足转向的公式推导**（稳态圆周运动，半径 R，侧向加速度 a_y = v²/R）：
1. 稳态时 ṙ = 0，转动方程给出 l_f·F_yf = l_r·F_yr；横向方程给出 F_yf + F_yr = m·a_y。两式联立：F_yf = m·a_y·l_r/L，F_yr = m·a_y·l_f/L。
2. 两个侧偏角相减：α_f − α_r = δ − (l_f + l_r)·r/v_x = δ − L/R（因为 r/v_x = 1/R）。
3. 所以 δ = L/R + α_f − α_r = L/R + F_yf/C_f − F_yr/C_r = L/R + (m/L)·(l_r/C_f − l_f/C_r)·a_y。

记 K = (m/L)·(l_r/C_f − l_f/C_r)，叫**不足转向梯度**，就得到：

> **δ = L/R + K·a_y**

本部分的车 K = (1500/2.8) × (1.6 − 1.2)/80000 = **0.00268 rad/(m/s²)**，约 1.5°/g。K > 0 就是不足转向：侧向加速度越大，需要的转角比几何转角 L/R 多得越多。

再由 R = v/r、a_y = v·r，从 δ = L·r/v + K·v·r 解出稳态横摆角速度：

> r = v·δ / (L + K·v²)

运动学模型相当于 K = 0，r = v·δ/L。两者之比 L/(L + K·v²) 就是上表里的数：v = 20 时 2.8/(2.8 + 0.00268 × 400) = 0.72。

**数例：过半径 50 m 的弯，车速 10 m/s**（侧向加速度 a_y = 100/50 = 2 m/s²）
- 运动学模型：δ = arctan(2.8/50) = **0.0559 rad**（3.2°）；
- 动力学模型：δ = L/R + K·a_y = 0.056 + 0.00268 × 2 = **0.0614 rad**（3.5°），要多打约 10%。

### 16.5 动力学模型的弱点：低速时不能用

方程里有 1/v_x。速度越低，这些项越大，系统变得极快（数学上叫"刚性"）。看 16.3 节矩阵 A 的特征值：

| 车速 | 特征值 | 最快的时间常数 |
|---|---|---|
| 1 m/s | −91.9，−121.4 | 8 ms |
| 10 m/s | −10.7 ± 2.9i | 94 ms |
| 30 m/s | −3.6 ± 3.2i | 281 ms |

1 m/s 时，离散步长必须远小于 8 ms 才算得准；速度趋于 0 时方程直接失效。所以常见做法是：**低速用运动学模型，高速用动力学模型**。Kong 等（IEEE IV 2015）专门比较过两种模型用于 MPC 的效果。

## 第 17 课：路径跟踪——用"相对于路的误差"描述车

### 17.1 换一种坐标

跟踪车道中心线时，我们关心的不是车在大地上的 X、Y，而是"离车道中心线多远、车头偏了多少"。所以换成相对于路径的量：

- **e_y**：**横向误差**，车到中心线的距离（米），左正右负或反过来，取定一个方向即可；
- **e_ψ**：**航向误差**，车头方向减去路在该处的方向（弧度）；
- **s**：沿路已经走了多远；
- **κ**（读作"kappa"）：路的**曲率**，等于 1/转弯半径。直路的 κ = 0，半径 50 m 的弯 κ = 0.02。

这种"沿路方向 + 垂直于路方向"的坐标叫 Frenet 坐标。

### 17.2 运动学版本

精确的方程：

> ṡ = v·cos e_ψ / (1 − κ·e_y)
> ė_y = v·sin e_ψ
> ė_ψ = v·tan δ / L − κ·ṡ

第二行：车头和路有夹角 e_ψ，车每秒就往侧面走 v·sin e_ψ。第三行：车头转动的快慢减去路本身的转弯快慢，就是航向误差变化的快慢。

**直路上、角度很小时的简化**（κ = 0，sin e_ψ ≈ e_ψ，tan δ ≈ δ）：

> ė_y = v·e_ψ   （车头偏了，车就横移）
> ė_ψ = (v / L)·δ  （打方向，车头就转）

这是一个**双积分器**：δ 改变 e_ψ，e_ψ 再改变 e_y。和第 1 课小车的"加速度改变速度、速度改变位置"结构完全一样。

**离散化**：一步之内 δ 不变，对上式积分。
- e_ψ 以恒定速率 (v/L)·δ 变化：e_ψ(t) = e_ψ + (v/L)·δ·t；
- 再积分一次：e_y(t) = e_y + v·e_ψ·t + (v²/(2L))·δ·t²。

取 t = Δt：

> e_y⁺ = e_y + v·Δt·e_ψ + (v²·Δt² / 2L)·δ
> e_ψ⁺ = e_ψ + (v·Δt / L)·δ

对这个线性模型，这个离散化是精确的（不是欧拉近似）。代入数字（Δt = 0.1 s）：
- v = 10 m/s：A = [[1, 1], [0, 1]]，B = [0.179, 0.357]。这个 A 和原论文例 4.1 的 A 一模一样，所以第 10–11 课的 QP 列式和不变集计算可以直接搬过来用。
- v = 20 m/s：A = [[1, 2], [0, 1]]，B = [0.714, 0.714]。

**弯道**：ė_ψ = (v/L)·δ − v·κ（κ 很小时 ṡ ≈ v）。要沿着弯道稳定行驶（ė_ψ = 0），需要一个基础转角 δ = L·κ，叫**前馈转角**。半径 50 m 的弯，δ = 2.8 × 0.02 = 0.056 rad，与第 16.4 节运动学模型的结果一致。MPC 里通常把前方各点的曲率当作已知量放进预测，前馈部分自然就包含在解里。

### 17.3 动力学版本（4 个状态）

高速时要用动力学模型。状态取 (e_y, ė_y, e_ψ, ė_ψ)。

**推导**（直路上，角度很小）只需要两个代换：
- 车相对于路的横向速度 = 自身的横向速度 + 车头偏角 × 前进速度，即 ė_y = v_y + v_x·e_ψ，所以 v_y = ė_y − v_x·e_ψ；
- 航向误差的变化率就是横摆角速度，即 ė_ψ = r。

把第 16.3 节的方程记作 v̇_y = a₁₁·v_y + a₁₂·r + b₁·δ，ṙ = a₂₁·v_y + a₂₂·r + b₂·δ。然后：

> ë_y = v̇_y + v_x·ė_ψ = a₁₁·ė_y − a₁₁·v_x·e_ψ + (a₁₂ + v_x)·ė_ψ + b₁·δ
> ë_ψ = ṙ = a₂₁·ė_y − a₂₁·v_x·e_ψ + a₂₂·ė_ψ + b₂·δ

代入 v_x = 20 m/s 的数字（a₁₁ = −5.333，a₁₂ = −18.933，a₂₁ = 0.533，a₂₂ = −5.333，b₁ = 53.33，b₂ = 32.0）：

> A = [[0, 1, 0, 0], [0, −5.33, 106.7, 1.07], [0, 0, 0, 1], [0, 0.53, −10.67, −5.33]]
> B = [0, 53.3, 0, 32.0]

例如第二行第三列：−a₁₁·v_x = 5.333 × 20 = 106.7；第二行第四列：a₁₂ + v_x = −18.933 + 20 = 1.07。

**核对**：用非线性动力学模型仿真了 3 秒的正弦转向（幅值 0.01 rad、频率 0.5 Hz），这个线性模型预测的 e_y 和非线性模型只差 **0.009 cm**（3 秒后两者都是 0.876 m）。

**一个重要性质**：这个模型的每一个元素都是 C_f、C_r 的线性函数。选题文档方向二的 C3（"横向误差动力学对侧偏刚度是仿射的，正好满足 RALMPC 的假设"）说的就是它：路面变化导致 C_f、C_r 变化时，A、B 按线性规律变化。

弯道上还会多出一项和期望横摆角速度 v_x·κ 有关的输入，做法和 17.2 节的前馈一样，这里不展开。

## 第 18 课：路径跟踪 MPC 怎么列式（高速换道）

### 18.1 场景

车速 20 m/s（72 km/h），向右换一条车道。中国高速公路的车道宽 3.75 m。以目标车道中心为 e_y = 0，车一开始在原车道中心 e_y = 3.75，车头沿路的方向（e_ψ = 0），前轮转角为 0。

### 18.2 模型

用第 17.2 节 v = 20 m/s 的运动学误差模型，Δt = 0.1 s：

> e_y⁺ = e_y + 2·e_ψ + 0.714·δ
> e_ψ⁺ = e_ψ + 0.714·δ

### 18.3 决策变量：每步转角的"变化量"

真实的转向系统不能瞬间打到某个角度，所以决策变量取每一步转角的变化量 Δδ_k，再把上一步的转角 δ_{k−1} 当作一个额外的状态：

> δ_k = δ_{k−1} + Δδ_k

增广后的状态是 z_k = (e_y,k, e_ψ,k, δ_{k−1})。这叫**增量形式**，车辆 MPC 里很常用。

### 18.4 约束：每一条都有物理含义

| 约束 | 公式 | 数值 | 含义 |
|---|---|---|---|
| 车道边界 | −0.875 ≤ e_y ≤ 4.625 | 车宽取 2.0 m，(3.75 − 2.0)/2 = 0.875 | 车身不压出这两条车道 |
| 舒适性 | \|a_y\| ≤ 2 m/s²，按 a_y ≈ v²·δ/L 即 \|δ\| ≤ 2L/v² | \|δ\| ≤ 0.014 rad（0.8°） | 乘客不被甩 |
| 转向速率 | \|Δδ\| ≤ 0.0014 rad / 0.1 s | 前轮 0.8°/s，相当于侧向冲击度 ≤ 2 m/s³ | 方向盘转得平缓 |

注意舒适性约束和车速有关：δ 的上限是 2L/v²。10 m/s 时是 0.056 rad，20 m/s 时只有 0.014 rad。**车速翻倍，允许的转角变成四分之一。** 这就是高速上方向盘只能轻轻动的原因。

转向速率限值在这里取得比较保守（方向盘约 12°/s），是一次很平缓的换道，只作示例。

### 18.5 目标函数

> 每一步的代价 = 1 × e_y² + 300 × e_ψ² + 1000 × (Δδ)²，再加终端代价 z_Nᵀ·P·z_N

三个权重的含义：
- e_y 的权重：希望快点到目标车道；
- e_ψ 的权重 300：希望车头尽早回正。e_ψ 以弧度计，1° 只有 0.0175 rad，平方后只有 3×10⁻⁴，所以权重要大，才能和 e_y 的量级相当；
- Δδ 的权重：希望方向盘动得平稳。

**权重怎么选**：我试了几组航向权重，看换道效果（其他设置不变，N = 40）：

| 航向权重 | 冲过目标车道中心多少 | 多久稳定（误差 < 0.1 m） |
|---|---|---|
| 1 | 34 cm | 4.4 s |
| 100 | 13 cm | 3.9 s |
| 300 | 0 | 4.2 s |
| 1000 | 0 | 6.7 s，太慢 |

调权重就是在"快"和"稳"之间找平衡，没有公式，需要试。

### 18.6 终端项

和第 6 课、第 11 课完全一样：
- 用 LQR（同样的权重）算终端代价矩阵 P；
- 再算这个 LQR 控制律在所有约束（车道边界、转角、转向速率）下的最大不变集，作为终端集合。这里得到的不变集有 14 条边。

选题文档阶段 2 写的认证单元"中心线附近的 LQR + 不变集"，就是这个东西。

### 18.7 完整的优化问题

把上面的内容合在一起，每个时刻要解的问题是：

> 最小化 Σ_{k=0}^{N−1} [ e_y,k² + 300·e_ψ,k² + 1000·(Δδ_k)² ] + z_Nᵀ·P·z_N
> 决策变量：Δδ₀, Δδ₁, …, Δδ_{N−1}
> 约束（对 k = 0, …, N−1）：
> - 预测：e_y,k+1 = e_y,k + 2·e_ψ,k + 0.714·δ_k，e_ψ,k+1 = e_ψ,k + 0.714·δ_k，δ_k = δ_{k−1} + Δδ_k
> - 车道：−0.875 ≤ e_y,k+1 ≤ 4.625
> - 舒适：|δ_k| ≤ 0.014
> - 转向速率：|Δδ_k| ≤ 0.0014
> - 终端：z_N 在终端集合里
> 初始条件：z₀ = 当前测量到的 (e_y, e_ψ, 上一步的转角)

目标是二次的，约束全是线性的，所以这是一个 QP，和第 10 课是同一类问题，只是变量更多。

### 18.8 时域

往前看 N = 40 步（4 秒，前方 80 米）。

从 e_y = 3.75 出发，**N = 20（2 秒）时问题无解，N = 25（2.5 秒）才有解**：短时域里，车来不及在约束允许的范围内回到中心线附近的不变集。这和单摆实验里看到的"覆盖率"现象是同一件事。

### 18.9 结果

| 时刻 | 0 s | 1 s | 2 s | 3 s | 4 s | 5 s |
|---|---|---|---|---|---|---|
| e_y（m） | 3.75 | 3.37 | 1.75 | 0.40 | 0.12 | 0.04 |

- 4.2 s 后误差稳定在 0.1 m 以内，**没有冲过头**；
- 最大前轮转角 0.73°，侧向加速度峰值 1.83 m/s²，没碰到 2 的上限；
- 起作用的是转向速率约束，在 3.4 s 内一直顶在上限：这次换道的瓶颈是"方向盘转多快"；
- 每一步求解用时约 8–10 ms（Python + cvxpy + Clarabel 原型；车上会用更快的专用求解器）。

前轮转角随时间的变化（度）：0 s 时 −0.08，0.5 s 时 −0.48，1 s 时 −0.65，1.5 s 时 −0.25，2 s 时 +0.15，2.5 s 时 +0.55，3 s 时 +0.51，3.5 s 时 +0.11。先向右打、再回正、再向左打把车头摆正，整个过程前轮转角每 0.1 秒最多变化 0.08°（换算到方向盘约 1.2°）。

**对比无约束的 LQR**：它第一步就要把前轮打到 4.1°。对应的侧向加速度 10.2 m/s²，连干路轮胎的极限 8.8 都超过了，前轮转动速度 41°/s，乘客会被狠狠甩出去。MPC 的价值就在于系统地处理这些限制。

## 第 19 课：模型选错了会怎样

到目前为止，"真实的车"和 MPC 用的模型是同一个。现实中不可能。下面用非线性动力学模型（第 16 课的方程，侧偏角用 arctan 精确计算，轮胎力在 μ·F_z 处截断）扮演"真车"，每 1 ms 积分一次；MPC 仍然每 0.1 s 计算一次。做了三组实验。

### 19.1 实验一：高速下用运动学模型

同一个运动学 MPC（第 18 课），控制干路上（μ = 0.9）的动力学车：
- **冲过目标车道中心 22 cm**，5.2 s 才稳定（原来是 0 cm、4.2 s）。
- 原因：20 m/s 时真车的转向响应只有运动学模型预测的 72%（第 16.4 节），而且横向速度带来了延迟。MPC 按"转得快"的模型规划，结果车跟不上，又过头。

**改用第 17.3 节的 4 状态动力学误差模型**（同样的权重和约束，舒适约束直接限制模型算出的侧向加速度）：冲过头 0 cm，4.3 s 稳定。

### 19.2 实验二：冰面上用干路的约束

μ = 0.1 时，路面最多只能提供约 0.98 m/s² 的侧向加速度，而 MPC 仍然允许用到 2：
- 运动学 MPC：3.0 s 时问题变成无解，这时车离目标车道中心还有约 0.82 m；
- 4 状态 MPC：先冲过头 35 cm，3.7 s 时无解。前轮侧偏角达到 1.47°，远超冰面的饱和角 0.6°，轮胎已经在滑。

**规划的动作超出了路面能提供的力，车做不到，就失控了。**

### 19.3 实验三：按附着系数收紧约束，却出现新问题

把约束改成 a_y ≤ 0.8·μ·g = 0.785 m/s²，结果 **0.8 s 时就无解了**。

查原因：出问题的那一刻，按当前状态算出的侧向加速度已经是 −0.855 m/s²，超过了 0.785。这是模型的微小误差造成的（线性预测和非线性真车略有不同）。而转向速率又受限，一步之内改不回来，于是"这一步就要满足约束"成了不可能完成的要求，求解器只能报告无解。

（我也检查过是不是轮胎饱和造成的：出问题之前前轮侧偏角最大只有 0.55°，还没到 0.6° 的饱和角，所以不是。）

**解决办法：软约束。** 允许约束被轻微违反，但违反量 ε 在目标函数里受很重的惩罚（这里加了 10⁵·ε + 10⁵·ε²）。改成软约束后：
- 4.9 s 完成换道，没有冲过头；
- 实际侧向加速度峰值 0.86 m/s²，略超过 0.785，但低于路面极限 0.98。

作为对照：同样用软约束，但限值仍然是干路的 2 m/s²，冰面上 3.7 s 时还是无解。软约束只能处理"小的违反"，处理不了"规划本身超出物理极限"。

### 19.4 这一课的三条经验

1. **模型要和速度区间匹配**：高速要用动力学模型。
2. **约束要随路面变**：附着系数 μ 必须估计出来，放进约束。
3. **依赖状态的硬约束，在模型有误差时可能突然无解**：要么用软约束，要么用鲁棒 MPC（比如 tube MPC，方向二读的 RALMPC 就是一种）。

## 第 20 课：车辆 MPC 在工程中还要考虑什么

### 20.1 常见问题和做法

| 问题 | 是什么 | 常见做法 |
|---|---|---|
| 车速在变 | 横向模型的 A、B 依赖车速 | 每一步按当前车速更新 A、B（线性时变 MPC），或者直接用非线性 MPC |
| 弯道 | 路的曲率随位置变 | 把前方的曲率当作已知输入放进预测，加前馈转角 |
| 纵向控制 | 定速巡航、跟车距离 | 加入 v̇ = a，速度和转向一起优化 |
| 避障 | 障碍物让可行区域分成"从左绕"和"从右绕"两块 | 非凸问题，有两个"山谷"（第 7 课）。常见做法是上层先决定从哪边绕，再在通道里解凸的 MPC；或者用非线性 MPC 加好的初值 |
| 实时性 | 车上通常要 20–50 Hz | QP 用 OSQP、qpOASES；非线性 MPC 用 acados；CasADi + IPOPT 适合做原型 |
| 延迟 | 转向执行器有延迟，计算也要时间 | 把延迟写进预测模型 |
| 参数变化 | 载人载货改变质量，轮胎和天气改变 C 和 μ | 参数估计、自适应或鲁棒 MPC |

### 20.2 仿真平台（从简单到复杂）

1. 本部分这种几十行的 Python 模型：最适合理解原理和做算法验证；
2. highway-env、MetaDrive：多车交互（方向三提到过）；
3. CARLA：带传感器和城市场景；
4. CarSim、Simulink：工业级车辆动力学。

### 20.3 推荐读物（仓库里没有，都是这个领域的经典）

- Rajamani，《Vehicle Dynamics and Control》第 2–3 章：自行车模型和横向误差模型，第 17.3 节就出自这里。
- Kong 等，"Kinematic and dynamic vehicle models for autonomous driving control design"，IEEE IV 2015：两种模型用于 MPC 的比较。
- Polack 等，IEEE IV 2017：运动学模型的适用范围。
- Falcone 等，"Predictive active steering control for autonomous vehicle systems"，IEEE TCST 2007：车辆转向 MPC 的经典论文。
- Liniger 等，"Optimization-based autonomous racing of 1:43 scale RC cars"，2015：极限工况下的车辆 MPC。
- Pacejka，《Tire and Vehicle Dynamics》：轮胎模型。

## 自测题

1. 停车场里以 3 km/h 倒车入库，用运动学模型还是动力学模型？为什么？
2. 车速从 20 m/s 提高到 30 m/s，舒适约束 a_y ≤ 2 m/s² 对应的最大前轮转角变成多少？
3. 第 19.3 节里，为什么硬约束的 MPC 在 0.8 s 无解，换成软约束就能继续工作？
4. 用第 16.4 节的公式，车速 20 m/s 过半径 200 m 的弯，需要多大的前轮转角？其中几何转角和"不足转向的额外转角"各是多少？

## 答案

1. 运动学模型。低速时车轮几乎不打滑，"不打滑"的假设成立；而动力学模型里有 1/v，3 km/h（0.83 m/s）时时间常数只有几毫秒，算不准，速度为 0 时直接失效。
2. δ_max = 2L/v² = 2 × 2.8 / 900 = 0.0062 rad（0.36°），只有 20 m/s 时（0.014 rad）的 4/9。
3. 模型误差让当前状态下的侧向加速度已经超过了限值（−0.855 对 0.785），而转向速率限制让这一步改不回来。硬约束要求"这一步就满足"，做不到，就没有可行解。软约束允许小幅违反，只是代价很高，所以总有解，MPC 会尽快把违反量压回去。
4. a_y = v²/R = 400/200 = 2 m/s²。几何转角 L/R = 2.8/200 = 0.014 rad；额外转角 K·a_y = 0.00268 × 2 = 0.0054 rad；合计 δ = 0.0194 rad（约 1.1°），比几何转角多了约 38%。车速越高，不足转向的影响越大。
